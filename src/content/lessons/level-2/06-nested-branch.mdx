## 1. 为什么需要多层分支？
生活中的收费、等级评价、购票优惠通常不是只有“是/否”两个结果，而是根据多个条件决定结果。

```cpp
if (score >= 90) cout << "A";
else if (score >= 80) cout << "B";
else if (score >= 60) cout << "C";
else cout << "D";
```

**数学原理：分段函数。** 上述代码对应四个互不重叠的区间：`[90,100]`、`[80,90)`、`[60,80)`、`[0,60)`。因为程序按顺序判断，所以第二个条件不必再写 `score<90`。

## 2. switch的典型结构
```cpp
switch(day){
    case 1: cout<<"Mon"; break;
    case 2: cout<<"Tue"; break;
    default: cout<<"Other";
}
```

`switch`适合比较整型或枚举等离散值，不适合直接表达 `score>=90` 这样的区间。缺少 `break` 时可能继续执行后面的 `case`，需要有意识地使用。

## 3. 例题：阶梯水费
输入非负整数用水量 `n`：前10吨每吨2元，11—20吨部分每吨3元，超过20吨部分每吨5元。

分段公式：
- `0≤n≤10`：`2n`
- `10<n≤20`：`20+3(n-10)`
- `n>20`：`20+30+5(n-20)`

```cpp
#include <iostream>
using namespace std;
int main(){
    int n; cin>>n;
    int cost;
    if(n<=10) cost=2*n;
    else if(n<=20) cost=20+3*(n-10);
    else cost=50+5*(n-20);
    cout<<cost<<'\n';
}
```

测试：`10→20`、`11→23`、`20→50`、`21→55`。边界值是分段题最重要的测试点。
