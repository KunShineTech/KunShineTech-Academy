## 1. 计算机生成的“随机”是什么？
`rand()`产生**伪随机数**：看起来不规则，但由算法和内部状态决定。`srand(seed)`设置种子；相同实现、相同种子通常会产生相同序列。考试重点是认识基本函数和使用方式。

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;
int main(){
    srand(123);
    for(int i=0;i<5;i++) cout<<rand()<<' ';
}
```

## 2. 数学原理：映射到指定区间
常见入门写法 `rand()%6+1` 将整数映射到1—6。`%6` 的结果为0—5，再加1得到1—6。

**注意**：这并不保证每个结果严格等概率，因为 `RAND_MAX+1` 未必能被6整除；也不适用于密码学。现代工程常用 `<random>`，但该库不属于此处上传的二级考纲明确要求。

## 3. 例题：模拟掷骰子
```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;
int main(){
    srand(static_cast<unsigned>(time(nullptr)));
    int dice = rand()%6+1;
    cout<<dice<<'\n';
}
```

## 4. 算法练习：统计骰子结果
如果掷骰子 `n` 次，如何统计点数6出现的次数？使用循环重复生成随机数，再用 `if(dice==6) count++` 统计。
