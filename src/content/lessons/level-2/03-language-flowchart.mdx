## 1. 语言从哪里来？
- **机器语言**：CPU可执行的机器指令，用二进制形式表示。
- **汇编语言**：用助记符表示机器指令，需要汇编器翻译。
- **高级语言**：如 C++、Python，更接近人类表达，通常需编译器或解释器等执行环境。

C++源代码经编译、链接等步骤形成可执行程序；Python常见实现通过解释器运行。两者不能简单等同于“一个快、一个慢”，具体性能受实现和任务影响。

## 2. 流程图四类核心符号
| 形状 | 用途 | 例子 |
|---|---|---|
| 椭圆 | 开始/结束 | Start、End |
| 平行四边形 | 输入/输出 | 输入n、输出结果 |
| 矩形 | 处理步骤 | `sum = sum + i` |
| 菱形 | 条件判断 | `n % 2 == 0?` |

## 3. 数学原理与算法步骤
判断偶数：存在整数 `k` 使 `n=2k`。在程序中，`n%2==0` 可判断整数 `n` 是否为偶数。

```cpp
#include <iostream>
using namespace std;
int main(){
    int n; cin>>n;
    if(n%2==0) cout<<"EVEN\n";
    else cout<<"ODD\n";
}
```
