## 2. 例题：统计区间内的完全平方数
输入 `L,R`（`0≤L≤R≤10000`），统计区间内的完全平方数个数。完全平方数是某个非负整数的平方，例如0、1、4、9、16。

方法A：对每个 `x` 从L到R，计算平方根并判断是否整数。但浮点比较有误差风险。

方法B（推荐）：枚举 `k`，检查 `L≤k*k≤R`，避免浮点问题。

```cpp
#include <iostream>
using namespace std;
int main(){
    int L,R;cin>>L>>R;
    int count=0;
    for(int k=0;k*k<=R;k++){
        if(k*k>=L) count++;
    }
    cout<<count<<'\n';
}
```

**数学分析：** 因为 `k*k` 随非负 `k` 增大而增大，枚举到 `k*k>R` 就可以结束。样例 `[1,10]` 中有1、4、9，共3个。

## 3. 例题：统计满足条件的数对
输入 `n`，统计满足 `1≤a&lt;b≤n` 且 `a+b` 为偶数的数对数量。

```cpp
#include <iostream>
using namespace std;
int main(){
    int n,ans=0;cin>>n;
    for(int a=1;a<=n;a++){
        for(int b=a+1;b<=n;b++){
            if((a+b)%2==0) ans++;
        }
    }
    cout<<ans<<'\n';
}
```

**数学原理：** 两数之和为偶数，当且仅当两数奇偶性相同。可先手工列出 `n=4` 的所有合法数对：`(1,3)`、`(2,4)`。
