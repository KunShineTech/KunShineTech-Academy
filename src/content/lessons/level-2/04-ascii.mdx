## 1. 字符为什么能用数字表示？
计算机最终存储的是二进制信息。ASCII是一种字符编码标准，定义了128个基本字符的编码。GESP二级明确要求识别四个常用值：

| 字符 | 十进制ASCII |
|---|---:|
| 空格 | 32 |
| `'0'` | 48 |
| `'A'` | 65 |
| `'a'` | 97 |

英文字母编码连续：`'A'`到`'Z'`对应65—90，`'a'`到`'z'`对应97—122，数字字符`'0'`到`'9'`对应48—57。

## 2. 关键程序元素
```cpp
#include <iostream>
using namespace std;
int main(){
    char c='A';
    cout<<int(c)<<'\n';       // 65
    cout<<char(65)<<'\n';     // A
    cout<<int('7'-'0')<<'\n'; // 7
}
```

**数学原理：** 大写与小写英文字符的ASCII编码相差32，因此 `char(c-'a'+'A')` 可以把已知的小写英文字母转换为对应大写字母。注意这不是所有语言文字的通用转换法。

## 3. 例题：单个小写字母转大写
**输入**：一个小写字母。**输出**：对应的大写字母。

算法：输入字符 `c` → 计算 `c-'a'+'A'` → 转为字符输出。

```cpp
#include <iostream>
using namespace std;
int main(){
    char c; cin>>c;
    cout<<char(c-'a'+'A')<<'\n';
}
```

**边界测试**：`a→A`、`z→Z`；若输入不是小写字母，这个转换公式不保证得到期望结果。
