## 1. 什么是枚举？
**枚举**就是把可能答案按照明确顺序逐一检查。它不是“瞎猜”，而是先确定**候选集合**，再写**判断条件**。

例如找1—100之间既能被3整除又能被5整除的数：
- 候选集合：整数1到100。
- 条件：`x%3==0 && x%5==0`。
- 输出：满足条件的数。

```cpp
for(int x=1;x<=100;x++){
    if(x%3==0 && x%5==0) cout<<x<<' ';
}
```

## 2. 数学原理：公倍数
同时被3和5整除的数是15的倍数。因为3和5互质，其最小公倍数是 `3×5=15`。可以用这个规律检查程序输出是否合理。

> “最小公倍数”属于本课为理解枚举加入的数学补充；GESP二级的官方重点是循环和条件控制，不要求在本级掌握完整数论算法。

## 3. 例题：统计符合条件的数
输入 `n`，统计1到n之间能被2或3整除的整数个数。

```cpp
#include <iostream>
using namespace std;
int main(){
    int n,ans=0;cin>>n;
    for(int x=1;x<=n;x++){
        if(x%2==0 || x%3==0) ans++;
    }
    cout<<ans<<'\n';
}
```

**样例** `n=6`：符合条件的是2、3、4、6，答案4。注意 `||` 是“或”，而 `&&` 是“且”。
