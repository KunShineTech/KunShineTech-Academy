## 1. 把循环理解为“行和列”
单层循环重复一个动作，双重循环可以重复“一组动作”。输出矩形时，外层决定有多少行，内层决定每行有多少列。

```cpp
for(int i=1;i<=3;i++){
    for(int j=1;j<=4;j++) cout<<'*';
    cout<<'\n';
}
```

输出3行、每行4颗星。注意 `cout<<'\n'` 必须放在内层循环结束之后。

## 2. 数学原理：循环次数
若外层循环 `n` 次，内层每次固定 `m` 次，内层语句共执行 `n×m` 次。

若第 `i` 行输出 `i` 颗星，总次数为 `1+2+…+n = n(n+1)/2`。这个等差数列求和公式是理解三角形输出的关键。

## 3. 例题：九九乘法表
```cpp
#include <iostream>
using namespace std;
int main(){
    for(int i=1;i<=9;i++){
        for(int j=1;j<=i;j++){
            cout<<j<<"*"<<i<<"="<<i*j<<' ';
        }
        cout<<'\n';
    }
}
```

**思路拆解：** 第 `i` 行只打印 `j=1` 到 `i`；内层次数随外层变量变化，因此输出三角形而非矩形。
