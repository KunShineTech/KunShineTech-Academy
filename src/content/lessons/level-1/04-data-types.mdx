## 1. 储物盒有不同型号
上一课我们知道变量是储物盒。盒子其实有不同型号：装整数的、装小数的、装单个字符的、装真假的。选错型号，轻则浪费空间，重则装不下出错。

| 类型 | 写法示例 | 占用空间（常见） | 适合装什么 |
|---|---|---|---|
| `int` 整型 | `int a = 42;` | 4 字节 | 一般整数，约 ±21 亿以内 |
| `long long` 长整型 | `long long b = 10000000000LL;` | 8 字节 | 很大的整数 |
| `float` 单精度 | `float c = 3.5f;` | 4 字节 | 小数（精度较低） |
| `double` 双精度 | `double d = 3.14159;` | 8 字节 | 小数（常用） |
| `char` 字符型 | `char e = 'A';` | 1 字节 | 单个字符，用单引号 |
| `bool` 布尔型 | `bool f = true;` | 1 字节 | 真 `true` 或假 `false` |

> 教学提醒：字符要用**单引号**，如 `'A'`；双引号是字符串的写法。`bool` 的值只有真和假两种。

## 2. 溢出：小杯子装大桶水
`int` 能装的整数有上限（约 21 亿）。如果硬塞一个一百亿的数进去，就像往小杯子里倒一大桶水——装不下的部分会**溢出**，结果变成一个错误的数，而且不会报错！

```cpp
int a = 1000000000;      // 十亿，int 装得下
int b = a * 2;           // 二十亿，超出了 int 的范围，溢出！
long long c = a * 2LL;   // 用 long long 参与计算就安全了
```

经验法则：不确定范围够不够大时，用 `long long` 更稳妥；涉及小数用 `double`。

**sizeof 小工具**：`sizeof(类型)` 可以查看类型占用几个字节：

```cpp
cout << sizeof(int) << '\n';    // 常见输出 4
cout << sizeof(char) << '\n';   // 常见输出 1
```

## 3. 类型之间的转换
把 `double` 装进 `int` 盒子，小数部分会被直接**截断**（不是四舍五入）：

```cpp
double pi = 3.14159;
int x = int(pi);    // x 的值为 3
int y = int(-2.9);  // y 的值为 -2（向零截断）
```

```cpp
char ch = 'A';
cout << int(ch) << '\n';  // 输出 65，字符背后藏着数字编码
```

## 4. 例题解析
**问题**：要保存「中国人口约 14 亿」这个整数，选 `int` 还是 `long long`？

**思路**：14 亿在 `int` 上限 21 亿以内，`int` 可以；但如果还要做乘法（如人均计算），乘积可能瞬间超出，此时用 `long long` 更保险。
