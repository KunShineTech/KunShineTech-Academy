## 1. 程序也需要看红绿灯
走到路口，红灯停、绿灯行——程序也有这样的「路口」，叫**分支结构**。条件成立就走一条路，不成立就走另一条路。

最简单的 `if` 语句：

```cpp
if (score >= 60) {
    cout << "及格啦！" << '\n';
}
```

规则：条件放在小括号里；条件为**真**（true 或非 0 的数）就执行大括号里的语句块，为假就跳过。

## 2. if-else：二选一
加个 `else`，两条路必选其一：

```cpp
if (x >= 0) {
    cout << x << '\n';      // 非负：直接输出
} else {
    cout << -x << '\n';     // 负数：取反变正
}
```

这段代码输出的正是 x 的**绝对值**。条件不限于一个比较，可以是任意逻辑表达式，比如「年龄在 6 到 12 岁之间」写作 `age >= 6 && age <= 12`。

## 3. 嵌套 if：套娃式判断
一个 if 的大括号里还能再放 if，这就是**嵌套**。常见的「成绩等级」问题：

```cpp
if (score >= 90) {
    cout << "A" << '\n';
} else {
    if (score >= 60) {
        cout << "B" << '\n';
    } else {
        cout << "C" << '\n';
    }
}
```

风格提示：内层只有一句时，`} else if (条件) {` 是更清爽的合并写法。else 总与**离它最近且尚未配对**的 if 结对，写嵌套时务必用大括号把层次标清楚。

## 4. 例题解析
**问题**：读入整数成绩 score（0 到 100），输出等级：90 及以上为 A，60 到 89 为 B，不足 60 为 C。

**思路**：三个分段、两条分界线，用「if—else if—else」三段式正好覆盖所有情况，不会遗漏。
