## 1. 键盘上没有的运算符号
数学里的 `×` 和 `÷` 在键盘上不好打，C++ 改用星号和斜杠：

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加 | `7 + 2` | 9 |
| `-` | 减 | `7 - 2` | 5 |
| `*` | 乘 | `7 * 2` | 14 |
| `/` | 除 | `7 / 2` | 3（见下） |
| `%` | 求余 | `7 % 2` | 1 |

## 2. 整除与求余：两个易错点
**整除**：当 `/` 两边都是整数时，结果也是整数，小数部分被**向零截断**（直接扔掉）：

```cpp
cout << 7 / 2 << '\n';    // 3，不是 3.5
cout << -7 / 2 << '\n';   // -3（向零方向截断）
cout << 7 / 2.0 << '\n';  // 3.5，只要一边是小数，结果就是小数
```

**求余** `%`：求两个整数相除后的余数，常用于取个位、判断奇偶：

```cpp
cout << 123 % 10 << '\n';  // 3，个位数字
cout << 10 % 3 << '\n';    // 1，10 除以 3 商 3 余 1
```

> 教学提醒：`%` 的两边必须是整数；想保留小数，就让除法的一边变成 `double`。

## 3. 优先级、括号与自增自减
运算有先后顺序，和数学一样：**先乘除、后加减，括号最优先**，同级从左到右：

```cpp
cout << 2 + 3 * 4 << '\n';    // 14，先算乘法
cout << (2 + 3) * 4 << '\n';  // 20，括号改变顺序
```

**自增与自减**：`a++` 让 a 加一，`a--` 让 a 减一，等价于 `a = a + 1` 的简写。前缀 `++a` 与后缀 `a++` 单独使用时效果一样；放在表达式里时求值顺序有差别，一级只需了解、考试不深入。

```cpp
int a = 5;
a++;                 // a 变成 6
cout << a << '\n';
```

**思路**：任何一个正整数对 10 求余，剩下的就是个位：`123 % 10` 得 3。
