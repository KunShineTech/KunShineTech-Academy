## 1. switch：多选一菜单
if-else 像每次只问一个是非题；当要对一个整数值做多路选择时，`switch` 像快餐店的编号菜单，更清爽：

```cpp
switch (day) {
    case 1:
        cout << "星期一" << '\n';
        break;
    case 2:
        cout << "星期二" << '\n';
        break;
    default:
        cout << "输入错误" << '\n';
}
```

结构要点：`switch` 后小括号放**一个整型表达式**；每个 `case` 后跟一个常量值和冒号；`default` 处理「所有没列出的情况」，建议总是写上。

## 2. 穿透现象：别忘了 break
**重点**：匹配某个 case 后，如果没有 `break`，程序会**继续往下执行**后面所有 case 的语句，这叫**穿透**（贯穿）。有时故意利用它，比如「1 到 5 都算工作日」：

```cpp
switch (d) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        cout << "工作日" << '\n';  // 前五个 case 都汇聚到这里
        break;
    case 6:
    case 7:
        cout << "休息日" << '\n';
        break;
    default:
        cout << "输入错误" << '\n';
}
```

不需要穿透时，每个 case 末尾都要写 `break`，这是初学者最常见的 bug。

## 3. 三目运算符：一句话二选一
`if-else` 的迷你版，格式为「条件 ? 值1 : 值2」：条件真取值 1，假取值 2。

```cpp
int a = 3, b = 7;
int mx = a > b ? a : b;   // mx 得到 7
cout << (a % 2 == 0 ? "偶数" : "奇数") << '\n';
```

它适合**两个值之间**的简洁选择；分段多、条件复杂时，还是 if 或 switch 更清晰。

**if 还是 switch？** 对一个变量的几个固定取值做多路选择，用 switch；对范围（如成绩分段）或复杂逻辑，用 if。

## 4. 例题解析
**问题**：读入 1 到 7 的整数，输出对应的星期几；其他数输出「输入错误」。

**思路**：七个固定取值正好用 switch 菜单，每个 case 记得 break，最后用 default 兜底。
