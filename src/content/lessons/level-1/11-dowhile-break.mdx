## 1. do-while：先斩后奏的循环
 while 循环「先问再做」，可能一次都不执行；`do-while` 相反——**先执行一次，再判断条件**，所以它的循环体**至少执行一次**。这就像先尝一口汤再问「要不要再加一勺」。

```cpp
int i = 1;
do {
    cout << i << '\n';
    i++;
} while (i <= 10);   // 注意结尾有分号
```

场景记忆：菜单至少要显示一次、密码至少要询问一次，都适合 do-while。别忘条件后的分号，这是新手易漏点。

## 2. break 与 continue：循环的两个开关
- **`break`**：立即结束**所在的那一层**循环，直接跳出。
- **`continue`**：跳过本轮剩余的语句，直接进入下一轮。

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;       // 数到 5 就停，输出 1 2 3 4
    cout << i << ' ';
}
```

```cpp
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;  // 偶数跳过，输出所有奇数
    cout << i << ' ';
}
```

> 教学提醒：break 只跳出**一层**。在两层循环里，它只终止内层，外层继续转。

## 3. 循环嵌套：行与列的分工
循环里再放循环，就像课表里「星期」套着「节次」：外层循环走一行，内层循环把这一行填满。输出一个 n 行 n 列的星号方阵：

```cpp
int n;
cin >> n;
for (int i = 1; i <= n; i++) {        // 外层：负责第几行
    for (int j = 1; j <= n; j++) {    // 内层：负责一行里的第几个
        cout << '*';
    }
    cout << '\n';                     // 一行打完才换行
}
```

分析执行次数：外层每转一圈，内层完整转 n 圈，总共输出 n×n 个星号。当 n 为 3 时就是三行「`***`」。

## 4. 例题解析
**问题**：读入 n，输出 n 行、每行 n 个星号的正方形。

**思路**：外层循环管「换几次行」，内层循环管「每行印几个星号」，内层结束后单独输出一次换行。
