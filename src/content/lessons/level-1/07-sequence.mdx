## 1. 顺序结构：一句跟着一句
做三明治有顺序：先拿面包，再放馅料，最后合盖。程序默认也是这么执行的——**从上往下，一句一句来**，这叫**顺序结构**，是最基本的程序结构。

```cpp
int a = 3;
int b = 7;
int sum = a + b;   // 必须先有 a、b，才能求和
cout << sum << '\n';
```

如果把求和写在定义之前，就像还没放馅料就合盖，编译器会报「变量未定义」。

## 2. 交换两个变量：需要一只空杯子
有两杯果汁，苹果汁在 A 杯，橙汁在 B 杯，怎么互换？直接倒会洒，需要一个**空杯子 T** 过渡。交换变量同理：

```cpp
int a = 3, b = 7;
int t = a;   // 1. 把 a 的备份倒进空杯 t
a = b;       // 2. 把 b 倒进 a
b = t;       // 3. 把备份倒进 b
cout << a << ' ' << b << '\n';  // 输出 7 3
```

**复合赋值**让常见操作更简洁：`a += 5;` 等价于 `a = a + 5;`，同理还有 `-=`、`*=`、`/=`、`%=`。

## 3. 数学公式翻译成程序
三步口诀：**读入 → 计算 → 输出**。以三角形面积（底乘高除以 2）为例：

```cpp
double a, h;
cin >> a >> h;          // 读入
double s = a * h / 2;   // 计算
cout << s << '\n';      // 输出
```

平均数公式「总和除以个数」写作 `(a + b) / 2.0`——注意分母写 2.0 保证结果带小数。

## 4. 调试与常见错误
新手四大「拦路虎」，遇到报错先查它们：

1. **漏写分号**：每句结尾都要有 `;`。
2. **大小写错误**：C++ 区分大小写，`Cout`、`Main` 都会报错，必须写 `cout`、`main`。
3. **拼错变量名**：定义叫 `sum`，后面写 `sun`，编译器会认为是个新名字。
4. **中文标点混入**：分号、括号、引号必须是英文半角，中文输入法很容易混入。

> 教学提醒：编译器报错常从「第一处错误」连锁出一片，先修第一行错误再重新编译，事半功倍。

## 5. 课后巩固
1. 说出顺序结构的执行特点，并举一个生活中「必须按顺序」的例子。
2. 解释为什么不能直接 `a = b; b = a;` 完成交换。
3. 把公式「梯形面积 = (上底 + 下底) × 高 ÷ 2」翻译成程序，设计样例并验证。
