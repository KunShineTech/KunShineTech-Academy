## 1. 循环：让计算机做重复的事
体育老师喊口令「1 到 10，报数！」——这就是循环：**重复做同一件事，只是次数在变**。让计算机从 1 数到 100，它一眨眼就完成。

`for` 循环是最常用的计数循环，小括号里三个要素用分号隔开：

```cpp
for (int i = 1; i <= 10; i++) {
    cout << i << '\n';
}
```

| 要素 | 这里是什么 | 职责 |
|---|---|---|
| 初始化 | `int i = 1` | 发令枪：只执行一次，设置起点 |
| 条件 | `i <= 10` | 刹车：条件为真继续，为假结束 |
| 更新 | `i++` | 步进：每轮结束后让 i 走一步 |

## 2. while：条件说了算的循环
`while` 循环只要读懂一句话：「**当**条件成立，就重复执行」。

```cpp
int i = 1;             // 起点写在循环外
while (i <= 10) {      // 条件
    cout << i << '\n';
    i++;               // 步进别忘，否则条件永远成立，死循环！
}
```

两种循环能互相改写：次数明确时常用 for；由某个条件控制结束时 while 更自然。**死循环**（条件永远为真、永远出不来）是新手最常见的坑，检查每轮有没有让条件「靠近 false」。

## 3. 循环累加：1 加到 n
高斯小时候算 1 加到 100。程序的做法是准备一个「累加器」盒子，每轮把一个数倒进去：

```cpp
int n;
cin >> n;
int sum = 0;                      // 累加器清零
for (int i = 1; i <= n; i++) {
    sum += i;                     // 等价于 sum = sum + i
}
cout << sum << '\n';              // n 为 100 时输出 5050
```

关键细节：累加器必须在循环**之前**清零；`sum += i` 是复合赋值简写。

## 4. 例题解析
**问题**：读入 n，输出 1 到 n 的和。

**思路**：读入 → 清零累加器 → 循环 n 轮累加 → 输出。这就是「读入、计算、输出」三步法套上一个循环。
