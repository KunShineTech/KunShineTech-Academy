## 1. 变量是贴标签的储物盒
程序需要记住数据。把内存想象成一排储物盒：**变量**就是给盒子贴上标签（变量名），盒子里的东西（值）可以随时更换。

```cpp
int age = 12;   // 找到一个 int 型盒子，贴标签 age，放入 12
age = 13;       // 赋值：把 age 盒子里的旧值换成 13
```

赋值语句的格式是「变量 = 表达式;」，方向从右往左：先算出右边的值，再放进左边的盒子。注意 `age = age + 1;` 在数学里不成立，在程序里却完全合法：把 age 的值加一，再存回 age。

如果盒子贴上标签后就不许换内容，这就是**常量**，用 `const` 加锁：

```cpp
const double PI = 3.14159;  // 常量：定义后不能再修改
```

## 2. 标识符命名规则与关键字
变量名（标识符）不是随便起的，要守规矩：

1. 只能由字母、数字、下划线组成；
2. 不能以数字开头；
3. 区分大小写，`Age` 和 `age` 是两个不同的盒子；
4. 不能用**关键字**——它们已被 C++ 占用。

常见关键字：`int`、`double`、`char`、`bool`、`const`、`if`、`else`、`for`、`while`、`return`、`switch`。

> 教学提醒：建议用有含义的名字，如 `sum`、`score`，不要图省事写成 `a1`、`a2`，代码是写给人读的。

## 3. 用 cin 让程序学会“听话”
`cout` 负责说，`cin` 负责听。`cin >>` 像一根吸管，把键盘输入吸进盒子：

```cpp
int a, b;
cin >> a >> b;   // 依次读入两个整数，中间用空格或回车分隔
cout << a + b << '\n';
```

C 语言风格的 `scanf` 和 `printf` 也能完成输入输出，GESP 一级只需了解：

```cpp
int x;
scanf("%d", &x);          // 读入整数，& 表示取地址
printf("%d\n", x);        // 输出整数
printf("%.2f\n", 3.14159); // 保留两位小数输出
```

本课程以 `cin`、`cout` 为主，`scanf`、`printf` 能看懂即可。

## 4. 例题解析
**问题**：读入小明今年的年龄，输出他明年的年龄。

**思路**：需要一个 int 盒子装年龄，用 `cin` 读入，再整体加一输出。

```cpp
#include <iostream>
using namespace std;
int main() {
    int age;
    cin >> age;            // 把键盘输入吸进 age 盒子
    cout << age + 1 << '\n';
    return 0;
}
```
