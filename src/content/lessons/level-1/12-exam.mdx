## 1. 考点串讲
把一级知识想象成一棵小树：树根是计算机基础，树干是数据与运算，枝叶是三种程序结构。按这张表逐行自查，标出「陌生」的单元回炉重学：

| 模块 | 核心考点 | 自查问题 |
|---|---|---|
| 计算机基础 | 硬件组成、操作系统、Dev C++ 六步流程 | 能默写编译运行步骤吗？ |
| 第一个程序 | `#include`、`main`、`cout`、`return`、注释 | 能不看样例写出 Hello 程序吗？ |
| 变量与输入 | 标识符规则、关键字、`cin`、赋值语句 | `=` 和 `==` 分得清吗？ |
| 数据类型 | int、long long、double、char、bool、溢出 | 什么情况下选 long long？ |
| 运算表达式 | `+ - * / %`、整除截断、优先级、`++ --` | `7 / 2` 和 `7 % 2` 各是多少？ |
| 关系与逻辑 | 六种关系符、`&& || !`、真值表 | 会写「6 到 12 岁之间」吗？ |
| 顺序结构 | 交换两数、公式翻译、常见语法错误 | 交换需要第几个变量？ |
| 分支结构 | if、if-else、switch、三目、穿透与 break | else 和谁配对？ |
| 循环结构 | for 三要素、while、do-while、break、continue、嵌套 | 累加器初始值是多少？ |

## 2. 考试结构与时间分配
GESP 认证采用「选择 + 判断 + 编程」的混合题型（以官方当次考试说明为准）。参考时间策略：

- 前 40 分钟：完成选择与判断，拿不准的题先标记。
- 40—75 分钟：第一道编程题，先写核心逻辑再处理边界。
- 75—110 分钟：第二道编程题。
- 最后 10 分钟：对照样例输入输出逐题验证，检查文件名与保存。

**本课模拟题均为原创教学练习，不是官方真题或命题预测。**

<Task title="奇偶判断" input="一个整数 n（`-1000 ≤ n ≤ 1000`）" output="偶数输出「偶数」，奇数输出「奇数」" sampleIn="7" sampleOut="奇数">读入一个整数，判断它是奇数还是偶数。提示：回想求余运算的妙用。注意负数也要判断正确。</Task>
<Reveal label="参考答案：奇偶判断"><pre><code>{`#include <iostream>\nusing namespace std;\nint main(){\n    int n;\n    cin >> n;\n    if (n % 2 == 0)\n        cout << \"偶数\" << '\\n';\n    else\n        cout << \"奇数\" << '\\n';\n    return 0;\n}`}</code></pre>思路：对 2 求余，余 0 是偶数。n=7 时 7%2 得 1，走 else 输出「奇数」，与样例一致；再验证 -4 输出「偶数」。</Reveal>

## 4. 模拟题二：累加求和
<Task title="一到 n 求和" input="一个正整数 n（`1 ≤ n ≤ 1000`）" output="1 到 n 所有整数之和" sampleIn="100" sampleOut="5050">读入 n，用循环累加 1 到 n。写完后用 n=1（最小）和 n=100（对照样例）各测一次。</Task>
<Reveal label="参考答案：累加求和"><pre><code>{`#include <iostream>\nusing namespace std;\nint main(){\n    int n;\n    cin >> n;\n    int sum = 0;\n    for (int i = 1; i <= n; i++) {\n        sum += i;\n    }\n    cout << sum << '\\n';\n    return 0;\n}`}</code></pre>思路：累加器清零后置入循环；n=100 时结果为 5050，与样例一致。若题目改为「读入 a 和 b，求 a 到 b 之和」，只需把循环起点和终点换掉。</Reveal>

## 5. 考试须知与心态
- **考前**：确认准考证与证件，提前到达考场，熟悉 Dev C++ 的编译运行快捷键。
- **考中**：先易后难；编程题先写「读入→计算→输出」骨架，再补细节；样例没通过前不要急着交。
- **常见失分点**：输出多空格或漏换行、文件名写错、把 `==` 写成 `=`、循环忘写步进导致死循环。
- **心态**：认证是一次阶段性的体检，不是终点站。认真复盘错题，比一次高分更有价值。

## 6. 课后巩固
1. 把第 1 节的自查表中所有「陌生」单元重新学习并各写一个小程序。
2. 不看参考答案，30 分钟内独立完成两道模拟题并对照样例验证。
3. 整理一页自己的「考前必看清单」：公式、易错点、常用模板。
4. 和家长做一次模拟口试：互相提问十道一级考点问题。
