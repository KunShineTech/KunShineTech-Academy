## 1. 计算机是怎样工作的？
把计算机想象成一家餐厅：**CPU（中央处理器）**是厨师，负责计算与做决定；**内存**是出菜口的工作台，正在做的菜摆在上面，打烊就清空；**硬盘**是仓库，长期存放食材（文件）；**键盘、鼠标**是点菜窗口，属于输入设备；**显示器、打印机**是上菜口，属于输出设备。

| 组成部分 | 餐厅类比 | 作用 |
|---|---|---|
| CPU | 厨师 | 运算与控制，是计算机的“大脑” |
| 内存 RAM | 工作台 | 临时存放正在运行的程序和数据，断电通常丢失 |
| 硬盘/固态硬盘 | 仓库 | 长期保存文件，断电不丢 |
| 输入设备 | 点菜窗口 | 把人的指令送进计算机，如键盘、鼠标 |
| 输出设备 | 上菜口 | 把结果展示给人，如显示器、音箱 |

> 历史小知识：1946 年，世界上第一台通用电子计算机 ENIAC 在美国诞生，它重达几十吨，每秒只能做几千次加法。今天的手机比它强大数百万倍。

## 2. 操作系统：计算机的大管家
**操作系统（OS）**是管理硬件、组织文件的“大管家”。我们写的程序，都要在操作系统搭好的舞台上运行。常见的操作系统有 Windows、macOS、Linux，手机上的 Android 和 iOS 也是操作系统。本课程使用的 Dev C++ 就运行在 Windows 操作系统上。

操作系统还负责“翻译”：你双击图标、敲击键盘，最终都会变成 CPU 能理解的指令。

## 3. Dev C++ 使用六步流程
就像做饭有固定流程，使用 Dev C++ 写程序也有标准动作：

1. **创建**：菜单「文件」→「新建」→「源代码」，或按 Ctrl+N。
2. **编辑**：在编辑区输入代码，关键字会自动变色。
3. **保存**：按 Ctrl+S，文件名建议用英文，后缀是 `.cpp`。
4. **编译**：按 F9，编译器把源代码翻译成机器语言，信息区出现「编译成功」才算通过。
5. **运行**：按 F10，查看程序结果。
6. **调试**：出错时阅读编译信息，逐行对照修改；也可以在行号处点红点设置断点，单步执行、观察变量的变化。

```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "你好，计算机！" << '\n';
    return 0;
}
```

## 4. 例题解析
**问题**：为什么硬盘里的文件关机后还在，而内存里的内容关机后通常消失？

**思路**：硬盘是非易失存储，用来长期保存；内存是易失存储，只为正在运行的程序提供临时工作空间。餐厅打烊（断电）后，工作台上的菜会收走，仓库里的食材仍然保留。
