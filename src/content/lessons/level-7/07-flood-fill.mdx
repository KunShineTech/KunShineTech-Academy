## 1. 一滴墨水的启示
把一滴墨水滴进清水里，墨水会顺着水纹向四面八方渗透，直到遇到边界或已经染黑的区域才停下——这就是**泛洪（flood fill）**：从一个起点出发，把「连得通的一片」全部标记出来。

网格图是最常见的舞台：每个格子是一个顶点，相邻格子之间有边。图的遍历（DFS/BFS）我们刚学过，泛洪就是它们在网格上的化身。

## 2. 四连通与八连通
「相邻」在网格里有两种定义：

- **四连通**：上、下、左、右四个方向，像 Manhattan 街区——斜对面的楼不算邻居。
- **八连通**：再加上四个对角方向，像国际象棋里王的一步。

题目不说时默认四连通；遇到「斜着也算连在一起」的题，才轮到八连通登场。

## 3. DFS 泛洪模板：数岛屿
地图由 n 行 m 列组成，`#` 是陆地，`.` 是海水，问有几座岛（上下左右相连的陆地算一座）？

```cpp
int n, m;
char g[505][505];
bool vis[505][505];

void fill(int x, int y) {
    if (x < 1 || x > n || y < 1 || y > m) return;  // 出界，停
    if (g[x][y] == '.' || vis[x][y]) return;       // 海水或已染色，停
    vis[x][y] = true;                              // 染黑这格
    fill(x + 1, y); fill(x - 1, y);                // 四连通扩散
    fill(x, y + 1); fill(x, y - 1);
}

int main() {
    // 读入地图……
    int islands = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (g[i][j] == '#' && !vis[i][j]) {
                islands++;      // 发现新大陆！
                fill(i, j);     // 把整座岛染掉
            }
    cout << islands << '\n';
}
```

外层双重循环负责「找还没被染色的陆地」，每发现一块就泛洪一次。泛洪次数，就是岛屿数量。这个「外层找新源 + 内部染一片」的结构，是所有连通块问题的通用骨架。

## 4. BFS 泛洪与染色应用
递归 DFS 在超大网格（如 5000×5000）下可能爆栈，这时把递归换成队列 BFS，逻辑一模一样：起点入队，每次取出一个格子，把合法的邻居入队。

泛洪还有两个常见变身：

- **染色标记**：不只数数量，还给每块连通区域编上不同编号（区域 1、区域 2……），方便后续查询「两个格子是否属于同一块」。
- **扩散模拟**：把 vis 换成 dist，记录「墨水染到每个格子用了几秒」，就是最短路在网格上的样子。

> 教学提醒：递归版泛洪一定要先把「出界判断」写在「访问格子」之前，顺序反了会数组越界。两个 if 的写法（先判出界、再判内容）是最稳妥的保险带。
