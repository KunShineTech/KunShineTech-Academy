## 1. 数学库：随身的科学计算器
以前算个平方根要写一堆循环，其实 C++ 早把常用数学运算打包好了。只要在文件开头加上头文件 cmath，就像手机里多了一个科学计算器 App：三角、对数、指数、幂次，随叫随到。

数学库函数有个共同脾气：**参数和返回值基本都是 double（双精度实数）**，传进去是小数，拿回来的也是小数。

```cpp
#include <iostream>
#include <cmath>
using namespace std;
int main(){
    cout << sqrt(2) << '\n';    // 1.41421...
    cout << fabs(-3.5) << '\n'; // 3.5
    cout << pow(2, 10) << '\n'; // 1024
}
```

## 2. 三角函数：sin、cos、tan
生活中量角用「度」，但数学库里用的是**弧度**。整个圆周 360° 对应 2π 弧度，所以换算公式是：弧度 = 角度 × π ÷ 180。口诀：**先转弧度，再进三角**。

```cpp
const double PI = 3.141592653589793;
cout << sin(PI / 2) << '\n';         // 90° 的正弦，输出 1
cout << cos(PI) << '\n';             // 180° 的余弦，输出 -1
double deg = 30;
cout << sin(deg * PI / 180) << '\n'; // 30° 的正弦，输出 0.5
```

> 教学提醒：学生最常犯的错误就是直接把角度丢进 sin——sin(30) 并不是 0.5，而是约 -0.988！看到三角函数题，第一反应应该是「单位是度还是弧度」。

## 3. 对数函数：log10、log2、log
对数是指数的逆运算，相当于给「指数爆炸」装上减速器：

- **log10(x)**：以 10 为底。地震里 8 级不是 4 级的两倍能量，而是 10⁴ 倍——这就是对数刻度。
- **log2(x)**：以 2 为底。log2(1024) = 10，因为 2 的 10 次方等于 1024。
- **log(x)**：以 e（约 2.718）为底的自然对数，别和 log10 搞混。

```cpp
cout << log10(1000) << '\n'; // 3
cout << log2(1024) << '\n';  // 10
```

两个实用技巧：**log2(n)** 回答「n 最多能折半几次」（二分查找就查这么多次）；**log10(n) 向下取整再加 1** 回答「n 有多少位」。

## 4. 指数函数：exp 与增长的速度
exp(x) 计算 e 的 x 次方，和 log 互为逆运算。指数增长有多可怕？e 的 20 次方已经超过 4 亿。复利的威力、谣言的传播、棋盘上的米粒，背后都是指数。

三条铁律：
1. 三角函数吃**弧度**。
2. 不带数字下标的 log 是**自然对数**，log10、log2 才指定底。
3. 数学库函数全是 double 运算，别和整数运算混着猜结果。
