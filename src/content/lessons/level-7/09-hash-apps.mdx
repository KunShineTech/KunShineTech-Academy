## 1. 哈希三大件：查存在、做计数、来去重
上一课我们造了哈希表这台「发动机」，这一课把它开到路上。绝大多数哈希应用都出自三个场景：

1. **快速查找**：「这个元素出现过吗？」——O(1) 回答，代替 O(n) 的逐个扫描。
2. **计数**：「每个元素出现了几次？」——哈希值直接当下标，cnt[x]++。
3. **去重**：「去掉重复只留一份」——查过了就不再收。

考场上不用每次都手写拉链法，C++ 的 STL 已经造好了成品：**unordered_set**（只存键）、**unordered_map**（键值对），底层就是哈希表，开箱即用。

```cpp
#include <unordered_map>
unordered_map<string, int> cnt;   // 字符串也能当「下标」！

string s;
while (cin >> s) cnt[s]++;        // 统计每种单词出现次数
```

## 2. 应用一：判定存在与去重
判重问题几乎是一套固定话术：

```cpp
unordered_set<int> seen;
for (int i = 1; i <= n; i++) {
    cin >> x;
    if (seen.count(x)) {          // 查存在，O(1)
        cout << "重复：" << x << '\n';
    } else {
        seen.insert(x);           // 登记入库
    }
}
```

以前判重要双重循环 O(n²)，1 万个数就要比较上亿次；哈希一来，1 秒跑完百万级数据。**当 n 到了 10⁵ 而你的算法还是 O(n²) 时，先想想哈希。**

## 3. 应用二：统计与配对
计数升级版：不只是「有没有」，还要「有几个」「和别的什么配成一对」。map 把任意类型映射到任意信息：

```cpp
unordered_map<long long, int> firstPos;  // 数值 -> 首次出现的位置
```

常见套路还有：统计频率后按频率排序找 Top-K；把「值」映射到「下标」实现快速反查；用 map 给离散的大数值重新编号（离散化思想）。

## 4. 应用三：字符串与 pair 哈希
哈希不限于整数。**字符串哈希**的思想：把字符串看成「大整数」（如把 "GESP" 视为 71×p³+69×p²+83×p+80），再取模压进表里——两个字符串哈希值相同，大概率内容相同。这是字符串匹配的利器（七级了解思想即可）。

**pair 哈希**：想按「(姓名, 科目)」两个字段一起查？把两个字段组合成一个整数键（如 a×大质数+b）再哈希。 unordered_map 甚至可以接受自定义哈希函数的 pair 键。

> 教学提醒：哈希速度快但有代价——unordered_set/map **不保证元素有序**。如果题目要求「按从小到大输出」或「找第 k 小」，请回头用 set/map（红黑树）或排序，别硬用哈希。
