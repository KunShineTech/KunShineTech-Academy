## 1. 图就在你身边——地铁图与朋友圈
打开地铁线路图：站点是**顶点（vertex）**，两站之间的线路是**边（edge）**——这就是一张图。朋友圈也是：每个人是顶点，好友关系是边。

两个基本分类要先分清：

- **无向图**：边是双向的，像双向马路、好友关系。「u 和 v 相邻」不分方向。
- **有向图**：边有箭头，像单行道、微博关注。「u 指向 v」不代表「v 指向 u」。

**度（degree）** 是一个顶点连出去的边数：无向图里就是边的条数；有向图拆成**出度**（指出去几条）和**入度**（被指几次）。

## 2. 邻接矩阵：一张 n×n 的表格
把每对顶点之间的关系填进二维表格：g[i][j] 表示顶点 i 到顶点 j 的边——无权图用 1 表示有边、0 表示没有；带权图存权值，没边存一个极大值 INF。

```cpp
int g[505][505];
int n, m; cin >> n >> m;      // n 个顶点，m 条边
for (int i = 0; i < m; i++) {
    int u, v; cin >> u >> v;
    g[u][v] = 1;
    g[v][u] = 1;              // 无向图：表格关于对角线对称
}
```

优点：查「i 和 j 之间有没有边」O(1) 搞定。缺点：就算只有几条边，也要开整个 n×n 的表——**空间 O(n²)**。n 到 5000 就要 100MB 了。所以它适合**点少、边多**的稠密图。

## 3. 邻接表：每个顶点的通讯录
稀疏图（点多边少，比如 10 万个点 20 万条边）用矩阵太浪费。换个思路：给每个顶点配一本通讯录，只存它真正相邻的点：

```cpp
vector<int> adj[100005];      // adj[u] 里全是 u 的邻居
for (int i = 0; i < m; i++) {
    int u, v; cin >> u >> v;
    adj[u].push_back(v);
    adj[v].push_back(u);      // 无向图双向登记
}
```

空间 O(n+m)，遍历 u 的所有邻居只需扫 adj[u]。**竞赛中最常用的就是它。**

口诀：**稠密图用矩阵，稀疏图用邻接表；不确定，就邻接表。**

> 教学提醒：无向图忘加反向边是图论入门的第一大坑——题目说「双向道路」「无向边」，就必须 push 两次。反过来，有向图只加一次，多加了反而错。

## 4. 读题建图：固定三步
拿到图论题，先找三样东西：

1. **顶点是什么？**（站点？城市？格子？）
2. **边是什么、有没有方向？**（线路？道路？规则转移？）
3. **边带不带权？**

然后按输入格式读 n、m，循环 m 次读边、存边。顶点编号从 0 还是从 1 开始，以题目为准，别想当然。
