## 1. 从「一条线」到「一张表」
六级我们学了一维 DP：状态排成一条线，像数楼梯一样一步一步推。可很多问题天生带着两个下标——第几行、第几列；左端点、右端点。这时一维数组就不够住了，要请出**二维 DP**：把状态想象成教室的座位表，f[i][j] 就是第 i 排第 j 列那个座位上的答案。

判断要不要升维，问自己一句：**描述「做到哪里了」需要一个数还是两个数？**

## 2. 例题：数字三角形
经典问题：一个数字三角形，从顶点出发，每步向左下或右下走，走到最底层，求路径上数字之和的最大值。

```
    7
   3 8
  8 1 0
 2 7 4 4
```

设计状态：**f[i][j] 表示从顶点走到第 i 行第 j 个数时能获得的最大和**。站在 (i, j) 这个位置，你只有两个「前任」：左上 (i-1, j-1) 和右上 (i-1, j)，转移方程：

**f[i][j] = a[i][j] + max(f[i-1][j-1], f[i-1][j])**

```cpp
int a[105][105], f[105][105];
int n; cin >> n;
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= i; j++) cin >> a[i][j];
f[1][1] = a[1][1];
for (int i = 2; i <= n; i++)
    for (int j = 1; j <= i; j++)
        f[i][j] = a[i][j] + max(f[i-1][j-1], f[i-1][j]);
int ans = 0;
for (int j = 1; j <= n; j++) ans = max(ans, f[n][j]);
```

> 教学提醒：把下标从 1 开始用是本题的偷懒小技巧——f[i-1][0] 和 f[i-1][i] 自动等于 0，每行两端的边界情况不用特判。二维 DP 初始化全为 0 时尤其要留意「这个 0 是合法初值还是漏算了」。

## 3. 例题：网格路径计数
快递车从仓库（左上角）出发给客户（右下角）送货，只能向右或向下开，问一共有多少种走法。

状态：**f[i][j] 表示走到格子 (i, j) 的方案数**。到达 (i, j) 只有两辆车：从上面来的、从左面来的，所以：

**f[i][j] = f[i-1][j] + f[i][j-1]**，第一行和第一列只有一条走法，全部填 1。

```cpp
int f[35][35] = {0};
int n, m; cin >> n >> m;
for (int i = 1; i <= n; i++) f[i][1] = 1;
for (int j = 1; j <= m; j++) f[1][j] = 1;
for (int i = 2; i <= n; i++)
    for (int j = 2; j <= m; j++)
        f[i][j] = f[i-1][j] + f[i][j-1];
cout << f[n][m] << '\n';
```

3×3 的网格答案是多少？6。数出来：右右下、右下右、下右右……一共 6 种，和表格最后一格对得上。

## 4. 区间 DP：合并石子的最小代价
地上摆着 n 堆石子，每次只能合并相邻的两堆，代价是两堆石子数之和，问全部合并成一堆的最小总代价。

状态：**f[i][j] 表示把第 i 到第 j 堆合并成一堆的最小代价**。想象最后一次合并：左边是 i..k 这团，右边是 k+1..j 这团，最后一刀切在哪？枚举分割点 k：

**f[i][j] = min(f[i][k] + f[k+1][j]) + (i..j 的石子总数)**，其中 i ≤ k ＜ j

```cpp
for (int len = 2; len <= n; len++)           // 先枚举区间长度
    for (int i = 1; i + len - 1 <= n; i++) { // 再枚举左端点
        int j = i + len - 1;
        f[i][j] = 1e9;
        for (int k = i; k < j; k++)          // 最后枚举分割点
            f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + s[j] - s[i-1]);
    }
```

口诀：**先短后长，先左后右，中间枚举分割点**。其中 s 是前缀和数组，s[j]-s[i-1] 一口气算出 i..j 的石子总数。
