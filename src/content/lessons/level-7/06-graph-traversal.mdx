## 1. 两种逛校园的方式
新学期逛校园，有两种走法：

- **DFS（深度优先搜索）**：认准一条路走到底，撞墙了才退回上一个路口换方向——像个独来独往的探险家。
- **BFS（广度优先搜索）**：从校门出发，先把周围 100 米逛完，再逛 200 米，一圈一圈向外扩散——像广播找人，消息按「离起点由近到远」传开。

两种方式都能**不重复、不遗漏**地走遍整张图，靠的都是同一个法宝：**访问标记**。visited[u] 记录「u 已经逛过了」，每个顶点只处理一次。

## 2. DFS：递归实现
```cpp
vector<int> adj[100005];
bool vis[100005];

void dfs(int u) {
    vis[u] = true;                  // 进门先打卡
    for (int v : adj[u])            // 逐个看望邻居
        if (!vis[v]) dfs(v);        // 没去过就深入
}
```

从起点调用 dfs(起点)，整张连通区域就被走遍了。递归天然携带「路径栈」：函数一层层压栈，正是一路走到底、回头退栈的过程。

## 3. BFS：队列实现
```cpp
void bfs(int s) {
    queue<int> q;
    q.push(s); vis[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop(); // 处理当前层
        for (int v : adj[u])
            if (!vis[v]) {          // 新发现的邻居
                vis[v] = true;
                q.push(v);          // 排入下一层
            }
    }
}
```

队列保证**先进先出**：先被发现的顶点先扩展，所以顶点被访问的顺序恰好是它们到起点的距离从近到远。这一点是金矿——**BFS 的分层数就是无权图的最短路**（每条边算一步）。

## 4. 什么时候用哪个？
- **判可达、数连通块、拓扑前的探路**：DFS、BFS 都行，DFS 代码更短。
- **求最少步数/最少换乘/最短路径（边无权）**：必须用 BFS，因为它按层扩散，第一次到达就是最近。
- **要走遍所有方案、回溯剪枝类问题**：DFS 更顺手（七级之后的级别会更常用）。

> 教学提醒：BFS 入队时就打标记 vis[v]=true，而不是出队时才打！否则同一个顶点可能被重复入队好多次，队列膨胀、时间翻倍。这是 BFS 最常见的实现错误。
