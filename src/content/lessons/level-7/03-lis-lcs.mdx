## 1. 子序列：按顺序「挑人」，不要求挨着
全班同学排成一列拍照，老师想挑出一些人组成一个「身高越来越高」的小队，但挑的人**不用相邻**——这就是子序列。形式化地说：子序列是从原序列中按原有顺序选出若干元素（可以不连续）组成的新序列。

注意区分：**子串（子数组）必须连续，子序列只要保序**。「algorithm」的子序列可以是「agt」，但「agr」不是（顺序乱了）。

## 2. LIS：最长上升子序列
给定序列，求最长的、严格上升的子序列长度。例如 3 1 4 1 5 9 2 6 的 LIS 是 1 4 5 9，长度为 4。

设计状态（关键一步）：**f[i] 表示以 a[i] 结尾的最长上升子序列的长度**。为什么要「以 i 结尾」？因为只有这样，转移才有据可依：在 i 之前，所有比 a[i] 小的 a[j] 都可以接在 a[i] 前面。

**f[i] = max(f[j] + 1)**，要求 j ＜ i 且 a[j] ＜ a[i]；什么都不接时 f[i] 至少是 1。

```cpp
for (int i = 1; i <= n; i++) {
    f[i] = 1;                       // 至少是自己一个人
    for (int j = 1; j < i; j++)
        if (a[j] < a[i])
            f[i] = max(f[i], f[j] + 1);
}
int ans = 0;
for (int i = 1; i <= n; i++) ans = max(ans, f[i]);
```

口诀：**「以自己结尾，前面接更矮的」**。

> 教学提醒：最常见的错误是直接输出 f[n]。LIS 不一定以最后一个元素结尾——序列 2 5 1 的 LIS 是 2（2,5），而 f[3]=1。答案一定是把所有 f[i] 扫一遍取最大值。

## 3. LCS：最长公共子序列
给你两份课堂笔记（两个序列或字符串），找出它们**共同保留**的最长内容，顺序都不能变。例如 「ABCBDAB」和「BDCABA」的 LCS 是 「BCBA」，长度为 4。

设计状态：**f[i][j] 表示 a 的前 i 个元素与 b 的前 j 个元素的 LCS 长度**。盯着 a 的第 i 个元素和 b 的第 j 个元素看：

- 如果 **a[i] == b[j]**：太好了，这一对可以一起进 LCS，**f[i][j] = f[i-1][j-1] + 1**。
- 如果不等：这一对至少有一个用不上，**f[i][j] = max(f[i-1][j], f[i][j-1])**。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        if (a[i] == b[j]) f[i][j] = f[i-1][j-1] + 1;
        else f[i][j] = max(f[i-1][j], f[i][j-1]);
```

整张表像 filling 一个 n×m 的棋盘：相等走对角线 +1，不等取上方和左方的较大值。全部初始为 0，天然处理了「前 0 个元素」的边界。

## 4. 手算一格，心里才有底
拿 s1 = 「ABC」、s2 = 「AC」 手动填表：

| | 空 | A | C |
|---|---|---|---|
| 空 | 0 | 0 | 0 |
| A | 0 | **1** | 1 |
| B | 0 | 1 | 1 |
| C | 0 | 1 | **2** |

右下角 2，对应 LCS「AC」。对角线 +1 只发生在字符相等的位置，方向感一下子就出来了。
