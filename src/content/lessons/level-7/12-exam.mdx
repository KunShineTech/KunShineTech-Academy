## 1. 考点串讲：四张知识地图
**数学库**：cmath 头文件提供三角、对数、指数函数。铁律：三角函数吃**弧度**（角度 × π ÷ 180）；log10 以 10 为底、log2 以 2 为底、不带下标的 log 是自然对数；exp(x) 计算 e 的 x 次方；函数参数与返回值都是 double。

**复杂动态规划**：二维 DP（数字三角形 f[i][j]=a[i][j]+max(左上,右上)；网格路径 f[i][j]=上+左）；区间 DP（合并石子：先枚举长度、再左端点、最后分割点）；LIS（f[i] 表示以 i 结尾，前面接更矮的，答案取全局 max）；LCS（相等取对角加一，不等取上左较大）；空间优化用滚动数组，0-1 背包一维化要**倒序**。

**图论**：图由顶点与边组成，分有向图与无向图，度描述顶点的连接数。存储用邻接矩阵（稠密图）或邻接表（稀疏图，首选）。DFS 一路走到底再回头，BFS 按层扩散且**层数就是无权最短路**；泛洪是遍历在网格上的化身，先判出界再判内容，外层找新源、内部染一片。

**哈希表**：哈希函数把内容映射成地址，实现平均 O(1) 的查找、插入、删除；冲突不可避免，用拉链法或开放寻址处理；竞赛中常用 unordered_set/unordered_map 解决判存在、计数、去重，但**哈希不保证有序**。

## 3. 模拟编程题二：括号序列（动态规划）
> 教学提醒：区间类 DP（合并石子、括号匹配）必须按「区间长度从小到大」递推，否则转移时用到的子区间还是未计算的垃圾值；初始化也别漏 f[i][i] 这样的单点边界。

<Task title="括号序列（测评题）" input="一行仅由 ( 和 ) 组成的字符串 s（长度 n≤300）" output="最少添加多少个括号，能使 s 变成合法的括号序列" sampleIn="(()" sampleOut="1">样例 (() 只需在前面加一个 ( 变成 (())。想：s 的哪一段本身就合法？这段越长，要补的越少。</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\n#include <string>\nusing namespace std;\nint f[305][305]; // s[i..j] 需要添加的最少括号数\nint main(){\n    string s;\n    cin>>s;\n    int n=s.size();\n    for(int i=0;i<n;i++) f[i][i]=1;\n    for(int len=2;len<=n;len++)\n        for(int i=0;i+len-1<n;i++){\n            int j=i+len-1;\n            f[i][j]=1e9;\n            for(int k=i;k<j;k++)\n                f[i][j]=min(f[i][j],f[i][k]+f[k+1][j]);\n            if(s[i]=='('&&s[j]==')')\n                f[i][j]=min(f[i][j],f[i+1][j-1]);\n        }\n    cout<<f[0][n-1]<<'\\n';\n}`}</code></pre>区间 DP：f[i][j] 表示让 s[i..j] 合法最少要补几个。两种情况取小：切成两段各自补（枚举分割点 k）；或首尾正好配对，那只需把中间补合法（注意 i+1>j-1 时中间为空，f 值为 0，所以该转移会给出 0）。样例 (()：f[0][2] 由 s[0]='(' 与 s[2]=')' 配对，取 f[1][1]=1，答案 1。这也说明：能匹配的对数越多，补得越少。</Reveal>

## 4. 考试须知
1. **时间分配**：180 分钟里，选择判断控制在 60 分钟内，编程题留足 70 分钟以上，最后 20 分钟回头检查。
2. **先框架后细节**：头文件、main、读入输出先写好跑通样例，再写核心算法——避免「写完发现读错输入」的惨剧。
3. **样例必测**：提交前把题目样例原样输入核对，包括空格、换行与大小写。
4. **边界自查**：数组开够（n≤1000 开 1005）？区间 DP 初值（f[i][i]=1）写了没？负数取模修正了吗？long long 该用用了吗？
5. **建模优先**：看到题先想「这是学过的哪个模型」——最长公共、最短路、连通块、判存在，七级题大多是旧模型换新衣裳。
