## 1. DP 的「房租」问题
二维 DP 好写，但代价是空间：f[1005][1005] 的 int 数组约 4MB，f[5005][5005] 就飙到 100MB，直接爆内存。类比搬家：如果新家的家具只和旧家的**一个房间**有关，何必整栋租下来？**滚动数组**就是每次只保留需要的那几行（甚至几个变量）。

先问自己：计算第 i 行时，到底回头看几行？只看一行，就滚一行；只看两个数，就留两个数。

## 2. 滚动数组：斐波那契的最省写法
斐波那契数列：f[i] = f[i-1] + f[i-2]。仔细看看——算 f[i] 时，f[i-3] 及更早的数还用吗？不用了！于是整个数组合租成两个变量：

```cpp
long long a = 1, b = 1;          // f[1], f[2]
for (int i = 3; i <= n; i++) {
    long long c = (a + b) % 1000000007;
    a = b; b = c;                // 轮流搬家
}
```

空间从 O(n) 降到 O(1)，这就是滚动的思想：**算完就扔，只留接力棒**。

## 3. 0-1 背包一维化：为什么必须倒序
0-1 背包：n 件物品，容量 V，第 i 件体积 w[i]、价值 v[i]，每件最多选一次，求最大总价值。二维状态 f[i][j] 表示「前 i 件物品、容量 j」的最大价值：

**f[i][j] = max(f[i-1][j], f[i-1][j-w[i]] + v[i])**（不选 i，或选 i）

发现没有？第 i 行只依赖第 i-1 行——可以滚！把第一维删掉，直接用 f[j] 表示「当前容量 j 的最优值」。但有个坑：**j 必须从大到小倒序枚举**。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = V; j >= w[i]; j--)   // 倒序！
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```

为什么？正序时，f[j-w[i]] 在本轮已经被物品 i **更新过了**——相当于物品 i 被用了两次，0-1 背包就变成完全背包了。倒序保证你读到的永远是「还没见过物品 i」的旧值。

> 教学提醒：背不下原理没关系，记住口诀「**0-1 倒序，完全正序**」。考场上先写对，再回头理解。

## 4. 最值优化：让内层 max 更聪明
有时慢的不是空间而是时间。两个常用优化思路：

1. **预处理最值**：如果转移要查「前面所有 f[j] 的最大值」，可以边算边维护一个 running max（前缀最值），把内层 max 变成 O(1)。
2. **二分优化 LIS**：LIS 的 O(n²) 可以进一步优化到 O(n log n)——维护一个数组 d，d[k] 表示「长度为 k 的上升子序列的最小结尾」，它一定是单调的，每次用二分查找插入位置。七级了解思想即可，记住结论：**LIS 有 O(n log n) 的做法**。

核心思想一句话：**DP 优化不是玄学，是找出计算中的浪费——存了不用的、算了重样的，然后把它砍掉。**
