## 1. 旅行装箱的烦恼
暑假去旅行，背包最多装 W 千克。桌上有 n 件物品，第 i 件重 w[i] 千克、价值 v[i] 元。**每件物品最多选一次**，怎么装才能让包里总价值最大？这就是著名的 **0-1 背包问题**——「0-1」表示每件物品要么拿（1）、要么不拿（0），不能只拿半件。

注意它和贪心的区别：如果按「单位重量价值」从高到低贪心拿，某些数据上会翻车（比如背包容量 10，有重量 6 价值 8、重量 5 价值 5、重量 5 价值 5 三件物品，贪心先拿第一件就装不下后两件了，总价值 8，不如拿后两件得 10）。**背包必须用 DP**。

## 2. 状态设计：前 i 件、容量 j
设 `f[i][j]` 表示：**只考虑前 i 件物品，在容量不超过 j 时能获得的最大价值**。考虑第 i 件物品时，只有两种选择：

- **不拿**：问题退化为前 i-1 件、容量 j，价值 `f[i-1][j]`；
- **拿**（前提是 j 不小于 w[i]）：先腾出 w[i] 的容量放它，剩下容量 j-w[i] 用前 i-1 件尽量装满，价值 `f[i-1][j-w[i]] + v[i]`。

**转移方程**：
```
f[i][j] = max( 不拿: f[i-1][j],
               拿:   f[i-1][j-w[i]] + v[i] )   仅当 j >= w[i]
```
**边界**：`f[0][j] = 0`（没有物品可选，价值为 0）。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 0; j <= W; j++) {
        f[i][j] = f[i-1][j];                    // 不拿
        if (j >= w[i])
            f[i][j] = max(f[i][j], f[i-1][j-w[i]] + v[i]);   // 拿
    }
cout << f[n][W] << '\n';
```

## 3. 滚动数组：压成一维
观察转移方程：`f[i][...]` 只依赖 `f[i-1][...]`—— older 行。干脆只用一行数组，**原地滚动更新**：

```cpp
for (int i = 1; i <= n; i++)
    for (int j = W; j >= w[i]; j--)      // 关键：容量倒序！
        f[j] = max(f[j], f[j-w[i]] + v[i]);
```

为什么要**倒序**？正序更新时，`f[j-w[i]]` 在本轮（第 i 件）**已经被更新过**，相当于第 i 件已经进过一次包，再拿就是重复拿——悄悄变成了完全背包。倒序从大容量往小更新，读到的 `f[j-w[i]]` 还是上一轮的旧值，保证每件物品只被选一次。**「0-1 背包容量倒序、完全背包容量正序」是必背口诀**。

> 教学提醒：让学生打印二维 f 表（n、W 都取小值如 3 和 5），先按转移方程手工填表，再和程序输出对照。手填一遍二维表的学生，几乎不会再搞混倒序循环的原因。

## 5. 课后巩固
1. 概念题：用自己的话解释「0-1 背包」中「0-1」的含义，并举一个不能拆分的现实例子。
2. 手算题：n=3、W=7，物品为 (3,4)、(4,5)、(2,3)，手工填写二维 f 表并给出最优值。
3. 编程题：用二维写法实现 0-1 背包，并和一维写法对拍验证（随机小数据比较输出）。
4. 思考题：为什么一维写法中 j 的循环可以只到 w[i] 就停（即 j 从 W 到 w[i]），而不是一路降到 0？
5. 挑战题：改造程序，在求出最大价值的同时，输出选择了哪些物品（提示：用二维表倒推，或额外记录决策）。
