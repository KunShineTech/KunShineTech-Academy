## 1. 走迷宫的人
想象你在迷宫里找出口，策略是：**随便选一条路往前走，能走就走；走到死胡同就退回上一个岔路口，换另一条没试过的路**。这种「不撞南墙不回头」的走法，就是**深度优先搜索（DFS，Depth-First Search）**——它沿着一条路径尽可能往深处钻，钻不通才回头。

对比生活场景：你在图书馆找一本「讲恐龙的书」，DFS 的做法是冲进一个书架，从最上层翻到最下层，翻完整个书架再换下一个——**先深挖，再横向**。

## 2. DFS 万能框架
DFS 的代码骨架惊人的统一，记住这个「四步走」：

```cpp
void dfs(当前状态) {
    if (到达终点) { 记录答案; return; }   // 1. 边界：走投无路或任务完成
    标记当前状态为「已访问」;              // 2. 做选择（上锁）
    for (每个可以走的下一步) {
        if (下一步合法且未访问)
            dfs(下一步);                 // 3. 深入
    }
    撤销标记;                            // 4. 回溯（解锁），恢复原状
}
```

第 2 步和第 4 步合称**回溯**：下去之前做个记号，回来擦掉记号，保证别的路线能正常使用这个状态。**漏写「撤销标记」是初学者最常见的 bug**——就像借书不还书签，后面的同学再也借不到那本书了。

> 教学提醒：第 1 级我们就学过递归（函数调用自己），DFS 只是递归的一个「著名角色」。让学生先徒手模拟 n=3 的全排列过程，再写代码，比直接背模板效果好得多。

## 3. 例题一：输出全排列
把 1~n 这 n 张不同的卡片排成一排，共有多少种排法？每种排法是什么？

用 DFS 逐位确定：第 1 位放谁？枚举 1~n 中没用过的数放上去，然后递归确定第 2 位……直到 n 位都放满就输出。

```cpp
#include <iostream>
using namespace std;
int n, a[10];
bool used[10];                    // used[i]：数字 i 是否已用
void dfs(int pos) {               // 正在填第 pos 位
    if (pos > n) {                // 边界：填满了
        for (int i = 1; i <= n; i++) cout << a[i] << ' ';
        cout << '\n';
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;    // 用过了就跳过
        a[pos] = i;               // 做选择
        used[i] = true;           // 标记
        dfs(pos + 1);             // 深入下一位
        used[i] = false;          // 回溯：撤销标记
    }
}
int main() { cin >> n; dfs(1); }
```

n=3 时输出 6 行排列，和数学课「3 的阶乘」答案一致——**搜索不仅找答案，还能完成枚举计数**。

## 4. 例题二：数连通块
迷宫地图上有些是墙、有些是空地，**几块互不相连的空地**就是几个连通块。用 DFS 扫一遍地图：每发现一个没访问过的空地，就从它出发把整片连通区域「染成同一个编号」，然后连通块计数加一。每个格子只被染色一次，总复杂度是格子数级别，非常快。

这其实就是「走迷宫」框架的直接应用：**每次 dfs 负责把一块地全部走完，主循环负责数数**。

## 6. 课后巩固
1. 概念题：用一句话概括 DFS 的搜索策略，并举一个生活中的类比。
2. 模拟题：徒手画出 n=2 时全排列 DFS 的递归调用树，标出每次「做选择」和「回溯」。
3. 编程题：修改迷宫程序，输出从入口到出口的一条路径（输出经过的坐标序列）。
4. 思考题：如果迷宫很大（n、m 达到 1000），递归 DFS 可能遇到栈溢出，你能想到什么替代办法？（提示：自己用一个数组模拟「待走路口」的栈。）
5. 挑战题：用 DFS 统计 n×m 地图中空地的连通块个数，并输出最大的一块有多少格。
