## 1. 洗碗与排队：两种生活秩序
- **栈（stack）**：一摞洗好的盘子，**后放上去的盘子先被拿走**——后进先出（LIFO）。浏览器「后退」、Word「撤销」、函数调用的返回地址，全是栈在撑腰。
- **队列（queue）**：食堂打饭排队，**先来的先打**——先进先出（FIFO）。打印任务排队、BFS 的待访问清单（第 6 课刚用过！）、客服热线排队，都是队列。

一句话区分：**栈像电梯（后进的先到顶），队列像传送带（先进先出）**。记住这句，选择题稳拿分。

## 2. STL 开箱即用
```cpp
#include <stack>
#include <queue>
using namespace std;
stack<int> st;          // 栈
st.push(5);             // 入栈
st.top();               // 看栈顶
st.pop();               // 弹出栈顶（注意 pop 没有返回值！）
st.empty();             // 是否为空
st.size();              // 元素个数

queue<int> q;           // 队列
q.push(5); q.front(); q.back(); q.pop(); q.empty();
```

> 教学提醒：两个高频小坑——`st.pop()` 只删不返，想拿到栈顶元素要先用 `top()` 再 `pop()`；对空栈调用 top/pop 是未定义行为，操作前先用 `empty()` 检查。越界访问的教训从数组课讲到这里，一脉相承。

## 3. 经典应用：括号匹配
检查 `(()())` 这样的括号串是否合法，是栈的成名之战。规则：遇左括号入栈，遇右括号就让栈顶左括号出栈配对；**最后栈空则全部配对成功**。核心洞察：后出现的左括号要先被配对——「后进先出」恰好就是括号的需求。

## 4. 循环队列：数组省着用
普通队列用数组实现时，不断入队出队，队头指针一路向右，**前面的空位再也用不上**，数组很快「假溢出」。**循环队列**把数组首尾相接成环（像环形跑道），指针走到数组末尾就跳回开头，用取模实现：

```
入队：q[tail] = x;  tail = (tail + 1) % M;
出队：head = (head + 1) % M;
队空：head == tail
队满：(tail + 1) % M == head   ← 故意留一个空位，否则队空队满无法区分
```

三条铁律：
1. **取模**让下标在数组里「转圈」，是循环的灵魂。
2. **故意浪费一个格子**：若不留空位，「head==tail」既表示空也表示满，真假难辨。
3. 队列元素个数 = (tail - head + M) % M。
