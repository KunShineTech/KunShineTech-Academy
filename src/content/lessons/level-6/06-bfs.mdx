## 1. 从传纸条到水波纹
上课想借块橡皮，DFS 是把纸条一个人一个人往深处传；而 BFS 的做法是：**你同时问左右同桌，同桌再同时问他们的同桌**——像水面扔进石子的涟漪，一圈一圈向外扩散。这就是**广度优先搜索（BFS，Breadth-First Search）**，也叫宽度优先搜索。

BFS 有一个 DFS 比不了的超能力：**第一次到达某个状态时，走过的步数一定是最少的**。涟漪先扫到的地方必然离中心最近——所以**求「最少步数」「最短距离」类问题，首选 BFS**。

## 2. 队列：BFS 的好搭档
BFS 怎么做到「一圈一圈」？答案是**队列**（第 10 课会细讲）：把待处理的结点排成一队，处理队头时把它的新邻居按顺序排到队尾。先进先出，保证**离起点近的永远先被处理**。

框架背下来：
```cpp
队列 q;
q.push(起点); dist[起点] = 0;
while (q 不空) {
    取出队头 u，出队;
    for (u 的每个邻居 v)
        if (v 没访问过) {
            dist[v] = dist[u] + 1;   // 比 u 远一步
            q.push(v);
        }
}
```

## 3. 例题：迷宫最短路
上一课用 DFS 判断迷宫「有没有出路」，如果还要问「最少走几步」，DFS 要枚举所有路径再比大小，而 BFS 天然一步到位：第一圈扩散到距离 1 的格子，第二圈距离 2……**第一次碰到出口时，当时的距离就是答案**。

```cpp
#include <iostream>
#include <queue>
using namespace std;
char g[25][25];
int dist[25][25], n, m;
int dx[4] = {-1, 1, 0, 0}, dy[4] = {0, 0, -1, 1};
int bfs() {
    queue<int> qx, qy;
    qx.push(1); qy.push(1); dist[1][1] = 0;
    while (!qx.empty()) {
        int x = qx.front(), y = qy.front();
        qx.pop(); qy.pop();
        if (x == n && y == m) return dist[x][y];
        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx >= 1 && nx <= n && ny >= 1 && ny <= m
                && g[nx][ny] == '.' && dist[nx][ny] == -1) {
                dist[nx][ny] = dist[x][y] + 1;
                qx.push(nx); qy.push(ny);
            }
        }
    }
    return -1;   // 到不了
}
```
dist 数组初始化为 -1，一箭双雕：既表示「未访问」，又能存距离。

## 4. 二叉树的层序遍历
BFS 在树上叫**层序遍历**：从上到下、从左到右逐层访问。用队列实现，出队一个结点就把它的左右孩子排进队尾：

```cpp
void level(int root) {
    queue<int> q;
    q.push(root);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << val[u] << ' ';
        if (lc[u]) q.push(lc[u]);
        if (rc[u]) q.push(rc[u]);
    }
}
```
想想队列里的变化：根先进队；根出队时它的两个孩子入队；左孩子出队时孙子入队……完美复刻「一层一层」的访问顺序。给完全二叉树（数组存储）做层序遍历更简单：**直接从下标 1 循环输出到 n 就是层序序列**。

> 教学提醒：层序遍历是「BFS + 队列」最经典的练习题，务必让学生徒手模拟一遍队列的入队出队过程，理解「为什么队列天然保证了分层」。讲透这一点，后面二叉树搜索、最短路的题都能迁移。

## 6. DFS 还是 BFS？选型口诀
- **问「能不能到」「所有方案」「连通块」** → DFS，代码短，回溯顺手。
- **问「最少步数」「最短距离」「第几层」** → BFS，队列一圈圈扩散，天然最优。
- 空间上 DFS 只存一条路径（省内存），BFS 要把整圈存进队列（费内存）。**时间都是每个状态处理一次**，选谁主要看题目问什么。
