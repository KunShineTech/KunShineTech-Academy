## 1. 从家谱认识树
「爷爷有三个孩子：大伯、爸爸和小姑；爸爸又有两个孩子：我和妹妹……」——画出家谱图，你会得到一棵倒着长的树：**最上面一位是根，往下不断分叉，最底下一层不再分叉的人就是叶子**。

在计算机里，**树**是 n 个结点的有限集合。当 n 大于 0 时，它有一个特殊的**根结点**，其余结点被分成若干棵互不相交的子树，每棵子树又是一棵树。注意这个定义里出现了「树」，这叫做**递归定义**——树的每一棵子树，本身也是一棵小树。

老师常问：「为什么计算机科学家喜欢树？」因为现实世界里到处都是树：公司组织架构、图书目录、电脑里的文件夹、比赛的对阵表……它们共同的特点是：**一个上级可以有多个下级，但每个下级只有一个直接上级**。

## 2. 基本术语：一根、二度、三层
先把名词认全（对照家谱记忆）：

- **根**：最顶上的结点，全家只有一位老祖宗。
- **父结点与子结点**：直接相连的一对，上面的叫父，下面的叫子。
- **叶子（终端结点）**：没有孩子的结点，家谱里就是还没当爸妈的人。
- **结点的度**：孩子的个数。树的度是整棵树里最大的结点度。
- **层**：根在第 1 层，孩子层数比父亲多 1。
- **深度（高度）**：树中结点的最大层数，也就是家谱「传了几代人」。
- **祖先与子孙**：从某结点一路往上能走到的，都是它的祖先。

三条铁律：
1. 树有 **n 个结点，恰好有 n-1 条边**（每个孩子连一条到父亲的线）。
2. 树中任意两个结点之间**有且只有一条路径**（家谱中两人必能找到共同祖先）。
3. 树**没有环**——不会出现「A 是 B 的祖先，B 又是 A 的祖先」这种乱套关系。

> 教学提醒：判断一个图是不是树，最方便的两把尺子是「连通」加「边数等于结点数减一」。n 个点只有 n-2 条边会断成两族（不连通），有 n 条边就会出现「近亲结婚」式的环。

## 3. 树的存储：邻接表
树怎么放进数组？最常用的办法是**邻接表**：开一个数组，第 u 个位置挂一个「名单」，名单里存 u 的所有孩子。

```cpp
#include <iostream>
#include <vector>
using namespace std;
vector<int> child[105];   // child[u] 存 u 的所有孩子
int main() {
    int n;
    cin >> n;                        // n 个结点
    for (int i = 1; i < n; i++) {    // 恰好 n-1 条边
        int u, v;
        cin >> u >> v;               // u 是 v 的父亲
        child[u].push_back(v);
    }
    // child[1] = {2, 3} 表示 1 号结点的孩子是 2 和 3
}
```

读一棵树的标准开头：先读 n，再循环 n-1 次读入「父 子」关系。**循环写 i 小于 n 而不是小于等于 n**，这个边界和第 3 级数组课的「读 n 个数」是一个道理，写错就会读错边。

## 4. 二叉树：最多两个孩子
有一种树在竞赛中最常用——**二叉树**：每个结点**最多**有两个孩子，分别叫左孩子和右孩子。像「左膀右臂」，分左右、讲顺序，交换左右会得到一棵不同的二叉树。

两类重要的特殊二叉树先混个脸熟，第 3 课专门研究它们：

- **满二叉树**：每一层结点都排满，像金字塔。
- **完全二叉树**：从上到下、从左到右依次排满，最后一层靠左站。它可以用一个数组直接编号存放，有漂亮的编号规律。
