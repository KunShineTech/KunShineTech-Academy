## 1. 综合题的拆解心法
考场上遇到大题，别急着敲键盘，先在草稿纸上走五步：
1. **读题圈关键词**：是「树」「最少步数」「最大价值」还是「括号配对」？
2. **建模**：把现实描述翻译成学过的模型——家谱 → 树；一圈圈扩散 → BFS；接不接上一段 → 一维 DP。
3. **选型**：这个模型配哪个工具？树遍历用递归，最短路用队列，背包用滚动数组。
4. **编码**：先写输入输出框架，再填核心逻辑。
5. **自测**：拿样例手算一遍，再敲进程序对拍，边界数据（n=1、全负数、空栈）各来一组。

本课三道大题分别串联「树 + 搜索」「一维 DP」「栈的应用」，都是六级真题的常驻组合。

> 教学提醒：综合课最忌「听懂了就是会了」。三道题务必让学生先独立限时完成（每题 20 分钟）再讲评，讲评时先让做对的学生说思路，老师只做点评和补充。

## 3. 题二：条形蛋糕（一维 DP）
<Task title="条形蛋糕" input="第一行正整数 n（n≤1000），第二行 n 个整数 a[i]（-1000≤a[i]≤1000），表示每块蛋糕的美味值（可为负）" output="选择连续的一段蛋糕，输出能获得的最大美味值总和" sampleIn="6
1 -2 3 5 -1 2" sampleOut="9">回忆第 7 课的最大连续和：f = max(a[i], f + a[i])，边算边记录历史最优。先用手填 DP 表验证样例，再写代码。</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\nusing namespace std;\nint main(){\n    int n; cin>>n;\n    long long x, f, best;\n    cin>>x; f = best = x;          // 边界：第一段必选\n    for(int i = 2; i <= n; i++){\n        cin>>x;\n        f = max(x, f + x);         // 接前面的段，或自己单开\n        best = max(best, f);\n    }\n    cout<<best<<'\\n';\n}`}</code></pre>这是「最大连续和」的在线写法：边读边算，O(n) 时间、O(1) 额外空间。样例手算：f 依次为 1、-1、3、8、7、9，best = 9（选第 3~6 块：3+5-1+2=9）。注意边界：初值 f = best = 第一个数，保证全负数数据也能得到正确答案（如 -5 -2 → 答案是 -2 而不是 0）。</Reveal>

## 4. 题三：车厢调度（栈）
<Task title="车厢调度" input="第一行正整数 n（n≤1000），第二行 1~n 的一个排列，表示车厢进入调度站的顺序" output="调度站是一条单方向的栈：车厢只能按后进先出出站。问能否通过调度得到顺序 1, 2, ..., n 出站（即第 1 节出站的必须是编号 1，第二必须是 2，以此类推）。能输出 YES，不能输出 NO" sampleIn="3
2 1 3" sampleOut="YES">模拟：按给定顺序逐节把车厢推进栈；每推进一节后，只要栈顶正好是「当前应该出站」的编号，就立刻让它出站。结束时若全部按 1..n 出站则 YES。再用「3 1 2」想想为什么会失败。</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\n#include <stack>\nusing namespace std;\nint main(){\n    int n; cin>>n;\n    stack<int> st;\n    int nxt = 1;                    // 当前等待出站的车厢号\n    bool ok = true;\n    for(int i = 1; i <= n; i++){\n        int x; cin>>x;\n        st.push(x);\n        while(!st.empty() && st.top() == nxt){\n            st.pop();\n            nxt++;\n        }\n    }\n    cout<<((nxt == n+1) ? "YES" : "NO")<<'\\n';\n}`}</code></pre>nxt 表示「现在轮到几号出站」。每进一节车厢就反复检查栈顶：是 nxt 就弹出并让 nxt 加一。读完所有车厢后，若 nxt 到达 n+1 说明 1..n 全部顺次出站。样例：进站 2,1,3。2 进栈，栈顶 2≠1，停住；1 进栈，栈顶 1=nxt 弹出，nxt=2，栈顶 2=nxt 再弹出，nxt=3；3 进栈后栈顶 3=nxt 弹出，nxt=4=n+1，输出 YES。再想一个失败的数据「2 3 1」：2 入栈（≠1），3 入栈（≠1），1 入栈后栈顶 1 弹出，nxt=2，此时栈顶是 3 卡住——2 被压在 3 下面永远出不来，输出 NO。请用 2 3 1 这组数据自测程序。</Reveal>

## 5. 复盘清单
- 树的问题先画出来，看清「问的是向下的孩子还是向上的祖先」。
- 「连续一段求最优」想到一维 DP；「最少步数」想到 BFS；「配对、最近、倒序」想到栈。
- DP 题先手填小表格，栈题先模拟小例子，再上机。
- 每题至少设计 2 组边界数据：n=1、全负数、空栈、单结点树。

## 6. 课后巩固
1. 把题一改造成「输出 x 的第 k 代祖先」，写出代码并测试。
2. 把题二中蛋糕改为「最多选 m 块」的版本，思考状态需要增加什么维度（选几块）。
3. 用「3 1 2」验证题三输出 NO，再找一个能输出 YES 的非平凡进站顺序并写出模拟过程。
4. 思考题：题一和题三一个用树的指针、一个用栈，它们的共同点是什么？（都是把「关系」存进合适的数据结构，然后按规则走。）
5. 综合题：读入一棵带权树，求从根出发的一条向下的路径，使路径上权值和最大（提示：DFS 返回「从该结点向下走能获得的最大权值」）。
