## 1. 从爬楼梯说起
回家要爬 n 级台阶，每次可以跨 1 级或 2 级，一共有多少种走法？n=3 时，枚举有：1+1+1、1+2、2+1，共 3 种。

如果硬算 n=20，枚举会爆炸。换个角度想：**最后一步要么从第 n-1 级跨 1 级上来，要么从第 n-2 级跨 2 级上来**。所以「到 n 级的方法数」=「到 n-1 级的方法数」+「到 n-2 级的方法数」——大问题被拆成了两个**同类的更小问题**！这就是**动态规划（DP）**的核心思想：**把原问题拆成重叠的子问题，把子问题的答案存起来重复利用**（存答案这一步叫「记忆化」，避免了递归重复计算）。

## 2. DP 三要素：背好这个口诀
1. **状态**：f(i) 表示什么？（到第 i 级台阶的方法数）
2. **转移**：f(i) 由哪些更小的状态推出来？（f(i) = f(i-1) + f(i-2)）
3. **边界**：最小的问题答案是什么？（f(1)=1，f(2)=2）

代码就水到渠成：
```cpp
int f[105];
f[1] = 1; f[2] = 2;
for (int i = 3; i <= n; i++)
    f[i] = f[i-1] + f[i-2];
cout << f[n] << '\n';
```

> 教学提醒：讲 DP 最忌直接甩公式。先用 n=5 带着学生手算 f(1) 到 f(5)，让他们自己「发现」递推关系，公式就成了他们自己推导出的结论，记忆和迁移能力都会好很多。

## 3. 例题：最大连续和（条形蛋糕预告）
蛋糕切成 n 条，第 i 条价值 a[i]（**可为负数**，表示那条不好吃还要倒贴钱）。选**连续的一段**吃掉，最多能吃到多少价值？

设 f(i) = 以第 i 条结尾的连续段能获得的最大价值。对第 i 条只有两种抉择：

- **接上前面的段**：f(i-1) + a[i]（前面的段是挣钱的，带上它）；
- **弃掉前面的，自己单开一段**：a[i]（前面在亏钱，果断割席）。

**取两者较大值**：f(i) = max(a[i], f(i-1) + a[i])。最终答案是所有 f(i) 中的最大值（最优段的结尾位置不固定）。

```cpp
int best = a[1], f = a[1];
for (int i = 2; i <= n; i++) {
    f = max(a[i], f + a[i]);   // 状态转移
    best = max(best, f);       // 顺便记录历史最优
}
cout << best << '\n';
```

这正是 GESP 真题「条形蛋糕」的简化版，第 11 课还会见到它的完整形态。

## 4. DP 与递归、贪心的区别
- **纯递归**：直接翻译递推式会反复计算同一个子问题（f(5) 要算 f(3) 两次），n 稍大就慢得离谱；DP 把结果存进数组，**每个子问题只算一次**。
- **贪心**：每一步只看眼前最优；DP 是「**枚举所有选择，取最优的那个**」。爬楼梯里「接不接前面」两种可能都试过了再取 max，这就是 DP 与贪心最本质的差别。
