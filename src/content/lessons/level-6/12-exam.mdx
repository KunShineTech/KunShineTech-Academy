## 1. 考点串讲：七张知识地图
**树的基本概念**：树有 n 个结点恰有 n-1 条边、无环、任意两点路径唯一。常用邻接表存储：child[u] 挂 u 的所有孩子。二叉树每个结点最多两个孩子，分左右。

**二叉树的构造与遍历**：记住三个口诀——先序「根左右」、中序「左根右」、后序「左右根」，变化只在根的位置。还原二叉树抓两条：先序首位是根；拿根到中序里一劈，左边左子树、右边右子树。

**特殊二叉树**：完全二叉树下标从 1 时，i 的左孩子 2i、右孩子 2i+1、父亲 i/2。二叉排序树左小右大，**中序遍历即升序**。哈夫曼树每次取两个最小权值合并，**WPL = 合并产生的新权值之和**，一定最短。

**编码**：哈夫曼编码是前缀码（只有叶子分配编码），总长度等于哈夫曼树的 WPL；解码从根走，遇 0 向左、遇 1 向右，到叶子输出并回根。格雷编码相邻只差一位，公式 `G = n ^ (n >> 1)`。

**搜索**：DFS「一条路走到底再回头」，配回溯三件套（做选择、深入、撤销标记），适合「能否到达、所有方案、连通块」。BFS「一圈一圈扩散」，配队列，**第一次到达即最短**，适合「最少步数、最短距离」。二叉树层序遍历就是 BFS 在树上的样子。

**动态规划**：三要素——状态、转移、边界。爬楼梯 f(i)=f(i-1)+f(i-2)；最大连续和 f(i)=max(a[i], f(i-1)+a[i])。0-1 背包 f[i][j]=max(f[i-1][j], f[i-1][j-w[i]]+v[i])，滚动成一维后**容量必须倒序**（完全背包才正序）。

**面向对象与栈队列**：类 = 数据 + 操作打包，封装靠 private 数据 + public 函数；继承是「是一种」关系，多态是「同一指令、不同反应」。栈后进先出（括号匹配、撤销、函数调用），队列先进先出（排队、BFS）；循环队列取模转圈、留一个空位区分队空队满。

## 2. 模拟编程题一：完全二叉树的第 k 层
<Task title="完全二叉树的第 k 层（测评题）" input="两个正整数 n 和 k（1≤n≤1000，1≤k≤10），一棵有 n 个结点的完全二叉树（下标 1~n，根为 1）" output="第 k 层的结点个数" sampleIn="12 3" sampleOut="4">第 k 层编号是一段连续区间，先写出区间端点的公式，再和 n 比较取交集。完全二叉树的编号规律是本题唯一考点。</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\nusing namespace std;\nint main(){\n    int n, k; cin>>n>>k;\n    int L = 1;\n    for(int i = 1; i < k; i++) L *= 2;   // 2^(k-1)\n    int R = L * 2 - 1;                    // 2^k - 1\n    int ans;\n    if(n < L) ans = 0;\n    else if(n >= R) ans = R - L + 1;\n    else ans = n - L + 1;\n    cout<<ans<<'\\n';\n}`}</code></pre>完全二叉树第 k 层编号从 2 的 k-1 次方到 2 的 k 次方减 1，是连续区间。n 比左端点小则该层没有结点；n 盖住整个区间则输出区间长度；否则输出 n 到左端点的距离。样例 n=12、k=3：区间 [4,7] 全部存在，输出 4。自测建议：n=12、k=4（区间 [8,15]，n 只盖到 12，输出 5）和 n=1、k=2（输出 0）。</Reveal>

## 3. 模拟编程题二：条形蛋糕
<Task title="条形蛋糕（测评题）" input="第一行正整数 n（1≤n≤1000），第二行 n 个整数 a[i]（-1000≤a[i]≤1000），表示第 i 块蛋糕的美味值" output="选择连续的一段蛋糕，输出能获得的最大美味值总和" sampleIn="8
2 -1 3 4 -10 5 2 -3" sampleOut="8">这是「最大连续和」：f = max(a[i], f + a[i])，全程记录最优。关键边界：全负数时答案是最大的那个负数，而不是 0。先填 DP 表再写代码。</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\nusing namespace std;\nint main(){\n    int n; cin>>n;\n    long long x, f, best;\n    cin>>x;\n    f = best = x;\n    for(int i = 2; i <= n; i++){\n        cin>>x;\n        if(f + x > x) f = f + x;   // 接前面的段\n        else f = x;                // 单开一段\n        if(f > best) best = f;\n    }\n    cout<<best<<'\\n';\n}`}</code></pre>转移方程 f = max(a[i], f + a[i])：前面的段挣钱就接上，亏钱就果断单开。初值取第一个数而不是 0，保证全负数数据正确。样例：f 依次为 2、1、4、8、-2、5、7、4，best = 8（选 2,-1,3,4 这一段，和为 8）。</Reveal>

## 4. 考试须知
1. **时间管理**：180 分钟里先易后难，选择判断控制在 60 分钟内，两道编程题至少留 70 分钟，最后 10 分钟检查提交状态。
2. **知识题抓高频**：完全二叉树编号公式、三种遍历口诀、哈夫曼 WPL 的「合并和」算法、格雷码异或公式、0-1 背包倒序循环——这五处年年考，务必滚瓜烂熟。
3. **先写框架再填肉**：main、头文件、输入输出先搭好，能编译通过再写核心逻辑；DP 题先在草稿纸填小表格，树上题先画树。
4. **边界自查**：数组开够大？long long 用了吗（DP 答案容易爆 int）？递归边界（空结点、栈空、队空）判断了吗？样例亲手输入核对了吗？
5. **心态**：编程题卡住时先问自己——「这像哪道练过的题？」树用递归、最短路用队列、连续段求最优用一维 DP，三大钥匙总能打开一扇门。

## 5. 课后巩固
1. 合上书，默写：完全二叉树的父子编号公式、三种遍历口诀、哈夫曼 WPL 两种算法。
2. 手算：权值 5、3、2、1 的哈夫曼树 WPL，并用「频率乘深度」核对。
3. 编程：完成本课两道测评题，完全二叉树题加测 n=1、k=1，蛋糕题加测全负数数据。
4. 总结：把七张知识地图各用一句话写成「考前小抄」，贴在书桌前。
5. 自评：对照七条官方大纲逐条给自己打分（会 / 模糊 / 不会），「模糊」项回到对应课文再学一遍。
