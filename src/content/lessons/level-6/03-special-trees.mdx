## 1. 完全二叉树：排座位有规矩
全班按个子高矮排成金字塔形拍照：第一排站 1 人，第二排 2 人，第三排 4 人……**从上到下、从左到右依次站人，最后一排靠左站，中间不许留空位**——这就是**完全二叉树**。

它最大的好处是**不用指针，一个数组就能存**：把根放在下标 1，然后按站位顺序依次放进数组。于是结点之间出现神器的编号关系：

- 结点 i 的**左孩子**是 `2*i`，**右孩子**是 `2*i+1`；
- 结点 i 的**父亲**是 `i/2`（整除）；
- 有 n 个结点的完全二叉树，**高度**是 log 以 2 为底 n 的对数向上取整。

像电梯按钮：知道你在第 i 层，左邻右舍的编号不用问人，算一下就知道。这套编号规律是六级选择题的高频考点。

> 教学提醒：编号规律的前提是「**下标从 1 开始**」。若题目规定从 0 开始编号，公式要相应改成 2i+1 / 2i+2，考试时一定看清题目约定。

## 2. 二叉排序树：天生会排队
**二叉排序树（BST）**规定：任意结点的**左子树所有值比它小，右子树所有值比它大**。就像班里按身高排队后挂到一棵树上——往左一站比队长矮，往右一站比队长高。

三个重要性质：
1. **中序遍历 BST，输出必然从小到大有序**。这是检查一棵树是不是 BST 的利器。
2. **查找**：比当前结点大往右、小往左，每次砍掉一半，和二分查找一样快（O(高度)）。
3. **插入**：按同样规则走到空位放进去。注意：普通 BST 可能被插入成一条「长辫子」（如依次插 1,2,3,4,5），高度退化为 n——这是它天生的缺点。

```cpp
// 在 BST 中查找 x：从根出发，大往右小往左
int cur = root;
while (cur != 0) {
    if (x == val[cur]) { /* 找到 */ break; }
    else if (x < val[cur]) cur = lc[cur];
    else cur = rc[cur];
}
```

## 3. 哈夫曼树：让权值大的结点住一楼
图书馆搬书：书有轻重，重的书（权值大）应该放在离门口近的位置。把「书到门口的搬运次数 × 书的重量」累加，就是**带权路径长度 WPL**。怎么安排所有人住的楼层，使总搬运量最小？答案就是**哈夫曼树**。

构造口诀：**每次取两个最小，合并成新结点，放回去再来**。具体步骤：
1. 把所有权值各自当成一棵单结点小树，放进「候选池」。
2. 从池里取出**最小的两棵**合并：它们成为新结点的左右孩子，新结点的权值 = 两者之和。
3. 把新树放回池中，重复第 2 步，直到只剩一棵树。

例：权值 1、2、3、4。候选池里先取最小的两个合并：1+2=3（池变成 3、3、4），再取两个 3 合并得 6（池变成 4、6），最后 4+6=10，只剩一棵树。

**WPL 最稳妥的算法：每次合并产生的新权值之和**，即 3+6+10 = **19**。用「频率 × 深度」核对：根是 10，它的左（右）孩子是 4 和 6；6 下面是合成的 3 和原始的 3；合成的 3 下面是 1 和 2。于是 4 的深度是 1，原始 3 的深度是 2，1 和 2 的深度是 3。WPL = 4×1 + 3×2 + 1×3 + 2×3 = 4+6+3+6 = 19，两种方法结果一致。手算时画好树、用两种方法互查，是考场保分的关键。

## 5. 三种树对比小结
- **完全二叉树**：存数组最省，编号有公式，常见于堆结构。
- **二叉排序树**：查找快，中序有序，插入顺手但怕「长辫子」。
- **哈夫曼树**：WPL 最小，是压缩编码的幕后英雄（第 4 课登场）。
