## 1. 从「散装零件」到「整机」
之前的程序像一盘散沙：学生的姓名是一个字符串、年龄是一个 int、成绩是一个数组，各过各的。如果班里有 50 个学生，变量会多到让人崩溃。**面向对象**的想法是：把「数据」和「操作这些数据的功能」打包成一个整体——就像手机把屏幕、芯片、摄像头封装成一个整机，你按按钮就行，不用管内部电路。

这个「整机」在 C++ 里叫**类（class）**，造出来的具体物件叫**对象**。类是图纸，对象是按图纸造出的实物：一张「学生」图纸，可以造出小明、小红无数个学生对象。

## 2. 封装：数据配保镖
打包只是第一招，面向对象的第一个核心概念是**封装**：把成员变量设为私有（private），只留公开的成员函数（public）作为「对外窗口」。

```cpp
class Student {
private:
    string name;              // 私有：外面不能直接碰
    int age;
public:
    void setAge(int a) {      // 公开的「设置窗口」
        if (a >= 0 && a <= 150) age = a;   // 顺带把关
    }
    int getAge() { return age; }
};
```

为什么要这么麻烦？想想 ATM 机：钱箱锁在机器里（private），你只能按公开按钮（public 函数）操作——**不该改的数据外面改不动，想捣乱也乱不了**。setAge 里的 if 把关还能拦截「年龄 = -5」这种脏数据。

> 教学提醒：struct 和 class 在 C++ 里几乎一样，唯一区别是默认访问权限：struct 默认 public，class 默认 private。竞赛代码里常见用 struct 存图上的边，也是合法的「类」。

## 3. 构造函数与 this
对象出生时自动执行的函数叫**构造函数**，名字和类名相同、没有返回值类型，常常用来初始化：

```cpp
class Student {
private:
    string name;
    int age;
public:
    Student(string n, int a) {   // 构造函数
        name = n; age = a;
    }
    void show() {
        cout << name << ' ' << age << '\n';
    }
};
Student stu("小明", 12);          // 出生时就起好名字
stu.show();
```

当参数名和成员变量同名时，用 `this->` 指「本对象的成员」：`this->age = age;`。this 就是对象自己的「自我介绍牌」。

## 4. 继承与多态：会认祖归宗
- **继承**：新类在旧类的基础上扩展。`class Pupil : public Student` 表示「小学生是一种学生」，自动拥有学生的一切成员，还可以加自己的新成员（如「少先队员编号」）。像孩子继承父母的基因又长出新的特点。
- **多态**：「同一句话，不同对象听出不同反应」。C++ 里通过**虚函数**实现：父类指针指向哪个对象，就执行哪个对象重写的版本。了解概念即可：马戏团驯兽师喊「叫一声」，狗汪汪、猫喵喵——**同一指令，因对象而异**。

六级要求「了解」继承与多态的概念，重点会写简单的类并正确使用。
