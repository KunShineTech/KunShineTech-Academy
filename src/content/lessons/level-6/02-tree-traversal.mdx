## 1. 二叉树的存储
二叉树每个结点最多两个孩子，最自然的存法是两个数组：`lc[u]` 表示 u 的左孩子，`rc[u]` 表示 u 的右孩子。没有孩子就用 0 表示（结点编号从 1 开始）：

```cpp
int n, lc[105], rc[105];
// 读入：n 个结点，依次给出每个结点的左孩子、右孩子编号，0 表示空
cin >> n;
for (int i = 1; i <= n; i++) cin >> lc[i] >> rc[i];
```

这就像给每个人登记「左手牵着谁、右手牵着谁」，整棵树的形状就记下来了。

> 教学提醒：用 0 表示「空」是因为结点编号从 1 开始，0 不会被用到。如果题目允许结点编号为 0，就要换个标记（比如 -1），读题时先看清编号范围。

## 2. 三种遍历：根站在哪里？
**遍历**就是把树上每个结点按一定顺序访问一遍。对二叉树最常用的三种遍历，本质区别在于「**根**什么时候被访问」：

- **先序遍历**：根 → 左子树 → 右子树。口诀：**根左右**。
- **中序遍历**：左子树 → 根 → 右子树。口诀：**左根右**。
- **后序遍历**：左子树 → 右子树 → 根。口诀：**左右根**。

生活类比：把树想成快递分拣——先序是先登记总站再分下去（从上往下派发）；后序是先分拣完下面的包裹最后汇总到总站（从下往上汇总）；中序最常见于**二叉排序树**，它能让结果从小到大排队输出。

## 3. 递归实现三兄弟
```cpp
void pre(int u) {              // 先序
    if (u == 0) return;        // 空树直接返回
    cout << u << ' ';
    pre(lc[u]);
    pre(rc[u]);
}
void in(int u) {               // 中序
    if (u == 0) return;
    in(lc[u]);
    cout << u << ' ';
    in(rc[u]);
}
void post(int u) {             // 后序
    if (u == 0) return;
    post(lc[u]);
    post(rc[u]);
    cout << u << ' ';
}
```

三份代码只有一句输出的位置不同，其余一模一样——这正是「根站在哪里」的直接体现。**递归的边界是遇到空结点（编号 0）就返回**，别忘了它，否则程序会沿着空指针一路走下去直到崩溃。

## 4. 还原二叉树：先序 + 中序
给你两趟「旅行记录」，能把原来的树画回来吗？能！规律是：**先序的第一个元素一定是根**；拿这个根去**中序**里一劈，左边是左子树、右边是右子树，两边再分别递归处理。

例如先序 `1 2 4 5 3`，中序 `4 2 5 1 3`：
1. 先序首位 1 是根；中序中 1 的左边 `4 2 5` 是左子树（3 个结点），右边 `3` 是右子树。
2. 左子树的先序段是 `2 4 5`，首位 2 为根；中序 `4 2 5` 劈成左 `4`、右 `5`。
3. 拼回去：1 的左是 2，2 的左是 4、右是 5；1 的右是 3。后序遍历结果为 `4 5 2 3 1`。
