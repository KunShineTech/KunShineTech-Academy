## 1. 整理扑克牌：插入排序
打扑克摸牌时，你每次把新摸的牌**插入**手里已经排好的一摞中：从右往左找到第一个不比它大的牌，插在它右边。手里的牌永远是**有序的**，一张一张直到摸完。

插入排序一模一样：把数组分成「左边已排序、右边未处理」两部分，每次取未区的第一个元素，**从后往前**和已区的元素比较，大的往后挪一位，空出的位置就是它的家：

```cpp
for (int i = 1; i < n; i++) {        // 第 0 张自带「已排序」属性
    int key = a[i];                  // 新摸的牌
    int j = i - 1;
    while (j >= 0 && a[j] > key) {   // 已区中比 key 大的往后挪
        a[j + 1] = a[j];
        j--;
    }
    a[j + 1] = key;                  // 插入空位
}
```

如果数据**基本有序**，每轮只挪一两下就停，接近 O(n)——这是插入排序的绝活。**它是稳定的**：while 条件是严格大于，相等元素不会被越过。

## 2. 每轮挑最小的：选择排序
班会选组长：从全班找出最矮的站第一位，再在剩下的人里找最矮的站第二位……**每轮从未排序区选出最小值，放到已排序区的末尾**。核心动作不是相邻交换，而是**记录最小值的下标**，一轮结束后**一次交换**：

```cpp
for (int i = 0; i < n - 1; i++) {
    int k = i;                       // k 记录最小值下标
    for (int j = i + 1; j < n; j++)
        if (a[j] < a[k]) k = j;      // 找到更小的就更新
    int t = a[i]; a[i] = a[k]; a[k] = t;  // 交换到已区末尾
}
```

无论输入是否有序，它都要做同样多的比较：O(n²)。**选择排序不稳定**：交换可能把后面与前面相等的元素换到前面去。

> 教学提醒：选择排序「一轮只交换一次」是它区别于冒泡的关键，也是「不稳定」的根源——手算例子 5a, 5b, 2（a、b 表示两个相等的 5）就能看清不稳定发生的瞬间。

## 3. 三种排序大比武

| 算法 | 思想 | 最坏复杂度 | 稳定性 | 绝活 |
| --- | --- | --- | --- | --- |
| 冒泡 | 相邻比较，大者后移 | O(n²) | 稳定 | 已有序时可达 O(n) |
| 插入 | 抓牌插入已排序区 | O(n²) | 稳定 | 基本有序时接近 O(n) |
| 选择 | 每轮选最小放前面 | O(n²) | 不稳定 | 交换次数最少（每轮一次） |

三者都只需 O(1) 额外空间，属于内排序、原地排序。n 较小（几百以内）时随便挑顺手的写。
