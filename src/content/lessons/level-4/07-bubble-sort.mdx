## 1. 气泡上浮：冒泡排序的思想
汽水瓶里摇一摇，最大的气泡总是最先冒到水面。**冒泡排序**就是模仿这个过程：反复比较**相邻**的两个数，如果前面比后面大就交换。每完整扫一遍，**当前最大的数就像大气泡一样被一路换到末尾**。

记住口诀：**「相邻比，逆序换，一趟下来最大值靠边站」**。

## 2. 手动模拟一遍
把 5, 1, 4, 2, 8 从小到大排：

- 第 1 趟：1 5 4 2 8 → 1 4 5 2 8 → 1 4 2 5 8 → 1 4 2 5 8（**8 就位**）
- 第 2 趟：1 4 2 5 8 → 1 2 4 5 8（**5 就位**，后面不用再碰）
- 第 3 趟：1 2 4 5 8（**4 就位**）
- 第 4 趟：确认 2 就位，全部有序。

n 个数需要 n-1 趟；第 i 趟只需比较到下标 n-1-i 为止，因为末尾已有 i 个数就位。

## 3. 代码实现
```cpp
for (int i = 0; i < n - 1; i++) {        // 共 n-1 趟
    for (int j = 0; j < n - 1 - i; j++) {// 每趟范围缩小
        if (a[j] > a[j + 1]) {           // 相邻比较
            int t = a[j]; a[j] = a[j+1]; a[j+1] = t;  // 交换
        }
    }
}
```

内层上界 `n - 1 - i` 是高频错误点：j 最大取到 n-2，才能安全访问 `a[j + 1]`。

## 4. 优化：已经有序就提前收工
如果某一趟**一次交换都没发生**，说明已经排好了，后面几趟全是白跑。加一个标志变量：

```cpp
for (int i = 0; i < n - 1; i++) {
    bool swapped = false;                // 本趟有没有交换过
    for (int j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
            swapped = true;
        }
    }
    if (!swapped) break;                 // 一趟都没换，已有序！
}
```

对于已经有序的数组，优化版只需 **O(n)**（一趟扫完就收工），这是它的最好情况；最坏（完全逆序）仍是 O(n²)。**冒泡排序是稳定的**——相等元素不交换，相对顺序不变。

> 教学提醒：「每趟结束后，最大值一定就位」是学生最容易困惑的点，务必先带学生手算一遍第 1 趟，亲眼看着最大值被交换到末尾，再讲代码。
