## 1. 上楼梯问题：递推的思想
你站在楼梯下，每次可以跨 1 级或 2 级。问：上到第 n 级，一共有多少种走法？

别想一口算出第 40 级！先玩小数据：1 级有 1 种走法，2 级有 2 种（1+1 或 2），3 级呢？**最后一脚**要么从第 2 级跨 1 级上来，要么从第 1 级跨 2 级上来——所以 3 级的走法 = 2 级的走法 + 1 级的走法 = 2 + 1 = 3 种。

这就是**递推**：不直接攻大目标，而是找到「**大问题 = 若干个稍小问题的组合**」的关系式，从最小的已知答案出发，一步一步推向目标。像传纸条：每一排都把前面两排的消息加起来写给自己后面的人。

## 2. 递推三要素：初始值、关系式、目标
把上面的推理一般化。设 f(n) 为上到第 n 级的走法数：

- **递推关系式**：最后一脚只有两种跨法，所以 f(n) = f(n-1) + f(n-2)
- **初始值**：f(1) = 1，f(2) = 2（关系式从 n=3 才开始适用）
- **计算方向**：从 f(3)、f(4)……一路推到 f(n)

数列写出来是 1, 2, 3, 5, 8, 13……没错，就是著名的**斐波那契数列**。递推解题的固定三步：**定初始值、找关系式、循环往后推**。缺了初始值，关系式就是无源之水。

> 教学提醒：让学生先手算前 5~6 项再写代码，能极大降低「关系式写反、初值定错」的概率。考试时先在草稿纸上把数列前几项列出来核对。

## 3. 写成代码：滚动变量
只需记住**最近两项**，像滚动前进的两个轮子：

```cpp
// 求台阶走法：f(1)=1, f(2)=2, f(n)=f(n-1)+f(n-2)
int n;
cin >> n;
long long a = 1, b = 2;      // a=f(1), b=f(2)
if (n == 1) cout << a << '\n';
else {
    for (int i = 3; i <= n; i++) {
        long long c = a + b; // 新轮子 = 前两轮之和
        a = b;               // 向前滚动
        b = c;
    }
    cout << b << '\n';
}
```

用 long long 是因为 f(45) 已经超过 21 亿——**递推题第一件事就是估算结果会不会爆 int**。

## 4. 递推与递归：一对兄弟
同一个问题也能用**递归**（函数自己调用自己）解决。递推是「自底向上」从小推到大，递归是「自顶向下」把大问题拆小。递推只用几个变量、没有函数调用开销，是竞赛中的首选写法；递归胜在代码像数学定义一样直白。四级要求先掌握递推。
