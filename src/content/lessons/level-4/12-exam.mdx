## 1. 考点串讲：三张知识地图
**指针与数据结构**：内存像快递柜，每个格子有地址，`&` 取地址、`*` 解引用；`int *p = &a;` 让 p 握住 a 的门牌号，`*p` 就是 a 本身；`*(p+i)` 等价于 `a[i]`。结构体把同一个人的数据装订成档案卡，成员用点号访问；二维数组是座位表，`g[i][j]` 先行后列，双重循环按行读写。

**函数与作用域**：函数是模块化编程的基本单位，先声明（或定义）后调用；声明 = 函数头 + 分号。形参是占位的空位，实参是真正放进去的值。**局部变量进门有效、全局变量全场通行**；参数传递默认是「复印一份」的值传递，想让函数改原件就用**引用传递（加 &）或指针传递（传地址）**。

**算法与工程**：递推三步走——**定初始值、找关系式、循环往后推**（如 f(n)=f(n-1)+f(n-2)，滚动变量只需记前两项）。排序要会分析**时间/空间复杂度、稳定性与场景**：冒泡、插入稳定且最坏 O(n²)，选择排序不稳定；O(n²) 是多项式，O(2ⁿ) 是指数，天壤之别；数据装不下内存用外排序。**文件操作**用 freopen 重定向 stdin/stdout 完成读、写、读写；**异常处理**记口诀「try 圈地，throw 报警，catch 善后」。

## 2. 模拟编程题一：兔子繁殖（递推）
<Task title="兔子繁殖（测评题）" input="一个正整数 n（1≤n≤45）" output="第 n 个月末的兔子对数。规则：第 1 个月有 1 对刚出生的小兔子；小兔子经过 1 个月长成成年兔；每对成年兔每月生 1 对小兔子" sampleIn="6" sampleOut="8">手算前几个月：1, 1, 2, 3, 5, 8……这是斐波那契数列！找出关系式 f(n)=f(n-1)+f(n-2)，定好初值 f(1)=f(2)=1，用滚动变量递推。注意 n 较大时用 long long。</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\nusing namespace std;\nint main(){\n    int n;\n    cin>>n;\n    long long a=1, b=1;\n    if(n<=2){ cout<<1<<'\\n'; return 0; }\n    for(int i=3;i<=n;i++){\n        long long c=a+b;\n        a=b;\n        b=c;\n    }\n    cout<<b<<'\\n';\n}`}</code></pre>递推三要素：初值 f(1)=f(2)=1；关系 f(n)=f(n-1)+f(n-2)；滚动两个变量向前推。样例：1,1,2,3,5,8，第 6 个月是 8。f(45)=1134903170 超过 int，必须 long long。</Reveal>

## 3. 模拟编程题二：成绩单排名（结构体 + 稳定排序）
<Task title="成绩单排名（测评题）" input="第一行一个正整数 n（n≤100），接下来 n 行，每行一个姓名（不含空格）和总分（0~750）" output="按总分从高到低输出姓名，空格分隔；总分相同保持输入顺序" sampleIn="4
Tom 600
Amy 650
Bob 650
Coco 590" sampleOut="Amy Bob Tom Coco">用结构体数组存学生，用**稳定的排序**（插入排序）按总分降序。关键决策：同分保持输入顺序，选择排序会打乱，必须用稳定的算法。</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\n#include <string>\nusing namespace std;\nstruct Student{\n    string name;\n    int score;\n};\nint main(){\n    int n;\n    cin>>n;\n    Student s[105];\n    for(int i=0;i<n;i++) cin>>s[i].name>>s[i].score;\n    for(int i=1;i<n;i++){\n        Student key=s[i];\n        int j=i-1;\n        while(j>=0 && s[j].score<key.score){\n            s[j+1]=s[j];\n            j--;\n        }\n        s[j+1]=key;\n    }\n    for(int i=0;i<n;i++){\n        if(i) cout<<' ';\n        cout<<s[i].name;\n    }\n    cout<<'\\n';\n}`}</code></pre>插入排序降序：只有严格小于才后移，同分元素互不跨越，输入顺序自然保留。Amy 与 Bob 同 650，Amy 先进已排序区、Bob 插入时不会越过她，输出 Amy Bob。这就是稳定性的实战价值。</Reveal>

## 4. 考试须知
1. **时间管理**：120 分钟里先易后难，选择判断控制在 50 分钟内，两道编程题至少留出 50 分钟。
2. **知识题抓高频**：指针的 & 与 *、三种参数传递的效果、排序稳定性与复杂度、递推初值与关系式，年年必考。
3. **先写框架再填肉**：main、头文件、读入输出先搭好；用函数拆题时先声明原型。
4. **边界自查**：递推是否 long long？排序同分怎么处理？文件读写路径与文件名是否和题目一致？
5. **心态**：递推题先手算前几项找规律，排序题先想清楚「稳定性」要求再选算法，文件题先注释 freopen 本地调通。
