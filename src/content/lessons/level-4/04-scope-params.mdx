## 1. 储物柜的租用范围：作用域
学校储物柜不是随便开的：你租的柜子，只有你的钥匙能开；教室图书角的共用书架，全班都能拿。变量也一样，每个变量都有一个「能使用它的范围」，叫**作用域**。

```cpp
int g = 100;                 // 全局变量：定义在所有函数外面
void f() {
    int x = 1;               // 局部变量：只在 f 里有效
    cout << g << ' ' << x << '\n';   // 100 1，都能用
}
int main() {
    f();
    cout << g << '\n';       // 100，全局变量 main 也能用
    // cout << x;            // 报错！x 是 f 的私有柜子
}
```

**全局变量**定义在函数外，从定义处到文件末尾的所有函数都能访问；**局部变量**定义在函数（或块）内，出了大门就失效。口诀：**「局部变量进门有效，全局变量全场通行」**。

> 教学提醒：全局变量虽然方便，但谁都能改，程序大了容易「谁在什么时候改了它」查不清。教学中要求：能用局部变量和参数传递解决的就别用全局变量。

## 2. 值传递：函数拿到的是复印件
默认情况下，调用函数时实参被**复印一份**装进形参。函数里改的是复印件，原件毫发无损：

```cpp
void f(int x) {
    x = 99;                  // 改的是复印件
}
int main() {
    int a = 1;
    f(a);
    cout << a << '\n';       // 输出 1，a 没变！
}
```

这就像你把作业复印一份借给同桌改，他改得再凶，你手里的原件一个字都不会变。

## 3. 引用传递：把原件交出去
想让函数修改实参，给形参加一个 `&`，它就变成实参的**别名**——不是复印件，是同一张原件的第二个名字：

```cpp
void f(int &x) {             // x 是实参的别名
    x = 99;                  // 改别名就是改原件
}
int main() {
    int a = 1;
    f(a);
    cout << a << '\n';       // 输出 99！
}
```

## 4. 指针传递：把门牌号交出去
上一课的指针也能办同样的事：把地址传给函数，函数按门牌号找到原件修改：

```cpp
void f(int *p) {
    *p = 99;                 // 解引用，开柜改原件
}
int main() {
    int a = 1;
    f(&a);                   // 把 a 的门牌号递过去
    cout << a << '\n';       // 输出 99！
}
```

三种方式对比：**值传递安全但改不了原件；引用传递写法最省事；指针传递能表达「可能为空」等更多含义**。让函数修改实参，记住口诀：**「想改原件，加 & 或传地址」**。
