## 1. 学生档案卡：为什么需要结构体
班里要登记学生信息：姓名、语文成绩、数学成绩。如果只用普通变量，得写成 name1、c1、m1、name2、c2、m2……人和成绩对得乱七八糟，像把档案卡的碎片撒了一地。

**结构体**就是把属于同一个人的若干数据**装订成一张完整的档案卡**：

```cpp
#include <string>
struct Student {
    string name;   // 成员：姓名
    int chinese;   // 成员：语文成绩
    int math;      // 成员：数学成绩
};                 // 注意：这里的分号不能丢！
```

## 2. 结构体的使用：定义、赋值与访问
定义好「卡片的样式」后，就可以批量造卡片了。访问卡片上的某一项，用**点号 `.`**：

```cpp
Student a;                   // 造一张卡片
a.name = "小明";             // 填写姓名栏
a.chinese = 90;
a.math = 95;
cout << a.name << " 总分 " << a.chinese + a.math << '\n';

Student b = {"小红", 88, 92};  // 定义时按顺序初始化
Student s[50];                 // 一沓卡片：结构体数组
s[0].math = 100;               // 第 0 张卡片的数学栏
```

> 教学提醒：结构体定义右括号后的分号是初学者最高频的编译错误，报错信息往往是「expected ; before...」，看到它先检查结构体的分号。

## 3. 教室座位表：二维数组
三级的一维数组像一排储物柜，**二维数组**则像教室里的座位表：有行有列。声明时写两个大小：

```cpp
int g[3][4];              // 3 行 4 列，共 12 个格子
int h[2][3] = {{1,2,3},   // 第 0 行
               {4,5,6}};  // 第 1 行

g[1][2] = 90;   // 第 1 行第 2 列（行、列下标都从 0 开始）
```

口诀：**「先行后列」，访问写 `g[i][j]`，i 是行号，j 是列号。** 三维及更多维数组同理，只是再多加几对方括号，如 `int cube[3][4][5];`。

## 4. 二维数组的遍历：双重循环
给整张座位表读入数据，用「外层走行、内层走列」的双重循环，这是固定套路：

```cpp
int g[105][105], n, m;
cin >> n >> m;                       // 先读行数和列数
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        cin >> g[i][j];              // 逐行逐列读入

for (int i = 0; i < n; i++) {
    int rowsum = 0;
    for (int j = 0; j < m; j++)
        rowsum += g[i][j];           // 累加第 i 行
    cout << rowsum << '\n';
}
```
