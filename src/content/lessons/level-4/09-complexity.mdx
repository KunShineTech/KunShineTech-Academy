## 1. 为什么需要复杂度：跑多快才算快
两台自动售货机，A 机找零要 10 秒，B 机要 1 秒——买一瓶水感觉差不多，但全校 3000 人课间同时买，差距就是 7.5 小时！**复杂度**就是用来描述「数据一多，程序慢得多快」的尺子，让我们不运行程序也能比较算法好坏。

## 2. 大 O 表示法：只抓大头
精确计算运行时间受电脑影响，没意义。大 O 表示法只看**增长趋势**：
- 去掉常数：`O(2n)` 写作 **O(n)**，因为电脑快慢这类常数不影响「趋势」。
- 去掉低阶项：O(n² + n) 写作 **O(n²)**，因为 n 很大时 n² 完全碾压 n。
- O(1) 表示**常数时间**——无论数据多大，一眨眼就完事。

## 3. 常见复杂度阶梯
| 复杂度 | 名称 | n=1000 时约需步数 | 感受 |
| --- | --- | --- | --- |
| O(1) | 常数 | 1 步 | 瞬间 |
| O(log n) | 对数 | 约 10 步 | 极快，每步砍掉一半 |
| O(n) | 线性 | 1000 步 | 很快 |
| O(n²) | 多项式 | 1,000,000 步 | 可接受（n 要小） |
| O(2ⁿ) | 指数 | 约 10³⁰⁰ 步 | 宇宙终结也算不完 |

**指数复杂度是洪水猛兽**：多项式复杂度（O(n)、O(n²)、O(n³)……）努努力还能跑，指数复杂度 n 稍大就彻底没戏——这就是密码学敢把安全建立在「分解大数」上的原因。

## 4. 估算实战：数循环层数
最简单的方法：**循环套了几层，先猜 n 的几次方，再检查内层是否真的跑满**。

```cpp
for (int i = 1; i <= n; i++)        // O(n)
    for (int j = i; j <= n; j++)    // 内层不是 n 次，而是 n-i+1 次
        cnt++;
```
内层次数是 n + (n-1) + ... + 1 = n(n+1)/2，仍是 **O(n²)**——内层长短不一时，估算「平均跑多少」即可。

而下面这个循环每轮 i 翻倍，只跑约 log₂n 次：
```cpp
for (int i = 1; i <= n; i *= 2) work();   // O(log n)
```

> 教学提醒：估算先数循环层数，再看每层次数是否与 n 同阶；遇到 i 乘 2、i 除 2 的循环，立刻反应过来是 O(log n)。常数和低阶项大胆扔掉。

## 5. 课后巩固
1. 计算：n=1000 时，O(n²) 和 O(n log₂n) 各约需多少步？相差多少倍？
2. 概念题：为什么大 O 表示法要扔掉常数项和低阶项？用「买 1 瓶水与全校同时买」类比说明。
3. 估算下列代码复杂度：`for(i=1;i<=n;i++) for(j=1;j<=m;j++) cnt++;`（两个变量 n、m）
4. 编程：写一段 O(log n) 的循环（i 每次乘 2），输出循环执行次数验证。
5. 思考：「枚举所有 n 个数的子集」大约是 O(2ⁿ)，n=30 时还能跑吗？n=100 呢？
