## 1. 快递柜与门牌号：什么是地址
想象一下学校门口的**快递柜**：每个格子都有一个编号，比如 8 号柜。寄件人不关心柜子里放了什么，只要报出编号，快递员就能准确找到那个格子。

计算机的内存就是一排巨大的快递柜。每个变量都住在其中一个格子里，**每个格子都有一个编号，这个编号就叫地址**。在 C++ 里，用 `&`（取地址运算符）可以问出变量住在几号柜：

```cpp
int a = 5;
cout << &a << '\n';   // 输出 a 的地址，形如 0x61fe14
```

运行一下，你会看到一串以 `0x` 开头的神秘数字——那就是变量 a 的「门牌号」。

## 2. 指针变量：专门存门牌号的变量
三级时我们说「变量是存数据的盒子」。有一种特殊的盒子，里面存的不是数据本身，而是**别的变量的地址**，这种盒子就叫**指针变量**。

```cpp
int a = 5;
int *p = &a;   // p 是一个指针，里面存着 a 的门牌号
```

三条铁律：
1. 指针变量也有自己的类型：`int *p` 表示 p 只能存 int 变量的地址，`double *q` 只能存 double 的地址。**门牌号必须对得上柜子类型。**
2. 定义时 `int *p` 的 `*` 表示「这是一个指针」；定义之外的 `*p` 是另一个意思，马上讲到。
3. 指针里存的是地址，不是数据本身：`cout << p` 打印门牌号，`cout << *p` 打印柜子里的东西。

> 教学提醒：没有初始化的指针（俗称野指针）指向随机位置，对它解引用就像拿着一张假门牌号去开别人的柜子——程序可能当场崩溃。给指针赋值之前，绝对不要使用它。

## 3. 解引用：按门牌号开柜取物
有了门牌号，就能开柜取物。`*p`（读作「解引用 p」）表示「找到 p 里存的地址对应的那个变量」。它不仅能**读**，还能**写**：

```cpp
int a = 5;
int *p = &a;
cout << *p << '\n';   // 读到 5
*p = 99;              // 往柜子里放新东西
cout << a << '\n';    // a 变成了 99！
```

注意最后一句：我们从头到尾没有直接碰 a，只是通过 p 修改了它，a 的值却变了。这就是指针的威力——**拿到门牌号，就等于拿到了柜子的钥匙**。

## 4. 指针与数组：门牌号是连号的
数组是一排连号的柜子，`a[0]` 的地址存进指针后，`p + 1` 就是下一个柜子的门牌号：

```cpp
int a[5] = {10, 20, 30, 40, 50};
int *p = a;            // 数组名 a 本身就是 a[0] 的地址
cout << *p << '\n';        // 10，即 a[0]
cout << *(p + 2) << '\n';  // 30，即 a[2]
```

记住这个等式：**`*(p + i)` 就是 `a[i]`**。因为柜子连号，所以指针加 i 就跳过了 i 个格子。
