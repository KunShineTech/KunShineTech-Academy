## 1. 数据的大仓库：为什么用文件
程序一关，变量全没。想让数据**活下来**、想一次准备几百组测试数据，就要请出**文件**——磁盘上长久保存数据的仓库。考试评测也常常要求：程序从 `xxx.in` 读数据、把答案写进 `xxx.out`。本章教你两个层面：**重定向**（最常用，一行搞定）和**文件流对象**（ifstream/ofstream）。

## 2. 一键重定向：freopen
`cin` 默认连着键盘，`cout` 默认连着屏幕。`freopen` 可以偷偷把它们的「线」改接到文件上——这就是**重定向**：

```cpp
freopen("data.in", "r", stdin);     // 让 cin 从 data.in 读（r = read）
freopen("result.out", "w", stdout); // 让 cout 写进 result.out（w = write）
```

三要素：**文件名、模式（r 读 / w 写）、重定向谁（stdin / stdout）**。加上这两行后，后面所有 cin、cout 照常写，浑然不觉自己被「调包」了。

> 教学提醒：w 模式会清空原文件内容再写入，像拿黑板擦把黑板擦干净——重要文件别乱用 w 模式调试。调试时先注释掉 freopen 用键盘输入，提交前再取消注释。

## 3. 读操作与写操作
- **读操作**：配好 `freopen("in.txt", "r", stdin)`，之后 `cin >> x` 读的就是文件里的数。文件读完后再读会失败（cin 进入失败状态），可用 `while (cin >> x)` 一直读到文件结尾，不知道个数的数据就这么处理。
- **写操作**：配好 `freopen("out.txt", "w", stdout)`，之后 `cout` 的内容全进文件，屏幕上什么也看不到——别慌，打开 out.txt 看看。
- **读写操作**：两个 freopen 同时配上，就是「从文件读、算出结果、写回文件」的完整流程，评测机的标准形态。

```cpp
#include <iostream>
using namespace std;
int main() {
    freopen("data.in", "r", stdin);
    freopen("result.out", "w", stdout);
    int n, sum = 0, x;
    cin >> n;
    for (int i = 0; i < n; i++) { cin >> x; sum += x; }
    cout << sum << '\n';          // 结果写进了 result.out
}
```

文件流写法（了解）：`ifstream fin("data.in"); fin >> x;`、`ofstream fout("result.out"); fout << x;`，功能与重定向等价。

## 4. 文本文件的分类
我们日常用的记事本、代码文件、CSV 表格都是**文本文件**：以可读的字符存储，用记事本打开能看懂。与之相对的是**二进制文件**：把内存里的原始字节直接写盘（如图片、可执行程序），记事本打开是乱码。文本文件便于人查看和跨程序交换；二进制文件更紧凑、读写更快。本课所有读写都是文本文件。
