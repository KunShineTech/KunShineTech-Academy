## 1. 综合题拆解四步法
五级的题很少只考一个点。拿到题别慌，先写四行字：
1. **输入是什么？输出是什么？**（数据范围多大，决定能用什么复杂度）
2. **数学结构是什么？**（有没有同余、奇偶、区间、单调性？）
3. **候选算法有哪些？**（枚举？排序+贪心？二分答案？递归分治？）
4. **边界和特殊数据是什么？**（n=1？全相等？负数？）

本课用两道题演示这套流程，它们各串联多个考点，难度对标真题。

> 教学提醒：要求学生在草稿纸上先写完四行分析再允许开编译器。多数「做不出来」其实是「没读题」，这一步能过滤掉八成失误。

## 2. 例题一：第 k 个与 7 无关的数（筛法 + 二分）
**题意**：如果一个正整数能被 7 整除、或十进制表示中含数字 7，就叫「与 7 有关」。求第 k 个「与 7 无关」的数（k≤10000）。

**拆解**：四行分析——输入 k（不大）；结构是「判定一个数是否与 7 有关」（整除或含数字 7，逐位检查即可）；候选：从小到大枚举无关数，数到第 k 个（k≤10000，枚举完全够快）；边界：1 是无关数，7、17、70 是有关数。

<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\nusing namespace std;\nbool related7(int n){\n    if(n%7==0) return true;\n    while(n>0){\n        if(n%10==7) return true;\n        n /= 10;\n    }\n    return false;\n}\nint main(){\n    int k; cin>>k;\n    int cnt = 0, x = 0;\n    while(cnt<k){\n        x++;\n        if(!related7(x)) cnt++;\n    }\n    cout<<x<<'\\n';\n}`}</code></pre>related7 做两件事：n%7==0 判整除；while 循环逐位剥个位判数字 7。主程序从小到大扫，遇到无关数就计数，数到第 k 个即答案。k≤10000 时答案不超过约 11000，循环总次数很小，暴力枚举绰绰有余——这体现了复杂度分析：先估算再选算法，能简单就不要炫技。样例第 5 个无关数是 6（7 被跳过）。"加强版"：若 k≤10⁷，枚举会慢，可改用「二分答案 + check 计数」（1~x 中无关数个数 = x - 有关数个数，而有关数个数可用容斥+数位思想算），体会同一个问题的多层解法。</Reveal>

## 3. 例题二：翻硬币（递归 / 递推 + 贪心观察）
**题意**：一排 n 枚硬币，正面朝上。每次操作必须翻转**相邻两枚**。要把全部翻成反面朝上，最少操作多少次？n≤10000。

**拆解**：四行分析——输入 n；结构是相邻翻转，每枚硬币被翻的次数奇偶性必须为「奇」；候选：手玩 n=1,2,3,4,5 找规律；边界：n=1 无解（输出 -1）。

手玩发现：n=1 不可能；n=2 翻 1 次；n=3 不可能；n=4 翻 2 次……**规律：n 为偶数时答案 n/2，n 为奇数时无解**。递归看这个问题也别有风味：f(n)=f(n-2)+1，边界 f(0)=0、f(1)=-1——递推式和找规律殊途同归。

<Check question="一排 n 枚正面朝上的硬币，每次必须翻转相邻两枚，n 为奇数时？" options={['答案为 (n+1)/2','答案为 n/2','无解','答案为 n-1']} answer={2} explanation="每次翻转改变 2 枚硬币的状态，正面硬币总数的奇偶性不变；初始 n 为奇数（奇数个正面），无法变成 0（偶数），故无解。n 为偶数时答案 n/2。这也是奇偶性分析的经典应用。" />

<Task title="翻硬币" input="一个正整数 n（1≤n≤10000）" output="最少操作次数；若不可能输出 -1" sampleIn="4" sampleOut="2">先手玩 n=1..5 列张表，观察规律：什么时候有解？答案和 n 是什么关系？用「奇偶性不变量」解释规律为何成立。</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\nusing namespace std;\nint main(){\n    int n; cin>>n;\n    if(n%2==1) cout<<-1<<'\\n';\n    else cout<<n/2<<'\\n';\n}`}</code></pre>三步走：第一步手玩列小表（n=1→-1，2→1，3→-1，4→2，5→-1，6→3）；第二步归纳猜想：奇数无解、偶数 n/2；第三步用奇偶性证明：每次翻 2 枚，正面数奇偶不变，奇数个正面永远变不成 0 个，奇数 n 无解；而偶数 n 从左到右两两分组各翻一次即达成，n/2 次够且（每组两枚必须各自被翻奇数次）省不掉。代码只剩两行，功夫全在分析——这正是五级综合题的常态：模型选对了，代码一行顶十行。样例 n=4，翻 (1,2) 与 (3,4) 共 2 次。</Reveal>

## 4. 复盘清单
综合题做完（哪怕没做完）都过一遍清单：
- 四步分析是否写在了纸上？数据范围对应哪种复杂度？
- 有没有用具体小数据（n=1,2,3）手算验证？
- 数学性质用上了吗：同余？奇偶？单调性？gcd？
- 边界：输出格式（-1？多行？空格？）是否与题目一字不差？
- 若超时，是算法选错，还是常数写大（如不必要的 O(n²)）？

## 5. 课后巩固
1. 概念题：重做「四步拆解」，对象换成第 6 课的奇偶数对计数题，写出你的四行分析。
2. 编程题：求第 k 个「既能被 3 整除、又不能被 5 整除」的数（k≤10⁵），写出两种做法并比较优劣。
3. 编程题：一排 n 个格子，每次跳 1 格或 2 格，从第 1 格到第 n 格有多少种跳法？（提示：斐波那契递推，n≤50，用 long long 观察何时溢出，思考如何只输出对 10⁹+7 取余的结果。）
4. 编程题：读 n 个区间，选出尽可能多的互不重叠区间（第 9 课活动安排的完整版），n≤10⁵。
5. 思考题：综合题里「枚举找规律 → 数学证明 → 代码实现」这条路线，和「直接套用模板」相比，各有什么优缺点？
