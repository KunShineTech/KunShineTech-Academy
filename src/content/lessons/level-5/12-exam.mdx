## 1. 考点串讲：五张知识地图
**初等数论**：素数（试除到 √n）、合数、1 既不是素数也不是合数；约数与倍数、gcd 与 lcm（黄金公式 a×b = gcd×lcm）；同余与模运算（和积的余数 = 余数的和积再取余）；奇偶性（和偶 ⟺ 同奇偶，积奇 ⟺ 全奇）。

**高精度计算**：long long 装不下的大数用数组**倒序**存储（个位在 a[0]）；加法进位「先加后除十」、减法借位、高精乘单精；输出前去前导零。

**链表**：节点 = 数据 + 指针；单链表插入删除改两根指针，口诀「先接后，再接前」；双向链表加 prev，找前驱 O(1)；循环链表首尾相接，终止条件常用 `p != head`；三者牺牲随机访问换插入删除灵活。

**数论算法**：辗转相除法 gcd(a,b)=gcd(b,a%b)；唯一分解定理与约数个数公式；埃氏筛 O(n log log n)、线性筛 O(n)。

**算法分析与二分**：大 O 记号（丢常数、留主项）；复杂度食物链 `O(1) < O(log n) < O(n) < O(n log n) < O(n²)`；二分查找（有序前提、`l=mid+1` / `r=mid-1`）与二分答案（判定有单调）。

**递归、贪心与分治**：递归三要素（出口、缩小、组合），警惕重复计算用记忆化；贪心每步取局部最优，前提是可证最优子结构（活动安排按结束时间排序）；分治三步「分、治、合」，归并排序稳定 O(n log n)，快排平均 O(n log n)。

## 2. 模拟编程题一：完全平方数判定（数论 + 二分思想）
<Task title="完全平方数（测评题）" input="一个正整数 n（1≤n≤10¹²）" output="若 n 是完全平方数输出 YES，否则输出 NO" sampleIn="144" sampleOut="YES">n 最大 10¹²，int 和 long long 都装不下？——long long 最大约 9×10¹⁸，装得下。关键是判断：逐个枚举平方根必超时，想想「平方函数在正整数域单调」，能不能二分平方根？</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\nusing namespace std;\nint main(){\n    long long n; cin>>n;\n    long long l = 1, r = 2000000;\n    bool ok = false;\n    while(l <= r){\n        long long mid = (l+r)/2;\n        if(mid*mid == n){ ok = true; break; }\n        if(mid*mid < n) l = mid+1;\n        else r = mid-1;\n    }\n    cout<<(ok?"YES":"NO")<<'\\n';\n}`}</code></pre>√10¹² = 10⁶，在 [1,2000000] 上二分平方根：mid² 与 n 比较，利用平方的单调性每次砍半，20 次内出结果。注意 mid*mid 最大约 4×10¹²，long long 足够（若上限更大要防溢出改用 mid < n/mid 写法）。也可用 sqrt 后平方校验的写法，但要警惕浮点误差。样例 144=12²，二分命中 mid=12，输出 YES。</Reveal>

## 3. 模拟编程题二：分组最小化（二分答案 + 贪心判定）
<Task title="分组最小化（测评题）" input="第一行两个整数 n、m（1≤n≤100000，1≤m≤n），第二行 n 个整数（每个不超过 10⁴）" output="把这 n 个数按顺序分成连续的 m 组，使「各组和的最大值」尽量小，输出这个最小化的最大值" sampleIn="5 3
1 4 2 8 1" sampleOut="9">经典的「二分答案」：对「最大值不超过 x」做判定——按顺序贪心分组，累加超过 x 就另起一组，组数 ≤ m 则 x 可行。答案满足单调性（x 可行则更大的也可行），二分 x。判定为什么必须按顺序而不能重新排序？</Task>
<Reveal label="查看参考程序与思路"><pre><code>{`#include <iostream>\nusing namespace std;\nint a[100005];\nint n, m;\nbool check(long long x){\n    int groups = 1;\n    long long cur = 0;\n    for(int i=0;i<n;i++){\n        if(a[i] > x) return false;      // 单个元素就超限，x 不可行\n        if(cur + a[i] <= x) cur += a[i];\n        else { groups++; cur = a[i]; }\n    }\n    return groups <= m;\n}\nint main(){\n    cin>>n>>m;\n    long long sum = 0;\n    for(int i=0;i<n;i++){ cin>>a[i]; sum += a[i]; }\n    long long l = 1, r = sum;\n    while(l < r){\n        long long mid = (l+r)/2;\n        if(check(mid)) r = mid;         // 可行，尝试更小\n        else l = mid+1;                 // 不可行，必须更大\n    }\n    cout<<l<<'\\n';\n}`}</code></pre>check(x) 是 O(n) 的贪心：顺序累加，装不下就另起一组，组数不超过 m 即可行。因为按顺序分组已最优（每个组都塞得尽量满），所以判定正确。答案在 [1, sum] 内且判定单调，二分收敛到最小的可行 x。样例 5 个数分 3 组：`{1,4}`+`{2}`+`{8,1}` 最大组和 9，验证 8 不可行（8 单独一组、2+1=3、1+4=5 要 3 组但 8 这组已经等于 8，再想 {8} 独占一组则其余 4 个数分 2 组最大至少 5？不行，严格验证：x=8 时 1+4=5、2、8、1 共 4 组 > 3，不可行），故答案 9。复杂度 O(n log sum)，轻松过 10⁵。</Reveal>

## 4. 考试须知
1. **时间分配**：五级考试时间更长、难度更高，先做选择判断稳住基本盘，编程题先读全题再动手，宁可一题做对不两题做半。
2. **数据范围是题眼**：看到 n≤10⁵ 就要想到 O(n log n)（排序、二分、分治），O(n²) 直接排除；看到「对 10⁹+7 取余」立即反应出同余运算。
3. **模板默写过关**：gcd、埃氏筛、二分模板、归并排序，考前一晚必须能不看资料默写。
4. **边界自查清单**：n=1 和 n 最大时对吗？输出格式（大小写、空格、-1 特判）和题目一字不差吗？long long 用了吗？
5. **留检查时间**：交卷前用 10 分钟重读两道题的题面，核对输出格式——大量失分来自「会做但输出错」。

> 教学提醒：考前一天不要再刷新题，把 gcd、埃氏筛、二分、归并四个模板各默写一遍，再完整做一遍本课两道测评题，手感比新题重要。
