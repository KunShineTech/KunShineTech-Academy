## 1. 素数与合数：数的「社交圈」
把正整数想象成一个班级。**素数（质数）**是只有 1 和它自己两个朋友的「独行侠」——除了 1 和本身，没有别的约数；**合数**则朋友多多，至少有 3 个约数。

```cpp
bool isPrime(int n) {
    if (n < 2) return false;          // 0 和 1 都不是素数
    for (int i = 2; i * i <= n; i++)  // 只需试除到根号 n
        if (n % i == 0) return false;
    return true;
}
```

为什么试除到 `i * i <= n` 就够了？因为如果 n = a×b 且 a≤b，那么 a 一定不超过 √n。找 36 的约数时，找到 6×6 就「碰头」了，再往后都是重复的老朋友。

**三条铁律**：
1. **1 既不是素数也不是合数**，这是考试最爱挖的坑。
2. 2 是唯一的偶素数，也是最小的素数。
3. 判素数试除到 √n 即可，不必跑到 n-1。

> 教学提醒：让学生亲手验证 2、3、5、7 是素数，4、6、8、9 是合数，再追问「1 呢？」——多数学生会脱口而出「素数」，此时纠正印象最深。

## 2. 约数、倍数与最大公约数
如果 a 能被 b 整除（a % b == 0），就说 **b 是 a 的约数，a 是 b 的倍数**。12 和 18 的共同约数有 1、2、3、6，其中最大的是 **6**，叫最大公约数（gcd）；它们最小的共同正倍数是 **36**，叫最小公倍数（lcm）。

**黄金公式**（务必背下来）：

**a × b = gcd(a, b) × lcm(a, b)**

所以求 lcm 可以不用枚举，先求 gcd 再相除：`lcm = a / gcd * b`。注意要先除后乘，防止 a×b 溢出。

## 3. 同余与模运算：钟表上的数学
现在是 10 点，过了 5 小时是几点？不是 15 点，是 3 点——因为 **15 ≡ 3 (mod 12)**。读作「15 与 3 模 12 同余」，意思是它们除以 12 的余数相同。

C++ 里 `%` 就是模运算。模运算有三条好性质（m 为正整数）：

```cpp
(a + b) % m == ((a % m) + (b % m)) % m
(a * b) % m == ((a % m) * (b % m)) % m
```

**口诀：和的余数 = 余数的和（再取余），积的余数 = 余数的积（再取余）。**

什么时候用？当答案很大只要求「对 10⁹+7 取余输出」时，每一步加乘后立刻取模，数就永远不大，这就是同余的威力。

> 教学提醒：模运算没有「除法的余数 = 余数的除法」这条性质，讲性质时只讲加、减、乘，减法可提一句 (a-b+m)%m 防止出负数的写法。

## 4. 奇偶性：最朴素的分类
把所有整数按除以 2 的余数分成两类：**奇数（余 1）**和**偶数（余 0）**。奇偶运算表像加法口诀一样好记：

- 奇 ± 奇 = 偶；偶 ± 偶 = 偶；奇 ± 偶 = **奇**
- 奇 × 奇 = 奇；只要有一个因子是偶，乘积就是 **偶**

「两个数之和为偶 ⟺ 两数同奇偶」「乘积为奇 ⟺ 全为奇」，这类结论在组合计数题里能直接砍掉一半情况。

## 5. 实战：求最大公约数
我们先用最笨的办法理解 gcd：枚举 1 到 min(a,b)，找最大的公共约数。思路没错，但五级有更漂亮的武器（辗转相除法），下一课专门讲。本课先把暴力版写出来打基础。
