## 1. 分治：大事化小，小事化了
全班按身高排队太乱？那就**分**成两组分别排，再把两列**合并**——这就是**分治**（Divide and Conquer）：把大问题拆成结构相同的子问题，递归解决子问题，最后把结果**合**并起来。**分、治、合**三步缺一不可，和递归天生一对（子问题用递归解决）。

排序是分治的主战场。著名的两大 O(n log n) 排序——归并排序、快速排序——都是分治的产物，它们比 O(n²) 的冒泡、选择排序快一个量级，是处理 10⁵ 级数据的标配。

## 2. 归并排序：先分两半，再有序合并
归并排序像整理两叠已排好序的扑克牌：两叠牌面朝上，每次取较小的一张放到新堆。前提是两叠**各自有序**——那就先把数组递归对半分，分到只剩 1 个元素（天然有序），再逐级合并。

```cpp
int a[100005], tmp[100005];
void mergeSort(int l, int r) {
    if (l >= r) return;                 // 出口：区间长度 <= 1，天然有序
    int mid = (l + r) / 2;
    mergeSort(l, mid);                  // 分：左半排好
    mergeSort(mid + 1, r);              // 分：右半排好
    int i = l, j = mid + 1, k = l;      // 合：双指针有序归并
    while (i <= mid && j <= r)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid) tmp[k++] = a[i++]; // 左半边剩余
    while (j <= r)   tmp[k++] = a[j++]; // 右半边剩余
    for (int t = l; t <= r; t++) a[t] = tmp[t];
}
```

每层合并 O(n)，共 log n 层，总复杂度 **O(n log n)**，且**稳定**（相等元素的相对顺序不变）。

> 教学提醒：归并的「双指针合并」是算法竞赛高频子模块（逆序对、区间合并都靠它），值得单独练熟。可让学生先手工模拟 {3,1,4,2} 的分治合并树。

## 3. 快速排序：选标兵，分左右
快排的思路反过来：**先治后分**。选一个**基准值 pivot**（常取中间元素），把数组重排成「≤pivot 的在左，>pivot 的在右」，然后对左右两边递归。

```cpp
void quickSort(int l, int r) {
    if (l >= r) return;
    int pivot = a[(l + r) / 2];
    int i = l, j = r;
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) { swap(a[i], a[j]); i++; j--; }
    }
    quickSort(l, j);                    // 递归左段
    quickSort(i, r);                    // 递归右段
}
```

平均复杂度 O(n log n)，但实际比赛中直接用 `sort(a, a+n)`（底层是 introsort，快排+堆排的保险版）即可，**手写快排的意义在于理解分区思想**——它还能 pivot 变形解决「第 k 大」等问题。

## 4. 复杂度与稳定性速览
| 排序 | 平均复杂度 | 最坏 | 稳定性 | 特点 |
|------|-----------|------|--------|------|
| 冒泡/选择 | O(n²) | O(n²) | 冒泡稳/选择不稳 | 写法简单，只适合 n≤10⁴ |
| 归并 | O(n log n) | O(n log n) | 稳定 | 需要额外数组，合并可扩展 |
| 快速 | O(n log n) | O(n²) | 不稳定 | 原地排序，常数小 |

**口诀：数据一多别冒泡，n log n 起步走；要稳定选归并，要原地选快排。**

## 5. 实战：逆序对数量
归并排序还有个隐藏技能：合并时「右边剩下的每个元素都比左边当前元素小」，可以直接数出**逆序对**（`i<j` 但 `a[i]>a[j]`）的总数。
