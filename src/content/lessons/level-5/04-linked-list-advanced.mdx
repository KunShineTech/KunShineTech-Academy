## 1. 单链表的「单程」遗憾
上一课的单链表只朝一个方向拉手，于是有个尴尬：知道节点 q，想找它的**前一个**节点，只能从头再数一遍。这就像在单向隧道里，走过出口想回退，只能绕全城一圈。**双向链表**给每个节点加了一根「朝后的手指」prev，既能前进又能后退。

## 2. 双向链表：prev 与 next 两手都要硬
节点结构多一个指针：

```cpp
struct Node {
    int data;
    Node* prev, *next;
};
```

在 p 与 p->next 之间插入 q，要改**四根**指针：

```cpp
q->prev = p;            // q 的前手指拉 p
q->next = p->next;      // q 的后手指拉 p 原来的后继
p->next->prev = q;      // 原后继的前手指改拉 q
p->next = q;            // p 的后手指改拉 q
```

**口诀：先把自己安顿好（prev、next），再通知两边改拉我。**

删除节点 q 则改两根指针、释放内存：

```cpp
q->prev->next = q->next;   // 前驱跳过 q 指向后继
q->next->prev = q->prev;   // 后继跳过 q 指向前驱
delete q;
```

> 教学提醒：双向链表操作指针多、顺序更容易错，强烈建议先画三个节点的「方框—箭头图」，在图上用红笔改箭头，确认无误后再翻译成代码。先图后码是本课纪律。

## 3. 循环链表：首尾相连的队伍
**循环链表**把最后一个节点的 next 指回头节点，队伍首尾相接，像围成一圈做游戏的人：从任意一个人出发沿 next 走，最终一定能转回起点。

```cpp
Node* tail = ...;              // 建完链后拿到尾节点
tail->next = head;             // 连成环
```

两个易错点：
1. **判空/终止条件变了**：单链表用 `p != nullptr` 判到头；循环链表常用 `p != head`（绕一圈回到头就停）。
2. 若用循环链表模拟「报数出局」类游戏，注意只剩一人时的特判。

循环链表还可升级为**双向循环链表**：prev 也成环，正向反向都能无限转。

## 4. 三种链表怎么选？
| 类型 | 找后继 | 找前驱 | 典型场景 |
|------|--------|--------|----------|
| 单链表 | O(1) | O(n) | 只向前处理，如栈式扫描 |
| 双向链表 | O(1) | O(1) | 需要来回移动，如浏览器前进/后退 |
| 循环链表 | O(1)（绕圈） | 视类型 | 轮转调度、约瑟夫问题 |

## 5. 实战：双向链表的建立与逆序输出
双向链表最大的甜头之一是**倒着遍历**不用递归也不用栈：从尾节点沿 prev 一路后退即可。
