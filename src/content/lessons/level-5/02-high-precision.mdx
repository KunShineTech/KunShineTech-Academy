## 1. 当数字大到装不下
`int` 最大约 21 亿，`long long` 最大约 9×10¹⁸——听起来很大？计算 100 的阶乘试试：100! 有 158 位，long long 连零头都装不下。就像用体重秤称大象，量程不够时，**我们把每一位数字拆下来，用数组一格装一位**，自己实现竖式运算，这就是**高精度计算**。

约定俗成的三条存储规则：
1. **倒序存储**：`a[0]` 放个位，`a[1]` 放十位……这样进位时直接往高位加，不用整体搬移。
2. 用 `len` 记录当前位数。
3. 读入用字符串，逐位转成数字存入数组。

```cpp
string s; cin >> s;
int a[505] = {0}, len = s.size();
for (int i = 0; i < len; i++)
    a[i] = s[len - 1 - i] - '0';   // 倒着放：个位进 a[0]
```

> 教学提醒：倒序存储是本课最大障碍。让学生在纸上把「123」按 a[0]=3、a[1]=2、a[2]=1 摆一次，再正序摆一次做竖式加法，亲身体会为什么倒序顺手。

## 2. 高精度加法：竖式进位
回想小学竖式：同位相加，满 10 进 1。写成代码就是逐位循环：

```cpp
// a、b 存两个加数，c 存结果，从低位往高位扫
for (int i = 0; i < max(lena, lenb); i++) {
    c[i] += a[i] + b[i];       // 先加，可能带着上一轮的进位
    c[i+1] += c[i] / 10;       // 满十进一
    c[i] %= 10;                // 留下个位
}
```

**口诀：先加后除十进位，个位留给自己。**

## 3. 高精度减法：借位处理
减法比加法多一步心思：同位相减，**不够减就向上一位借 1 当 10**。

```cpp
for (int i = 0; i < lena; i++) {
    c[i] += a[i] - b[i];       // 先减
    if (c[i] < 0) {            // 不够减：借位
        c[i] += 10;
        c[i+1] -= 1;
    }
}
```

注意两件事：若 `a<b` 要**先交换再补负号**；结果高位可能剩一串 0，输出前要从高往低跳过前导零。

## 4. 高精度乘法（高精 × 单精）
把一个 200 位的大数乘以一个 10000 以内的整数：用每一位去乘小因子，再统一进位。

```cpp
for (int i = 0; i < lena; i++) {
    c[i] += a[i] * b;          // 该位乘小因子，累加进 c[i]
    c[i+1] += c[i] / 10;       // 进位给高位
    c[i] %= 10;
}
```

乘积的位数最多是「大数位数 + 小因子位数」，开数组时留够余量（如 505 格）。高精乘高精是五级以上的进阶内容，考纲要求到「高精 × 单精」即可。
