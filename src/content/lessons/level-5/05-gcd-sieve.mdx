## 1. 辗转相除法：gcd 的聪明算法
第一课的暴力求 gcd 要枚举到 min(a,b)，太笨。两千多年前的欧几里得发现了一个秘密：**gcd(a, b) = gcd(b, a mod b)**。为什么呢？想象 a = 99、b = 36：99 = 2×36 + 27。任何同时整除 36 和 27 的数，也一定能整除 99；反过来同时整除 99 和 36 的数也一定能整除 27。所以两对数的「公共约数集合」一模一样，最大公约数自然相同。

反复用这个式子，余数会迅速缩小，直到余数为 0，此时的 b 就是答案。代码短得惊人：

```cpp
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);   // b 为 0 时，a 就是答案
}
```

**口诀：大除小，余替换，余零收工。**

## 2. 唯一分解定理：每个合数的「身份证号」
**唯一分解定理**（算术基本定理）：每个大于 1 的正整数 n，都能唯一地写成素数之积：

**n = p₁^a₁ × p₂^a₂ × … × pₖ^aₖ**

就像 360 = 2³ × 3² × 5¹，它是唯一的，没有第二种分法。这个定理威力巨大，比如**约数个数公式**：把每个素因子的指数加 1 再相乘，就是 n 的约数总数——360 的约数有 (3+1)×(2+1)×(1+1) = 24 个。想枚举所有约数，也只需对每个素因子选「取 0 到 a 次」做组合。

```cpp
// 分解质因数：试除到根号 n
for (int i = 2; i * i <= n; i++) {
    while (n % i == 0) {          // i 是素因子
        cout << i << ' ';         // 记录 i 及其次数即可
        n /= i;
    }
}
if (n > 1) cout << n << ' ';      // 剩下的大于根号的因子
```

> 教学提醒：试除过程中 i 被整除尽之后的下一个 i 一定是素数——因为合数 i 的素因子早在更小的 i 处就被除掉了。这个「隐性筛素」的性质值得和学生点破。

## 3. 埃氏筛：一次筛出一张素数表
判一个数是不是素数，试除法够了；但要判 **1~n 里所有**素数呢？埃拉托斯特尼想了个筛豆子的办法：从 2 开始，把 2 的倍数全部划掉；找到下一个没被划掉的 3，把 3 的倍数全划掉；再下一个 5……留下的就是素数。

```cpp
bool vis[100005] = {false};       // vis[i]=true 表示 i 被划掉
int primes[100005], cnt = 0;
for (int i = 2; i <= n; i++) {
    if (vis[i]) continue;         // 被划掉，跳过
    primes[cnt++] = i;            // i 是素数，收进口袋
    for (int j = i + i; j <= n; j += i) vis[j] = true;  // 划掉倍数
}
```

复杂度约 O(n log log n)，n = 10⁶ 眨眼就出结果。注意 `j = i + i` 起步即可，`i` 本身不能划。

## 4. 线性筛：让每个合数只被划一次
埃氏筛有个小浪费：12 会被 2 和 3 各划一次。欧拉筛（线性筛）规定：**每个合数只被它的最小素因子划掉**，复杂度严格 O(n)。

```cpp
for (int i = 2; i <= n; i++) {
    if (!vis[i]) primes[cnt++] = i;          // i 是素数
    for (int j = 0; j < cnt && i * primes[j] <= n; j++) {
        vis[i * primes[j]] = true;           // 划掉 i×第 j 个素数
        if (i % primes[j] == 0) break;       // 关键：整除就停！
    }
}
```

关键是那个 break：一旦 primes[j] 是 i 的因子，i×primes[j+1] 会由更小的素因子在别处被划，不必重复劳动。五级掌握埃氏筛为主，线性筛作为「精益求精」了解其思想即可。
