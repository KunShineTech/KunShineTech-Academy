## 1. 套娃与递归
俄罗斯套娃：打开一个大娃娃，里面有个一模一样的较小娃娃，再打开还有……直到最小的那个实心娃娃为止。**递归**就是程序里的套娃：**函数自己调用自己**，每次解决一个「更小一号」的问题，直到「最小号」直接得出答案。

数学里的阶乘定义就是递归的：n! = n × (n-1)!，而 0! = 1。翻译成代码：

```cpp
int fact(int n) {
    if (n == 0) return 1;      // 出口：最小号的娃娃，直接作答
    return n * fact(n - 1);    // 递推：把更小的问题交给"下一个自己"
}
```

调用 `fact(3)` 时：3×fact(2) → 2×fact(1) → 1×fact(0) → 1，再一路乘回来得 6。这叫**递推**下去、**回归**回来。

## 2. 递归三要素：出口、缩小、组合
写递归就检查三要素：
1. **出口（边界条件）**：什么时候不再调用自己？没有出口的递归会**栈溢出**——娃娃无限套下去，电脑内存装不下。
2. **问题缩小**：每次调用，问题规模必须变小（n-1、n/2 等），保证能到达出口。
3. **结果组合**：子问题的答案如何拼成当前问题的答案（n × fact(n-1)）。

**口诀：先想出口，再变小，最后拼答案。** 三要素缺一，递归必翻车。

> 教学提醒：初学者最常见错误是忘写出口或缩小方向写反。要求学生在写函数体之前，先用注释写下这三要素，再动笔。

## 3. 经典例题：斐波那契与 Hanoi
斐波那契数列：F(n) = F(n-1) + F(n-2)，F(1)=F(2)=1。

```cpp
int fib(int n) {
    if (n <= 2) return 1;
    return fib(n - 1) + fib(n - 2);
}
```

代码优雅，但它有个问题：算 F(50) 要等「永远」——因为它重复计算了大量重叠子问题（F(3) 被算了千千万万次），复杂度约 O(2ⁿ)。

**优化策略**（记住名字即可）：
- **记忆化**：开个数组 `memo[n]` 存算过的结果，重复查询直接取用，降到 O(n)。
- **递推（动态规划雏形）**：从小到大用循环算，天然不重复。

汉诺塔是递归思维的标志性题目：把 n 层塔从 A 移到 C，先递归把上面 n-1 层移到 B，移动最底层，再递归把 n-1 层移到 C。核心心得：**相信递归**——调用 fib(n-1) 时不要去想它内部怎么转，相信「更小的问题它能解决」。

## 4. 递归的复杂度分析
- **时间**：画一棵「递归调用树」，数节点个数。fact 是一根链，n 个节点 → O(n)；fib 是分叉树 → O(2ⁿ)。
- **空间**：每层调用占一份**调用栈**空间（存局部变量和返回位置），最深递归深度就是空间复杂度。fact 深度 n → O(n) 栈空间。

这也是为什么出口缺失会「栈溢出」：调用层数无上限，栈内存被撑爆。
