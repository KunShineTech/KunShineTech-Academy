## 1. 数组的烦恼：插队问题
班里排队打饭，老师说「小 A 插到第 3 个位置」。用数组模拟的话，第 3 个之后所有人都要**往后挪一格**——O(n) 的搬运量，队伍越长越慢。而现实中人们插队只是**改一下前后手的拉法**：前面的人改拉小 A，小 A 拉住原来那个人。**链表**就是程序里的这种「手拉手」队伍：每个节点只知道自己后面是谁，插入删除只需改一两根「手指」，不用搬家。

代价是：想找到第 k 个人，只能从头一个个数过去（O(n)），不能像数组那样 `a[k]` 直达。**一句话总结：链表牺牲随机访问，换取插入删除的快捷。**

## 2. 节点：数据和指路的指针
每个节点分两格：一格装**数据**，一格装**指向下一个节点的指针**（相当于「拉着下一个人的手」）。

```cpp
struct Node {
    int data;      // 数据
    Node* next;    // 指向下一节点的指针
};
```

创建链表的固定套路：用 `new` 申请节点、填数据、接指针。还可以设一个**头节点**（哨兵），它的 data 不用，只用来当「队伍的排头标志」，这样第一个位置的操作和中间位置就统一了，代码不容易错。

```cpp
Node* head = new Node{0, nullptr};  // 头节点，next 先指向空
Node* p = head;                     // p 是移动指针，从头出发
for (int i = 1; i <= n; i++) {
    int x; cin >> x;
    p->next = new Node{x, nullptr}; // 接到队伍末尾
    p = p->next;                    // p 前进到新节点
}
```

> 教学提醒：`p = p->next` 是链表遍历的灵魂语句，建议让学生在纸上画 3 个节点和箭头，亲手把 p 走一遍，理解「p 始终指向当前节点」。

## 3. 遍历：从头走到尾
遍历链表和遍历数组很像，只是「步进」方式不同：数组用 `i++`，链表用 `p = p->next`。

```cpp
for (Node* p = head->next; p != nullptr; p = p->next)
    cout << p->data << ' ';
```

循环条件 `p != nullptr` 就是「还没走出队伍尽头」。nullptr 相当于队伍最后一个人说：「我后面没有人了。」

## 4. 插入与删除：改两根「手指」
在第 3 个节点**之后**插入新节点，只需两步：

```cpp
Node* q = new Node{x, nullptr};
q->next = p->next;   // 新节点拉住 p 原来的下一个
p->next = q;         // p 改拉新节点
```

**口诀：先接后，再接前——新节点先记住后面是谁，前面的人才改拉它。**

删除 p 后面的节点更简单：

```cpp
Node* q = p->next;   // 记住要删的人
p->next = q->next;   // p 改拉 q 的下一个（跳过 q）
delete q;            // 释放内存，好习惯
```

两句话千万记牢：**插入和删除的指针操作顺序不能颠倒**（先接后、再接前），且都要找到「前一个节点」才能动手——这就是为什么遍历找位置时，通常停在目标的前一个。
