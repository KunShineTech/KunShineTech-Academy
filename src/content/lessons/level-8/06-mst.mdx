## 1. 从「村村通公路」说起
有 n 个村庄、m 条候选公路，每条公路有造价。政府想让**所有村庄互相连通**，且**总造价最小**，该怎么选路？

这就是经典的**最小生成树（MST, Minimum Spanning Tree）**问题：把村庄看成点、公路看成边，选出一批边使所有点连通、没有环，且边权之和最小。

**生成树**有两个关键性质，考试常考：

1. 选出的边恰好是 **n−1 条**（n 个点连通且无环，边数必为 n−1）。
2. 生成树的边权之和叫「生成树的权」，其中最小的就是最小生成树。

## 2. Kruskal：从小到大贪心选边
Kruskal 的思路朴素得可爱：**把所有边按权值从小到大排序，依次考虑每条边；若它连接的两个点还不连通，就选它，否则跳过。**

「连不连通」怎么判断？——**并查集**！选边的过程就是把两个集合合并的过程：若 find(u) ≠ find(v)，说明不连通，选这条边并合并集合；若相等，说明会形成环，舍弃。

三条铁律（Kruskal 版）：

1. **先排序，再贪心**：从小到大保证每一步都取当前最便宜的「安全边」。
2. **判环靠并查集**：路径压缩 + 按秩合并后，每次查询近乎 O(1)。
3. **选够 n−1 条边即停**：若所有边都试完了还不够 n−1 条，说明图**不连通**，无解。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int f[5005];
int find(int x) { return f[x] == x ? x : f[x] = find(f[x]); }  // 路径压缩

struct Edge { int u, v, w; };
bool cmp(Edge a, Edge b) { return a.w < b.w; }

int main() {
    int n, m;
    cin >> n >> m;
    vector<Edge> es(m);
    for (auto &e : es) cin >> e.u >> e.v >> e.w;
    sort(es.begin(), es.end(), cmp);
    for (int i = 1; i <= n; i++) f[i] = i;

    long long ans = 0;
    int cnt = 0;                       // 已选边数
    for (auto &e : es) {
        int fu = find(e.u), fv = find(e.v);
        if (fu != fv) {                // 不连通：选它，合并
            f[fu] = fv;
            ans += e.w;
            cnt++;
        }
    }
    if (cnt == n - 1) cout << ans << '\n';
    else cout << "orz\n";              // 连不通，无解
}
```

复杂度：**排序 O(m log m) + 并查集 O(m·α(n))**，其中 α 是近乎常数的反阿克曼函数，整体就是 O(m log m)。

> 教学提醒：Kruskal 的正确性依赖一个贪心事实——权值最小的跨集合边一定在某棵最小生成树里（「切分定理」）。考试不要求证明，但要记住结论：Kruskal 选边顺序是全局从小到大，Prim 是局部从点出发，二者结果（总权值）一定相同。

## 3. Prim：从点出发长树
Prim 是另一种贪心：从任意一个点开始，维护「已在树中的点集」，每步从**连接树内点与树外点的边**中选权值最小的一条，把新点拉进树。重复 n−1 次。

- 朴素实现：每轮扫描所有边找最小跨边，O(n²)。
- 堆优化：用优先队列维护候选边，O(m log n)。

**Kruskal 围着「边」转，Prim 围着「点」转。**

## 4. 两种算法怎么选
| 场景 | 推荐算法 | 理由 |
| --- | --- | --- |
| 边少点多的稀疏图（m ≈ n） | **Kruskal** | 排序 + 并查集代码短、常数小 |
| 边多点密的稠密图（m ≈ n²） | **Prim（朴素）** | O(n²) 避开排序开销 |
| 要求输出选边方案 | 两者皆可 | 记录被选中的边即可 |

八级考试里 Kruskal 出现频率更高——代码短、好写、好调试，务必形成肌肉记忆。
