## 1. 从一次秋游说起
「同学们，周末秋游，从学校到森林公园可以坐火车，也可以坐汽车。火车有 3 个班次，汽车有 2 个班次，一共有几种走法？」

教室里马上有两种声音：有人喊 3+2=5，有人喊 3×2=6。到底谁对？——都对，只是他们想的不是同一个问题：**问「几种走法」时，要先想清楚这些走法之间是「分类」关系还是「分步」关系**。这就是组合数学的入门第一课：计数原理。

计数原理是八级组合数学的地基，后面学的排列、组合、杨辉三角，全都建立在这两个原理上。竞赛里也到处有它的影子：方案计数、概率统计、搜索剪枝的上界估计，都要先会「数数」。

## 2. 加法原理：分类做一件事
完成一件事有 n 类办法，第 i 类有 a_i 种不同的方法，且**各类之间互不重叠**，那么完成这件事共有：

**N = a_1 + a_2 + … + a_n**

秋游问题里，「坐火车」和「坐汽车」是两类各自独立的办法：坐火车任选一个班次就到，不需要再坐汽车。所以走法总数 = 3 + 2 = **5 种**。

口诀：**分类用加法，类类独立、互不重复。**

> 教学提醒：加法原理的关键词是「互不重复」。如果两类办法有重叠（比如火车 3 班中有 1 班其实和汽车同线路），直接相加会把重复的方案数两遍，必须先去掉重叠部分——这就是容斥原理的思想萌芽。

## 3. 乘法原理：分步做一件事
完成一件事要分 k 个步骤，第 i 步有 b_i 种方法，且**每一步都不能省略**，那么完成这件事共有：

**N = b_1 × b_2 × … × b_k**

换一个问题：「从 3 件上衣、2 条裤子、4 双鞋中各选一件配成一套，有多少种搭配？」选上衣、选裤子、选鞋是三步，缺一不可，所以搭配数 = 3 × 2 × 4 = **24 种**。

口诀：**分步用乘法，步步相依、缺一不可。**

## 4. 综合应用：先分类，再分步
真实题目往往是「分类」套「分步」。看这道竞赛风格的小题：

> 从 1~9 中选一个数字作为十位，从 0~9 中选一个数字作为个位，要求这个两位数是偶数，有多少个？

先分类（个位是偶数）：个位 ∈ `{0, 2, 4, 6, 8}`，共 5 类。每一类内部再分步：十位有 9 种选法（1~9，不受个位影响）。每类 9 个，共 5 × 9 = **45 个**。这就是「先分类、再分步」的标准打法。

用程序暴力验证一遍，是竞赛选手的好习惯：

```cpp
#include <iostream>
using namespace std;
int main() {
    int cnt = 0;
    for (int tens = 1; tens <= 9; tens++)        // 十位：分步第一步
        for (int ones = 0; ones <= 9; ones++)    // 个位：分步第二步
            if (ones % 2 == 0) cnt++;            // 分类条件：偶数
    cout << cnt << '\n';   // 输出 45
}
```

三重结构各司其职：**分类靠分支（if），分步靠嵌套循环，验证靠枚举计数。**

## 5. 课后巩固
1. 概念：用自己的话解释加法原理和乘法原理的区别，并各举一个生活例子。
2. 计算：书架上有 4 本数学书、3 本物理书、2 本化学书，从中任取一本有多少种取法？各取一本又有多少种取法？
3. 编程：输入 a、b、c 分别表示三类互不重叠的办法数，输出完成这件事的总办法数，并用两组数据自测。
4. 思考：「用 1~9 的数字组成无重复数字的三位偶数」需要先分类还是先分步？试着列出你的计数结构。
5. 拓展：查一查什么是容斥原理，说说它解决的是加法原理中的什么问题。
