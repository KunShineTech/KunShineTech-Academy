## 1. 一张流传了八百年的数表
把数字排成下面这样的三角形：

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1
```

它在中国叫**杨辉三角**（杨辉在《详解九章算法》中引用，更早可追溯到贾宪），在西方叫**帕斯卡三角形**。别看它朴素，它藏着组合数学最核心的秘密：**第 n 行第 k 个数，恰好就是 C(n,k)**。

## 2. 两条生成规则
用 C(n,k) 的眼光看这表，构造规则一目了然：

1. **每行首尾都是 1**：C(n,0) = C(n,n) = 1。
2. **中间的数 = 肩上两数之和**：C(n,k) = C(n-1,k-1) + C(n-1,k)。

规则 2 就是著名的**帕斯卡恒等式**。直观理解：从 n 个人里选 k 个，盯住某一个人甲——选甲的方案有 C(n-1,k-1) 种（剩下 n-1 人中再选 k-1 个），不选甲的方案有 C(n-1,k) 种，两类相加正是 C(n,k)。**分类用加法**，原理课的知识无缝衔接！

## 3. 杨辉三角的五大性质
竞赛中常考的结论，一次记牢：

1. 第 n 行有 n+1 个数，对应 C(n,0) 到 C(n,n)。
2. **每行左右对称**：C(n,k) = C(n,n-k)。
3. **第 n 行数字之和 = 2ⁿ**（每个元素「选或不选」各一次，共 2ⁿ 个子集）。
4. 递推式 C(n,k) = C(n-1,k-1) + C(n-1,k)，这是 DP 算组合数的基础。
5. 斜着看：第 3 条斜线是三角数 1, 3, 6, 10, …（C(n,2)）。

> 教学提醒：行号从 0 还是从 1 开始是这一课最容易翻车的地方！本课统一约定：**最顶端单独的 1 是第 0 行**，所以「1 5 10 10 5 1」是第 5 行。读题时务必先确认题目的行号约定，否则递推边界全错。

## 4. 打印杨辉三角
用二维数组 + 递推，十行代码搞定：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, a[35][35];
    cin >> n;                          // 输出前 n 行（第 0 ~ n-1 行）
    for (int i = 0; i < n; i++) {
        a[i][0] = a[i][i] = 1;         // 规则一：首尾为 1
        for (int j = 1; j < i; j++)
            a[i][j] = a[i-1][j-1] + a[i-1][j];  // 规则二：肩上相加
    }
    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) cout << a[i][j] << ' ';
        cout << '\n';
    }
}
```

如果只想要某一个 C(n,k)，可以**滚动数组**只保留上一行，空间从 O(n²) 降到 O(n)——这正是后面「算法优化」课要反复用到的思想。

## 5. 课后巩固
1. 概念：写出杨辉三角的两条生成规则，并说明第 n 行第 k 个数与 C(n,k) 的关系。
2. 计算：利用帕斯卡恒等式，由 C(6,2) 和 C(6,3) 推出 C(7,3)。
3. 编程：输出杨辉三角的前 10 行，要求每行数字对齐成等腰三角形形状。
4. 思考：第 2 条斜线 1, 2, 3, 4, …（即 C(n,1)）和第 3 条斜线 1, 3, 6, 10, …（即 C(n,2)）各代表什么实际计数问题？
5. 拓展：调查杨辉三角中奇数的分布（谢尔宾斯基三角形），说说它为什么能和分形产生联系。
