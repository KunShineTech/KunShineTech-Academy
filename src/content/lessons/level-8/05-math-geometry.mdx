## 1. 方程：带着未知数的等式
「一个数的 3 倍加上 5 等于 26，这个数是多少？」设这个数为 x，翻译成数学语言：**3x + 5 = 26**——这就是**方程**：含有未知数的等式。让等式成立的未知数的值叫**方程的解**。

方程是数学建模的第一步：竞赛题里「等量关系」往往就是列方程的依据。会解方程，很多应用题就只剩「翻译」这一道工序了。

## 2. 一元一次方程：移项变号
只含一个未知数、且未知数次数为 1 的方程叫**一元一次方程**，标准形：**ax + b = c（a ≠ 0）**。

求解全靠一条金句：**移项要变号**。

- 3x + 5 = 26 → 3x = 26 − 5 = 21（+5 移到右边变 −5）
- x = 21 ÷ 3 = **7**

写成通式：**x = (c − b) / a**。程序化就是把这套流程翻译成代码：

```cpp
double a, b, c;
cin >> a >> b >> c;        // 解 ax + b = c
cout << (c - b) / a;       // 公式即算法
```

## 3. 二元一次方程组：消元
「买 3 支笔、2 个本共 19 元；买 2 支笔、3 个本共 16 元。笔和本各多少钱？」设笔 x 元、本 y 元：

```
3x + 2y = 19
2x + 3y = 16
```

**核心技巧：消元**——把两个未知数消成一个。

- **加减消元**：第一式 ×3、第二式 ×2，得 9x+6y=57 与 4x+6y=32，相减消去 y：5x=25，x=5，代回得 y=2。
- **代入消元**：由第一式解出 y=(19−3x)/2，代入第二式求解。

竞赛中使用计算机求解二元一次方程组时，常用**加减消元的公式版**（克莱姆法则）：对 ax+by=e、cx+dy=f，令 D=ad−bc，则 x=(ed−bf)/D，y=(af−ec)/D。**D≠0 是唯一解的前提**——D=0 时方程组无解或有无穷多解。

> 教学提醒：用公式法解方程组前务必先判断 D=ad−bc 是否为 0！除数为 0 会让程序崩溃或输出乱值。竞赛数据若保证唯一解也要写明「数据保证 D≠0」；若题目不保证，代码里就要分支处理。

## 4. 常见图形的面积公式
几何题在信息学竞赛中常以「计算几何入门」形式出现，先背熟这张表：

| 图形 | 面积公式 |
| --- | --- |
| 长方形 | S = a × b（长 × 宽） |
| 正方形 | S = a² |
| 三角形 | S = 底 × 高 ÷ 2 |
| 平行四边形 | S = 底 × 高 |
| 梯形 | S =（上底 + 下底）× 高 ÷ 2 |
| 圆形 | S = π × r² |

三条铁律：

1. **单位要统一**：长用米、宽用厘米，先换算再计算。
2. **三角形的高**必须是对应底边上的高（钝角三角形的高可能落在形外）。
3. **π 的取值**：竞赛通常取 3.1415926 或直接用 `acos(-1)`（最精确的 π），输出格式看题目要求保留几位小数。

## 5. 用程序解方程、算面积
把公式写进代码，就是最简单的「数学辅助编程」：

```cpp
#include <iostream>
#include <cmath>           // 提供 M_PI 或 acos
using namespace std;
int main() {
    double r;
    cin >> r;
    double pi = acos(-1);  // 求 π 最保险的方法
    printf("%.2f\n", pi * r * r);   // 圆面积，保留两位小数
}
```

## 6. 课后巩固
1. 概念：什么是方程的解？举例说明「移项变号」的规则。
2. 计算：解方程组 x + y = 10，x − y = 4；再求半径为 5 的圆的面积（π 取 3.1415926）。
3. 编程：输入二元一次方程组的四个系数与两个常数项，输出 x、y（数据保证唯一解，保留两位小数）。
4. 思考：一块长方形菜地长 12 米，宽比长少 4 米；若把它改成正方形且面积不变，正方形边长是多少？（提示：面积先算，再开方。）
5. 拓展：推导梯形面积公式为什么等于「两底之和 × 高 ÷ 2」，并用两个完全一样的梯形拼一拼验证。
