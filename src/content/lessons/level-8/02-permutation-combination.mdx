## 1. 有序还是无序？一字之差
「从 5 名同学中选出 2 人去参加比赛」和「从 5 名同学中选出 2 人，一人当组长、一人当记录员」，是一回事吗？

前者选出 `{甲, 乙}` 和 `{乙, 甲}` 算同一种选法——**无序**；后者甲当组长乙记录，与乙当组长甲记录，是两种不同安排——**有序**。

- **排列**：选出 m 个并**安排顺序**，记作 A(n,m)（或 P(n,m)）。
- **组合**：选出 m 个**不看顺序**，记作 C(n,m)（或写作 n 选 m 的括号记号）。

竞赛教练常说：读题时先问一句「**交换顺序算不算新方案？**」——算，用排列；不算，用组合。

## 2. 排列数：站成一排有多少种站法
5 个人站成一排，第 1 个位置有 5 种选择，第 2 个位置剩 4 种……共 5×4×3×2×1 = 120 种。这就是**阶乘**：n! = n×(n-1)×…×2×1。

只选 m 个位置排列：第 1 位 n 种，第 2 位 n-1 种……第 m 位 n-m+1 种，所以：

**A(n,m) = n×(n-1)×…×(n-m+1) = n! / (n-m)!**

特别地，**A(n,n) = n!**（全排列）。

## 3. 组合数：只看选出谁，不看顺序
排列把「选谁」和「怎么排」打包算了。组合只关心选谁：m 个被选的人内部有 m! 种排法在排列里被重复计算了，除掉即可：

**C(n,m) = A(n,m) / m! = n! / (m! × (n-m)!)**

组合数有两个非常好用的对称性质：

1. **C(n,m) = C(n,n-m)**：选 m 个去比赛，等价于选 n-m 个留下来。
2. **C(n,0) = C(n,n) = 1**：什么都不选或全选，都只有一种方案。

## 4. 用程序算排列组合
阶乘增长极快：13! 就超过了 int 上限（约 2.1×10^9），20! 就远超 long long。所以竞赛里**绝不先算 n! 再相除**，组合数用递推式边乘边除：

```cpp
#include <iostream>
using namespace std;

long long fact(int n) {                 // 排列、小阶乘时用
    long long r = 1;
    for (int i = 2; i <= n; i++) r *= i;
    return r;
}
long long A(int n, int m) {             // A(n,m) = n!/(n-m)!
    return fact(n) / fact(n - m);
}
long long C(int n, int m) {             // 边乘边除，不爆 long long
    m = min(m, n - m);                  // 利用对称性减少计算量
    long long r = 1;
    for (int i = 1; i <= m; i++)
        r = r * (n - i + 1) / i;        // 每次先乘后除，结果必为整数
    return r;
}
```

> 教学提醒：`r * (n-i+1) / i` 为什么每次都能整除？因为第 i 轮循环时，r 恰好等于 C(n, i-1)，乘以 (n-i+1) 再除以 i，恰好是递推式 C(n,i) = C(n,i-1) × (n-i+1) / i，数学上保证是整数。但千万不要写成 `r / i * (n-i+1)`——除法在前会先把整数除断，结果就错了。

## 5. 竞赛中的常见模型
把公式套进真实赛题，常见三类：

1. **选人无顺序**：从 n 人中选 m 人 → C(n,m)。
2. **安排有顺序**：n 人排成一列 → n!；选 m 人排队 → A(n,m)。
3. **先选后排**：先 C(n,m) 选出人选，再乘上各自的内部排列数——本质是乘法原理的组合版。

口诀：**先问有序无序，再定排列组合；公式拿不准，小数据枚举验。**

3. 编程：输入 n，输出 n! 的值；试到 n 多大时结果超出 long long 范围，并记录。
