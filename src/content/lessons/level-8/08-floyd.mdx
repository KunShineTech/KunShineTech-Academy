## 1. 新问题：任意两点都要最快
上节课 Dijkstra 解决的是「从我家出发」的单源最短路。但物流公司要规划全城配送：任意两个网点之间的最短距离都要知道，该怎么办？

**全源最短路**：求出图中**每一对**点之间的最短距离，共 n² 个答案。朴素办法是对每个点各跑一次 Dijkstra，共 O(n·m log n)。而 Floyd 算法只要**三重循环**，思路却优雅得像一首诗。

## 2. Floyd 的思想：逐个请「中转点」
把问题倒过来看：dist[i][j] 表示 i 到 j 的最短距离。我们逐个「放行」中转点 k=1,2,…,n，每放行一个 k 就问自己一句：

> **「允许经过 k 中转，能不能让 i→j 更近？」**

转移方程只有一行：

**dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])**

放行完所有中转点，dist 里存的就是任意两点间的最短距离。这是典型的**动态规划**：阶段是「已放行的中转点集合」，决策是「要不要借道 k」。

口诀：**中转点放外层，借道中转试一试，三重循环全 pair。**

## 3. 代码与初始化
```cpp
#include <iostream>
#include <cstring>
using namespace std;

const long long INF = 1e15;
long long dist[305][305];
int n, m;

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            dist[i][j] = (i == j) ? 0 : INF;   // 自己到自己为 0
    for (int i = 0; i < m; i++) {
        int u, v; long long w;
        cin >> u >> v >> w;
        dist[u][v] = min(dist[u][v], w);       // 重边取最小
        dist[v][u] = min(dist[v][u], w);       // 无向图双向存
    }
    for (int k = 1; k <= n; k++)               // 中转点 k 必须在最外层！
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (dist[i][k] + dist[k][j] < dist[i][j])
                    dist[i][j] = dist[i][k] + dist[k][j];
}
```

复杂度 **O(n³)**，三层循环直白得没有优化空间——所以 Floyd 的适用边界很清晰：**n ≤ 500 左右**（500³ = 1.25×10^8，勉强可过；n=10^3 就要三思）。

> 教学提醒：三重循环中 **k 必须是最外层**！只有按「中转点逐个点亮」的顺序递推，dist[i][k] 和 dist[k][j] 才已经包含「只允许更早的中转点」的最优值。把 k 放内层等于同时允许所有点中转，递推关系被破坏，结果必然出错——这是 Floyd 最经典的失分点。

## 4. Floyd 与 Dijkstra 怎么选
| 对比项 | Floyd | Dijkstra |
| --- | --- | --- |
| 求解范围 | 一次算出**所有点对** | 固定**一个起点** |
| 时间复杂度 | O(n³) | 朴素 O(n²)，堆优化 O((n+m) log n) |
| 适用规模 | n ≤ 500 | n 可达 10^5 |
| 负权边 | **允许**（但不能有负环） | 不允许 |
| 代码量 | 极少 | 较多 |

经验法则：**问一对点跑 Dijkstra，问所有点跑 Floyd；点多图疏用 Dijkstra（堆优化），点少查询多上 Floyd。** 八级真题常考「理解实现同一功能的不同算法的比较，并灵活解决相关问题」，这张表就是答题模板。
