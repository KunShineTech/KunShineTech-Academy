## 1. 从排队理解数组变换
同学们排成一队，老师要做三件事：让队伍**倒着报数**（逆序）、中间来了一位新同学**插队**（插入）、有同学请假**离队**（删除）。数组的变换和排队一模一样，区别在于：插队要让后面的人挨个往后挪，离队要让后面的人挨个往前补。

## 2. 逆序：倒着输出与首尾交换
**逆序输出**最简单：下标从 n-1 递减到 0 输出即可，数组本身不变。

**原地逆置**（把数组内容真正倒过来）用**首尾交换**：i 和 n-1-i 两个位置互换，i 只走到数组一半。以 5 个数为例，交换 (0,4) 和 (1,2)，中间的 2 号位置不用动。

```cpp
for (int i = 0; i < n / 2; i++) {
    int t = a[i]; a[i] = a[n-1-i]; a[n-1-i] = t;
}
```

## 3. 插入与删除
**在 p 号位置插入 x**（原 p 号及之后元素都后移）：从最后一个元素开始，逐个往后挪一格，腾出 p 号位，再放进 x，元素个数加一。

**删除 p 号位置的元素**：从 p+1 开始，每个元素向前挪一格盖住前一个，元素个数减一。

```cpp
// 在 p 处插入 x
for (int i = n; i > p; i--) a[i] = a[i-1];
a[p] = x; n++;

// 删除 p 处元素
for (int i = p; i < n-1; i++) a[i] = a[i+1];
n--;
```

**数组平移**（了解）：把数组整体向左循环移动 k 位，相当于每位元素的下标减去 k 再对 n 取模。三重循环可以完成，更高效的做法是三次逆置，有兴趣的同学课后研究。

## 4. 课后巩固
1. 手推：对 `1 2 3 4 5 6` 做原地逆置，写出每轮交换后的数组。
2. 编程：在下标 p 处插入整数 x，并输出插入后的整个数组。
3. 编程：删除数组中**所有等于 x** 的元素（提示：逐个判断，不等 x 的才保留）。
4. 说出「逆序输出」与「原地逆置」的两点区别。
5. 思考：为什么插入/删除操作要求数组「留出空位」？如果数组开得刚刚好会发生什么？
