## 1. 从抓犯人理解枚举
警察破案：把嫌疑人名单列出来，逐个核对证据，最后锁定真凶。这就是**枚举算法**：把可能的答案**一一列举**出来，对每个候选答案**验证**是否满足条件。它不靠灵感，靠耐心——计算机最不缺的就是耐心。

枚举三步骤：
1. **确定范围**：答案可能在哪里？（如 1~n）
2. **写出验证条件**：怎么判断是不是答案？
3. **逐个检查**：for 循环跑一遍，命中就处理。

## 2. 配合数组的枚举
数组是枚举的好帮手：把每个候选者的属性存进数组，枚举下标即可。

```cpp
// 筛选 1~n 中所有 3 的倍数，并计数
int a[105], cnt = 0;
for (int i = 1; i <= n; i++)
    if (i % 3 == 0) a[cnt++] = i;   // 命中就存进数组
```

**筛素数初步**：判断 x 是否为素数，可以枚举 2 到 x-1，看有没有能整除 x 的数。这是典型的「枚举 + 验证」。

## 3. 枚举的优化
当范围很大时，全枚举会超时。两把快刀：

1. **缩小范围**：判素数只需枚举到根号 x——如果 x 有因子，必然一个小于等于根号 x、一个大于等于根号 x。
2. **数学约束**：求「两个数之和为 s」的配对，固定第一个数 a 后，第二个数只能是 s-a，无需再枚举。

```cpp
// 判断 x 是否为素数：只需试除到 sqrt(x)
bool isPrime = true;
for (int i = 2; i * i <= x; i++)
    if (x % i == 0) { isPrime = false; break; }
```
