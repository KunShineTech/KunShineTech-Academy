## 1. 从储物柜理解数组
班里 50 个同学，每人一个储物柜，柜子上贴着 0 号、1 号、……、49 号的号码牌。**数组**就是这样的储物柜阵列：一排连续的同类型格子，每个格子有一个编号，这个编号叫**下标**。

之前我们写 `a1, a2, a3...` 一个一个起名，同学多了根本忙不过来。有了数组，只要写 `a[i]`，就能用变量 i 访问第 i 个格子，配合循环就能「批量处理」。

## 2. 定义、初始化与下标
```cpp
#include <iostream>
using namespace std;
int main() {
    int a[5];              // 定义 5 个 int 格子
    int b[5] = {1, 2, 3};  // 前 3 个初始化为 1,2,3，其余自动为 0
    int c[] = {10, 20, 30}; // 不写大小，编译器数出 3 个

    for (int i = 0; i < 5; i++) a[i] = i * 10;
    cout << b[0] << ' ' << b[4] << '\n';  // 1 0
}
```

三条铁律：
1. 下标从 **0** 开始，`a[5]` 的合法下标是 0~4。
2. 数组大小必须是常量（或编译期可确定的数），不能是输入的变量。
3. 访问越界位置（如 `a[5]`）是**未定义行为**：程序可能崩溃、可能输出乱值，编译器不报错——这是初学者最常见也最隐蔽的 bug。

> 教学提醒：int 数组只初始化一部分时，其余元素自动为 0；但完全不初始化（如 `int a[5];`）的元素是不确定的垃圾值。

## 3. 遍历数组：for 循环三件套
遍历（从头到尾访问每个格子）是数组的灵魂，固定套路是：

```cpp
for (int i = 0; i < n; i++) {   // i 从 0 开始，到 n-1 结束
    cin >> a[i];                // 依次读入
}
for (int i = 0; i < n; i++) {   // 再输出
    cout << a[i] << ' ';
}
```

循环条件「`i < n`」保证了 i 最大只到 n-1，永远不会越界。读入 n 个数的流程：先读 n，再开循环读 n 个数。
