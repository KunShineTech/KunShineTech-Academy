## 1. 从班级成绩单理解统计
期末考试结束，老师拿到一叠成绩：算总分、找最高分和最低分、数及格人数、查某个分数有没有出现过——这四件事就是数组统计的四大基本功。把成绩存进数组后，所有操作都变成一句口诀：**设好初值，遍历一遍，逐个比较或累加**。

## 2. 最值与下标：先假设第一个
求最大值时，经典的「擂台法」：先让擂台主 `mx` 等于 `a[0]`，然后每个选手 `a[i]` 上台挑战，谁更大谁当新擂主。如果同时记录擂主的**下标** `pos`，赛后就能知道冠军坐在第几号位置。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a[5] = {7, 3, 9, 2, 9};
    int mx = a[0], pos = 0;
    for (int i = 1; i < 5; i++) {
        if (a[i] > mx) { mx = a[i]; pos = i; }
    }
    cout << mx << ' ' << pos << '\n';  // 9 2
}
```

> 教学提醒：循环从 `i = 1` 开始（0 号已经在擂台上了）。找最小值用 `a[i] < mn`，逻辑完全一样。

## 3. 计数与查找
**计数**：设置计数器 `cnt` 初值为 0，遍历中每遇到一个满足条件的元素就 `cnt++`。判断条件写在 if 里，想数什么就写什么。

**查找**：想知道数组里有没有某个数 x？从头到尾比一遍——找到就输出「有」并可以立即结束；全部走完都没找到，输出「没有」。这个算法叫**顺序查找**。

```cpp
int cnt = 0;
for (int i = 0; i < n; i++)
    if (a[i] % 2 == 0) cnt++;   // 统计偶数个数

bool found = false;
for (int i = 0; i < n; i++)
    if (a[i] == x) { found = true; break; }
```
