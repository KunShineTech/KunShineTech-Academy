## 1. 为什么计算机只认识 0 和 1？
生活中我们习惯用**十进制**：逢十进一，因为人有十个手指。计算机却用**二进制**：逢二进一，只用 0 和 1 两个数字。

为什么？可以把计算机内部想象成一排灯泡：每个灯泡只有「亮」和「灭」两种状态，稳定又容易区分。如果让计算机识别十种电压等级，稍有干扰就会出错。所以计算机的每一个存储位（bit）只有两种状态，对应 0 和 1，这正是二进制的本质。

| 数制 | 基数 | 可用数字 | 例子（表示十进制 9） |
|---|---|---|---|
| 二进制 | 2 | 0、1 | `1001₂` |
| 八进制 | 8 | 0~7 | `11₈` |
| 十进制 | 10 | 0~9 | `9` |
| 十六进制 | 16 | 0~9、A~F | `9` |

在 C++ 中，可以直接写出不同进制的常量：`0b1010` 表示二进制 10（部分编译器支持），`012` 表示八进制 10，`0x1F` 表示十六进制 31。

## 2. 二进制转十进制：位权展开法
每个位置都有**位权**：从右往左，第 0 位是 `2⁰=1`，第 1 位是 `2¹=2`，第 2 位是 `2²=4`，第 3 位是 `2³=8`，依此类推。

例如 `1011₂`：把每一位的数字乘上它的位权再相加——`1×8 + 0×4 + 1×2 + 1×1 = 11`，所以 `1011₂ = 11`。

```cpp
#include <iostream>
using namespace std;
int main() {
    int b = 0b1011;        // 二进制常量
    cout << b << '\n';     // 输出 11
    cout << 0x1F << '\n';  // 十六进制 31
}
```

> 教学提醒：位权展开的口诀是「按权展开、逐项相加」。低位在右，高位在左，数清位数最关键。

## 3. 十进制转二进制：短除法
要把十进制 `11` 转成二进制：反复除以 2 并记录余数，直到商为 0，最后把余数**倒序**读出。

`11÷2=5 余1 → 5÷2=2 余1 → 2÷2=1 余0 → 1÷2=0 余1`，余数倒序为 `1101`？不对——倒序读出应是 `1011₂ = 11`。请自己动手验证一遍，体会「先得到的余数是低位」。

八进制转二进制有一个快捷方法：因为 `2³=8`，所以每 **3 位二进制** 对应 1 位八进制；十六进制则每 **4 位二进制** 对应 1 位（`2⁴=16`）。例如 `101 110₂` 分成两组，正好是 `5 6₈`。

```cpp
#include <iostream>
using namespace std;
int main() {
    int n = 11, b = 0, p = 1;
    while (n > 0) {
        b += (n % 2) * p;  // 取余数，放到当前位
        p *= 10;           // 让下一位进一位
        n /= 2;            // 商继续
    }
    cout << b << '\n';     // 输出 1011
}
```

## 4. 进制之间的快速通道
二进制与八进制、十六进制之间有一条「分组捷径」，考试常考：

- 二进制转八进制：从右往左每 3 位一组，每组直接写成 0~7 的一个数字。
- 二进制转十六进制：从右往左每 4 位一组，每组写成 0~9 或 A~F。

例如 `101110₂`：从右往左每 3 位分组为 `101 110`（高位不足时补 0），得 `5 6`，即 `56₈`；而 `1010₂` 正好 4 位一组，直接就是 `A`。

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s = "101110";
    int sum = 0;
    for (int i = 0; i < s.size(); i++)
        sum = sum * 2 + (s[i] - '0');  // 按位权还原成十进制
    cout << sum << '\n';               // 46
}
```

**思路：** A 表示 10。位权展开：`2×16 + 10×1 = 42`。
