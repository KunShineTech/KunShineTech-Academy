## 1. 从瑞士军刀理解字符串函数
string 内置了一整套瑞士军刀。掌握它们的关键是记住**三要素**：从哪个位置开始、操作多长、返回什么。下面这张表建议抄写背诵：

| 函数 | 作用 | 例子（s = "abcde"） |
|---|---|---|
| `s.find(t)` | 找子串 t 首次出现的位置 | `s.find("cd")` 得 2 |
| `s.substr(p, len)` | 从 p 截取 len 个字符 | `s.substr(1,3)` 得 "bcd" |
| `s.replace(p, len, t)` | 把 p 起 len 个字符换成 t | `s.replace(1,2,"XY")` 得 "aXYde" |
| `s.insert(p, t)` | 在 p 处插入 t | `s.insert(0,"*")` 得 "*abcde" |
| `s.erase(p, len)` | 删除 p 起 len 个字符 | `s.erase(1,2)` 得 "ade" |
| `s += t` / `s.append(t)` | 末尾拼接 | `s += "fg"` 得 "abcdefg" |

## 2. find 与 npos：一对黄金搭档
`find` 找到了返回位置（下标从 0 开始），**没找到**返回一个特殊常量 `string::npos`。所以判断查找是否成功的标准写法是：

```cpp
string s = "hello world";
if (s.find("wor") != string::npos) {
    cout << "找到了，位置是 " << s.find("wor") << '\n';  // 6
} else {
    cout << "没找到\n";
}
```

> 教学提醒：npos 是无位置标记，不要把它当成 -1 参与计算；只用 `!= string::npos` 判断是否找到。

## 3. 数字与字符串互转（了解）
`to_string(123)` 得到 `"123"`；`stoi("456")` 得到整数 456。处理「把数字按位拆开」或「把读入的数字串求和」类题目时非常方便。

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s = to_string(2025);   // "2025"
    int x = stoi("42");           // 42
    string r = s.substr(0, 2);    // "20"
    s.replace(0, 4, "ok");        // s 变成 "ok"
}
```
