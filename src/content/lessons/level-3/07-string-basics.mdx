## 1. 从快递单理解 string
字符数组像手写便签：好用但得自己管结束符、长度。`string` 类型是 C++ 自带的「智能快递袋」——能自动变长、自带尺子（求长度）、还有一堆工具（查找、替换、截取）。GESP 三级以后处理文字，优先用 string。

使用前记得 `#include <string>`。

## 2. 定义、读入与长度
```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s = "hello";       // 定义并初始化
    string t(5, 'a');         // 5 个 a：aaaaa
    string u;                 // 空串
    cin >> u;                 // 读入一个不含空格的词
    getline(cin, u);          // 读入一整行（含空格）——了解
    cout << s.size() << ' ' << s.length() << '\n';  // 5 5
}
```

两种读入方式的区别：`cin >> u` 遇到空格就停，只读一个「词」；`getline` 读入整行直到回车，空格也读进来。初学竞赛题多数用 `cin`，读整行时再请 getline 出场。

长度用 `s.size()` 或 `s.length()`，两者完全一样，返回字符个数（例如 `"hello"` 返回 5）。

## 3. 下标、遍历、比较与拼接
string 支持下标访问 `s[i]`，下标从 0 开始，遍历写法：

```cpp
for (int i = 0; i < s.size(); i++) cout << s[i];
```

字符串比较用字典序：从第一个字符开始逐位比 ASCII，分出大小就立刻停止。`"abc" < "abd"` 为真，`"apple" < "banana"` 为真。相等判断用 `==`；`s.compare(t)` 也能比较（了解），返回 0 表示相等。

拼接用 `+`：`string s = "he" + string("llo");`，还可以在末尾追加：`s += "!"` 或 `s.push_back('!')`。
