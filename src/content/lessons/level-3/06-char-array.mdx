## 1. 从字典排序理解字符比较
查字典时「apple」排在「banana」前面，因为第一个字母 a 在 b 前面。C++ 比较字符也是看**字典序**，本质是比较 ASCII 编码的大小：`'A' < 'B'` 为真，`'a' < 'b'` 为真，但 `'Z' < 'a'` 也为真（因为大写字母 65~90，小写字母 97~122，**所有大写字母都小于所有小写字母**）。

字符可以参与运算：`'a' - 'A'` 等于 32，`'7' - '0'` 等于 7。这些技巧在密码题里经常出现。

## 2. 大小写转换：两种武器
方法一（背公式）：已知是小写字母时，`char(c - 32)` 转大写；已知是大写字母时，`char(c + 32)` 转小写。依据是同一字母大小写相差 32。

方法二（更稳妥）：用 cctype 库函数 `toupper(c)` 和 `tolower(c)`。它们的好处是：不是字母的字符原样返回，不用先判断。

```cpp
#include <iostream>
#include <cctype>
using namespace std;
int main() {
    char c = 'g';
    cout << char(c - 32) << '\n';      // G
    cout << char(toupper('m')) << '\n'; // M
    cout << char(tolower('Q')) << '\n'; // q
    cout << ('a' < 'z') << '\n';        // 1（真）
}
```

## 3. 字符数组：一串字符的格子
字符数组就是「每格存一个字符」的数组，用法和普通数组几乎一样，但常与字符串打交道：

```cpp
char s[10] = {'h', 'i'};   // 前两个是 h、i，其余自动为 '\0'
char t[] = "hello";        // 字符串字面量初始化，编译器自动补上结尾符 '\0'
for (int i = 0; t[i] != '\0'; i++)   // 遇到结尾标志就停
    cout << t[i];
```

注意 `'\0'` 是值为 0 的「字符串结束标志」，它不是字符 0。用 `t[i] != '\0'` 作为循环条件，是遍历字符数组的经典写法。
