## 1. 从照着菜谱做菜理解模拟
做菜时严格照着菜谱：先放盐、再煮三分钟、最后出锅——每一步都不许自由发挥。**模拟算法**就是把题目的过程当菜谱，用代码**原样复现**一遍：题目说报数，我们就报数；题目说出圈，我们就标记出圈。它考验的不是巧思，而是**细致与耐心**。

模拟的关键步骤：
1. 读懂规则，把过程拆成若干**小步骤**；
2. 想清楚每一步**用什么变量记录状态**（数组、计数器）；
3. 按顺序实现，注意**边界**（第 1 个、最后 1 个）。

## 2. 报数出圈初步：用数组做「淘汰标记」
n 个人围成一圈，从 1 开始报数，报到 m 的人出圈，从下一个人继续。用数组 `alive[i]` 记录每个人是否还在圈内（1 在、0 出），再配合计数器模拟报数：

```cpp
int alive[105] = {0};          // 先全部置 0
for (int i = 0; i < n; i++) alive[i] = 1;
int cnt = 0;                   // 已出圈人数
int num = 0;                   // 当前报数
int i = 0;                     // 当前下标
while (cnt < n - 1) {          // 只剩 1 人时停
    if (alive[i]) {
        num++;
        if (num == m) { alive[i] = 0; cnt++; num = 0; }
    }
    i = (i + 1) % n;           // 下标绕圈：到尾回头
}
```

`i = (i + 1) % n` 是实现「围成圈」的精髓：取模让下标到 n 后自动回到 0。

## 3. 边界与对拍测试
模拟题最容易错在**边界**：第一个出圈的人、最后一个留下的人、n=1 的情况。写完代码后：
- **手算小样例**：用 n=5、m=2 笔算答案，和程序对拍；
- **特殊值测试**：n=1、全是同一值、答案在开头或结尾；
- **对拍思想**：写两个不同实现的程序，用大量随机数据比较输出是否一致。
