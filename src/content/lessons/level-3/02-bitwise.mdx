## 1. 从开关面板理解位运算
把整数的二进制位想象成一排开关。位运算就是**直接对这排开关做批量操作**，不需要理解整数的数学大小，只看每一位的 0 和 1。

四个基本位运算的「开关规则」：

| 运算 | 符号 | 规则（两个开关并排看） |
|---|---|---|
| 按位与 | `&` | 两个都是 1，结果才是 1 |
| 按位或 | `\|` | 只要有一个是 1，结果就是 1 |
| 按位非 | `~` | 0 变 1，1 变 0 |
| 按位异或 | `^` | 相同为 0，不同为 1 |

## 2. 异或与移位的重要性质
异或 `^` 有两条金规则，非常好记：`a^a` 永远等于 0（自己跟自己没差异），`a^0` 永远等于 a（跟 0 异或什么都不变）。利用它们，三次异或就能交换两个变量的值！

移位运算像给整排开关「整体搬家」：`<<` 左移一位相当于**乘 2**，`>>` 右移一位相当于**除以 2 向下取整**。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 12, b = 10;   // 1100 与 1010
    cout << (a & b) << '\n';  // 1000 = 8
    cout << (a | b) << '\n';  // 1110 = 14
    cout << (a ^ b) << '\n';  // 0110 = 6
    cout << (1 << 4) << '\n'; // 10000 = 16
    cout << (7 >> 1) << '\n'; // 3（7/2 取整）
}
```

> 教学提醒：位运算的优先级低于比较运算，写表达式时多打括号，例如 `(x & 1) == 0`。

## 3. 位运算的典型应用
**判断奇偶**：任何整数的二进制末位是 1 则为奇数，所以 `(x & 1) == 1` 表示奇数。

**取低几位**：`x & 3` 保留低 2 位（因为 3 的二进制是 `11`）；`x & 15` 保留低 4 位。相当于对 `2^k` 取余：x & (2的k次方-1) 等价于 x % 2的k次方。

**清零与保留**：`x & 0` 得 0（清零）；`x | 0` 得 x（保留）；`x ^ x` 得 0；`x ^ 0` 得 x。

## 4. 位运算练习场
**异或交换**：利用 `a ^ a` 得 0 的性质，三行代码就能交换两个变量，不需要临时变量。

**取第 k 位**：`x >> k` 先把目标位移到末位，`& 1` 再把它单独取出来，`(x >> k) & 1` 就是第 k 位的值。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 5, b = 9;
    a = a ^ b; b = a ^ b; a = a ^ b;  // 三次异或交换
    cout << a << ' ' << b << '\n';    // 9 5
    int x = 13;                        // 二进制 1101
    cout << ((x >> 2) & 1) << '\n';    // 取第 2 位：1
}
```
