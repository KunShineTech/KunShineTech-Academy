## 1. 从回文诗理解对称判断
「上海自来水来自海上」正着读反着读都一样，这叫**回文**。判断回文的经典方法是**首尾双指针**：左指针 i 从 0 出发，右指针 j 从末尾出发，每轮比较 `s[i]` 与 `s[j]` 是否相等；不等立刻不是回文，相等则 i 右移、j 左移，直到两指针相遇。

```cpp
bool ok = true;
for (int i = 0, j = s.size() - 1; i < j; i++, j--) {
    if (s[i] != s[j]) { ok = false; break; }
}
```

## 2. 字符统计与单词反转
**统计**的套路不变：计数器清零，遍历每个字符，用条件分类累加。统计元音字母：`s[i]=='a' || s[i]=='e' || s[i]=='i' || s[i]=='o' || s[i]=='u'`（注意要同时考虑大写）。

**单词反转**：把一个句子的每个单词字母倒序，单词顺序不变。核心是把字符串按空格切成单词，逐词逆序输出——本质还是下标遍历。

## 3. 凯撒加密：每个字母往后挪三位
凯撒加密把每个字母变成字母表中往后数 3 位的字母：`a→d`、`b→e`、……、`x→a`（绕回开头）。用取模实现循环：`(c - 'a' + 3) % 26 + 'a'`。

```cpp
for (int i = 0; i < s.size(); i++) {
    if (s[i] >= 'a' && s[i] <= 'z')
        s[i] = char((s[i] - 'a' + 3) % 26 + 'a');
}
```

> 教学提醒：凯撒加密只是教学扩展，让大家体会字符编码与取模的应用，真正的加密远比这复杂。解密就是把 +3 换成 +23（往回挪 3 位）。
